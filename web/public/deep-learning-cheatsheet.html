Building Blocks (MLP)

neuron: y = act(w·x + b)         # dot + bias + nonlin
layer:  H = act(X @ W + b)       # X:[N,d_in] W:[d_in,d_out]
net   = stack of (linear + nonlinearity)
  • Depth builds a hierarchy of features learned end-to-end: early layers = edges/n-grams, late layers = objects/semantics. Width = features per layer; depth = composition.
  • Universal approximation: one hidden layer can fit any continuous function — but may need exponential width. Depth buys the same expressiveness far more cheaply. Approximation is a possibility theorem, not a guarantee SGD finds the weights.
  • Params = weights + biases. Activations are cached on the forward pass for backprop → memory scales with depth × activation size !
  • Without a nonlinearity, a stack of linear layers collapses to a single linear map ! — no benefit from depth.

When to Use DL & Inductive Bias

Inductive bias = the structural assumption an architecture bakes in, which is what lets it learn from limited data. Choosing an architecture is choosing a prior.

ArchBias baked in
MLPnone — unordered vector; flexible but data-hungry
CNNlocality + translation equivariance → images
RNN/LSTMsequential order, same transition every step
Transformerall positions interact; weak locality → needs data + pos-encoding
GNNdata is a graph; respect connectivity
  • Strong correct bias (CNN on images) → less data needed. Weak bias (transformer) → more flexible, needs more data to compensate.
  • rule Should I even use DL? Unstructured input (image/audio/text) + lots of data (or a pretrained model) → yes. Tabular → gradient-boosted trees first. Thousands of rows, no pretrained model → classical ML.
  • ! Establish a simple baseline (logistic reg / XGBoost) before a net — DL must earn its complexity. Reaching for a deep net on 3k tabular rows is the classic mistake.
  • "Black box" is about the learned representation, not the mechanism — every forward matmul and backward gradient is derivable and every failure mode (NaN, flat loss, dead ReLU) has a known cause.

Tensor Shapes & Param Counting

vectors: (N, d_in)         # batch, features
images:  (N, C, H, W)      # batch, chan, H, W
Linear(d_in,d_out) params = d_in*d_out + d_out
Conv2d(Cin,Cout,k) params = (k*k*Cin + 1)*Cout   # size-INDEPENDENT
conv out H = ⌊(H + 2p − k)/s⌋ + 1

Worked: Linear(784, 256)

input (32,784) → out (32,256); params = 784·256 + 256 = 200,960. Batch dim never counts toward params.

Worked: CIFAR stage, track (C,H,W)

(3,32,32) Conv 3→32 (p=1)  → (32,32,32)
          Conv 32→32       → (32,32,32)
          MaxPool2 	        → (32,16,16)
          Conv 32→64       → (64,16,16)
          MaxPool2 	        → (64,8,8)
  • rule Same-pad 3×3 keeps size inside a stage; downsample (pool/stride-2) at stage boundaries; double channels when you halve H,W (VGG heuristic) → balanced capacity.
  • A conv's param count is independent of image size (weight sharing) ! — an MLP on 224×224×3 → 1000 units is ~150M weights; a CNN is orders of magnitude smaller.

Activation Functions

FnRange · note
sigmoid 1/(1+e⁻ˣ)(0,1); saturates → vanishing grad !; not zero-centred
tanh(-1,1); zero-centred but still saturates
ReLU max(0,x)default; cheap, sparse, no saturation for x>0; dying ReLU (stuck ≤0) !
LeakyReLU / PReLUsmall slope for x<0 → fixes dying units
GELU / SiLUsmooth; transformer/CNN default now
softmaxvector → prob simplex (output layer)
  • rule Hidden layers: start ReLU (or GELU). Reserve sigmoid/tanh for gates (LSTM) and binary output — never deep hidden stacks.
  • Dying ReLU cause: large negative bias / too-high LR pushes pre-activation permanently ≤0 → zero gradient forever. Fix: LeakyReLU, lower LR, better init.

Loss Functions

MSE = mean((y - ŷ)²)              # regression
MAE = mean|y - ŷ|                 # robust to outliers
BCE = -[y·log p + (1-y)·log(1-p)] # binary
CE  = -Σ yᵢ·log pᵢ                # multiclass (1-hot)
  • ! Use cross-entropy, not MSE, for classification: MSE + sigmoid gives a near-flat gradient when badly wrong (saturation); CE's gradient stays strong. CE also = maximum-likelihood under a categorical model.
  • The clean identity: softmax + cross-entropy ⇒ dL/dz = p − y (predicted minus one-hot). Elegant, numerically stable — always fuse them (CrossEntropyLoss takes logits, not probs) !
  • Regression outliers: MAE/Huber over MSE (MSE squares errors → dominated by tails).

Loss Zoo — beyond cross-entropy

LossUse / behavior
MSE / MAE / Huberregression; MAE/Huber robust to outliers
Cross-entropysingle-label; softmax; never zero (keeps sharpening)
BCE + sigmoidmulti-label (independent classes)
HingeSVM margin; zero once y·s ≥ 1; no probs
Focal-(1-pₜ)^γ·log pₜ; down-weights easy examples → class imbalance
Contrastive / tripletmetric learning; distance = similarity
Dicesegmentation region overlap
  • Label smoothing: target 1-ε on truth, ε/(K-1) elsewhere → caps logit magnitude, better calibration, mild regularizer. Small free accuracy bump on ImageNet/transformers.
  • Focal (γ≈2): easy example pₜ→1 ⇒ modulator (1-pₜ)^γ→0 ⇒ its loss vanishes → gradient listens to hard examples. Made single-stage detectors (RetinaNet) work.
  • Triplet max(0, d(a,p) − d(a,n) + m): anchor nearer positive than negative by margin. Hard/semi-hard mining is the whole game — random negatives give zero gradient !
  • CE = entropy + KL(true‖pred); minimizing CE = minimizing KL to the true distribution. Self-supervised (masked/next-token) and RL (-log π·advantage) are just losses whose target is free.
  • ! Probs summing to 2 → per-class sigmoid on a single-label task (should be softmax), or double-applied softmax.

Backpropagation

= reverse-mode autodiff over the computational graph. Computes dL/dw for every weight in ~one extra forward pass. Backprop only computes gradients — the optimizer is a separate step !

forward: cache activations left→right
backward: seed dL/dL = 1, chain rule right→left
  dL/dx = dL/dy · dy/dx        (local × upstream)

Canonical local gradients

Linear y = xW:  dL/dW = xᵀ·(dL/dy)
                dL/dx = (dL/dy)·Wᵀ
ReLU:           dL/dx = dL/dy · 1[x>0]   # mask
Add:            copies gradient to both inputs
Fork (reused x): gradients from all paths SUM
  • Backward, not forward, because one scalar loss vs millions of params: reverse mode computes each shared dL/d(layer) once → O(1) forward passes, not O(#params).
  • Backward reuses cached activations (doesn't recompute) → memory cost; gradient checkpointing trades compute to shrink it.
  • ! detach()/.data, in-place ops, or a non-differentiable step silently cut the graph → zero/None grads. Also: forgot zero_grad() → grads accumulate across steps.
  • Numerical grad-check: compare analytic grad to (L(w+h)−L(w−h))/2h (central difference, h≈1e-5); relative error < 1e-6 = correct. Use on a tiny net before trusting a hand-written backward.

LR Schedules, Warmup & Clipping

canonical recipe: linear WARMUP → cosine DECAY
 warmup: 0 → peak over first ~few-k steps
 decay:  peak → ~0 (or 10%) over the run
  • Warmup — why: early on weights and Adam's second moment v are unreliable (few samples); dividing by an underestimated √v → huge erratic steps exactly when the model is fragile. Skipping warmup on a transformer routinely diverges !
  • Decay — why: big exploratory steps early, small settling steps late → converge smoothly into (flat) minimum without bouncing out. Variants: step / cosine (default) / exponential / linear.
  • Adaptive ≠ no LR: Adam's √v only sets per-param relative scale; the global lr still multiplies everything (~3e-4 sweet spot) and too-large still diverges.
  • Gradient clipping: cap global grad-norm (~1.0) so a rare spike can't blow up weights → the RNN/deep-net exploding-gradient fix. First reach when loss goes NaN, alongside lowering LR.
  • rule Transformer-from-scratch: AdamW · β=(0.9, 0.95) on large LMs · warmup→cosine · clip 1.0 · weight-decay ~0.1 excluding biases & LayerNorm · large effective batch (grad-accum) · bf16.

Weight Init & Gradient Flow

  • ! All-zeros init → every neuron identical, identical gradients, never differentiate (symmetry never breaks). Init must be random.
  • Xavier/Glorot Var=1/n for tanh/sigmoid; He/Kaiming Var=2/n for ReLU (accounts for the half killed by max(0,·)). Goal: keep activation & gradient variance ~constant across depth.

Vanishing / exploding gradients !

backprop multiplies many Jacobians:
 |∂| < 1 repeatedly → VANISH (early layers freeze)
 |∂| > 1 repeatedly → EXPLODE (NaN loss)
  • Vanish cause: depth × saturating activations × repeated ·W. Symptom: early layers stop learning, loss plateaus.
  • Fix stack: ReLU-family · good init · normalization · residual connections · LSTM/GRU gates (sequences) · gradient clipping (RNN explosion).

Normalization

for a feature over the chosen axis:
 μ=mean  σ²=var  x̂=(x-μ)/√(σ²+ε)
 y = γ·x̂ + β        # learnable scale+shift

γ/β let the layer undo normalization → zero loss of expressiveness. β subsumes the preceding bias.

VariantNormalize over
BatchNormthe batch (per feature) — CNNs
LayerNormfeatures of one example — transformers/RNN
GroupNormchannel groups/example — small-batch vision
InstanceNormper channel/example — style transfer
  • ! BN train vs inference differ: train uses batch stats; inference uses stored running (EMA) stats. Forget model.eval() → garbage at test / batch-size-1 crash. THE classic bug.
  • BN benefits: higher LR, faster/stabler, mild regularization (from batch noise). Breaks at tiny batch → use GroupNorm/LayerNorm. LayerNorm is batch-independent → works at batch=1 & variable-length seqs (why transformers use it).
  • ! A bias before BN/LN is redundant — the norm subtracts the mean, killing it; β re-adds a learnable shift. Set bias=False on a conv/linear feeding a norm.
  • Where the norm sits: conv block is Conv→Norm→Act. Transformer pre-LN (LN→sublayer→+skip) trains far more stably than the original post-LN (sublayer→+skip→LN) — pre-LN keeps the residual path clean so gradients flow un-normalized. Norm pairs with residuals: it rescales while the skip preserves signal.

Regularization

  • Dropout(p): randomly zero units each step (implicit ensemble of subnetworks). ! Off at inference; inverted dropout scales by 1/(1-p) at train so activations match. model.eval() disables it (same switch as BN).
  • Weight decay / L2: penalize ‖w‖² → smaller weights, smoother function. Use AdamW for correct decoupling. L1 → sparsity.
  • Early stopping: halt when val loss turns up — cheap, always-on.
  • Data augmentation = biggest lever in vision (flip/crop/colour; mixup, cutmix). Label smoothing (target 0.9 not 1.0) curbs overconfidence.
  • mixup: train on convex blends of two examples and their labels (x̃=λxᵢ+(1-λ)xⱼ). CutMix: paste a patch of one image into another, mix labels by area. Both smooth decision boundaries and improve calibration.
  • Stochastic depth: randomly drop whole residual blocks at train (identity survives) → a dropout for layers; lets very deep ResNets train and act as an implicit ensemble of depths.
  • More data > every regularizer. BN also mildly regularizes (redundant with heavy dropout). rule Order when overfitting: more/augmented data → regularize → shrink model (last resort; shrinking loses double-descent benefits).

Overfitting, Capacity & Generalization

SymptomDiagnosis → fix
train↓ val↑ (gap)overfit → regularize / more data / smaller model
train & val both highunderfit → bigger model / train longer / lower reg
train≈0 val highmemorizing → augment, dropout, weight decay
  • Bias–variance: underfit = high bias; overfit = high variance. The gap between train and val is the variance.
  • ! Deep nets defy classic U-curve — double descent: past the interpolation threshold, more params can improve test error. Overparameterized + regularized is normal.
  • Always split train/val/test; tune on val, touch test once. Watch the val curve, not train.

Double Descent, Grokking & Flat Minima

test err vs capacity:
 \        /\          <- peak AT interpolation threshold
  \__   _/  \____     <- 2nd descent (over-param)
        ↑ train err hits 0
  • Interpolation threshold: capacity to just fit train exactly → ~unique wildly-wiggly interpolant that must thread every noisy point → high variance, test error peaks. "Just barely big enough" is the worst size !
  • Second descent: past the threshold many interpolants exist → optimizer's implicit bias picks a smooth, low-norm one → error falls again. Same shape appears epoch-wise and sample-wise (adding a little data can briefly hurt).
  • Implicit regularization of SGD: minimum-norm bias + mini-batch noise (acts like temperature) + spectral bias (fits simple/low-freq structure first) → generalizing solution found for free. Changing batch/LR/init changes test acc at identical zero train loss.
  • Flat vs sharp minima: train/test surfaces are shifted copies; a flat (wide) basin stays low under the shift → generalizes; a sharp one spikes. Small-batch SGD noise avoids sharp basins; SAM seeks flat ones explicitly.
  • Grokking: train acc hits 100% early, val stuck at chance for thousands of steps, then suddenly generalizes — weight decay drives it off the memorizing manifold. Proof that generalization is selection among interpolants, decoupled from fitting train.
  • rule Train 100% on epoch 3 but val still climbing = healthy over-param regime — don't stop; judge by the val curve, not train saturation.

CNN Fundamentals

feature map = conv(input, kernel) + b
out = ⌊(n + 2p − k)/s⌋ + 1     # per spatial dim
params(conv) = (k·k·C_in + 1)·C_out   # size-independent!
  • Parameter sharing (one kernel slid everywhere) + local receptive fields → translation equivariance, far fewer params than dense, works at any input size.
  • Levers: padding p ('same' keeps size), stride s (downsample), dilation (grow receptive field cheaply).
  • Receptive field grows with depth/stride — deep layers "see" more of the image. This is why depth matters for vision.
  • Pooling (max/avg) downsamples + adds small translation invariance; increasingly replaced by strided conv.

Pooling & Downsampling

MaxPool2d(2, stride=2): (C,H,W) → (C,H/2,W/2)

  • rule Max inside, average (global) at the end. Max keeps salient features + small-shift invariance; GAP gives a stable position-invariant summary for the classifier and kills the giant FC head.
  • Three jobs: downsample (cut compute/memory) · local translation invariance · faster receptive-field growth.
  • Pooling vs strided conv: pooling is parameter-free with built-in invariance (LeNet/VGG); strided conv learns the downsample and can keep info a hard max discards → modern default (ResNet), often with only a final GAP !

CNN Architectures & Components

  • 1×1 conv: mixes/projects channels, no spatial mixing → cheap dimensionality change ("bottleneck", network-in-network) ! underrated.
  • Depthwise-separable (MobileNet): depthwise (per-channel spatial) + 1×1 pointwise → ~⅑ the compute.
  • Global average pooling replaces giant FC head → fewer params, any input size.
  • Lineage: LeNet→AlexNet (ReLU+dropout+GPU)→VGG (stacked 3×3)→Inception (multi-scale, 1×1)→ResNet (skips)→EfficientNet (compound scaling).
  • Conv block idiom: Conv → Norm → Act (often → Conv → Norm → +skip → Act).

Residual Networks (ResNet)

y = F(x) + x        # skip / identity shortcut
  • Solves the degradation problem: plain nets past ~20 layers train worse — not overfitting, an optimization failure ! A deep plain net can't even learn identity mappings.
  • The block learns a residual F(x)=H(x)−x; if identity is optimal, drive F→0 (easy). The +x path is a gradient highway: backprop gets 1 + ∂F → gradient never vanishes to 0.
  • Enabled 100–1000+ layers. One of DL's most important ideas — reappears in every transformer block. Pair with BN/LayerNorm.
  • Bottleneck block: 1×1 (reduce) → 3×3 → 1×1 (restore) for depth-efficiency.

RNNs & BPTT

h_t = tanh(W_x·x_t + W_h·h_{t-1} + b)
y_t = W_y·h_t          # weights SHARED across time
  • Process sequences by carrying a hidden state. Trained by BPTT — unroll the loop, backprop through every timestep.
  • ! Long sequences → repeated ·W_h ⇒ vanishing (can't learn long-range deps) or exploding (NaN) gradients. Exploding fix: gradient clipping. Vanishing fix: gating (LSTM/GRU).
  • Variants: many-to-one (classify), many-to-many (tag/translate), bidirectional (see both directions — offline only).
  • Fundamental limit: sequential, no time-parallelism → slow to train. Transformers won on this.
  • Truncated BPTT: unrolling a 10k-step sequence is infeasible → backprop only through the last k steps (a window), trading exact long-range gradients for tractable memory/compute.

LSTM & GRU

LSTM gates (σ = 0..1):
 f=σ(...) forget   i=σ(...) input   o=σ(...) output
 C_t = f⊙C_{t-1} + i⊙C̃_t       # cell state
 h_t = o⊙tanh(C_t)
  • Cell state C is a near-linear conveyor belt: the forget gate's additive update lets gradients flow across long ranges → beats vanishing gradients !
  • Gates learn what to keep / write / expose — solves long-term dependencies RNNs can't.
  • GRU: merges to reset + update gates, no separate cell → fewer params, often ~as good, faster. Try GRU first.
  • Both still sequential — largely superseded by transformers for long-range tasks, but strong on small data / streaming / low-latency.

Attention & Transformers

Attention(Q,K,V) = softmax(Q·Kᵀ / √d_k)·V
  • Each output = content-based weighted average of values; weights = query·key similarity. Position 5 reads position 500 in one hop (O(1) path length) vs O(n) for an RNN.
  • ! ÷√d_k: without it, dot products grow with dimension → softmax saturates → tiny gradients.
  • Multi-head: split d into h subspaces, attend in parallel, concat → learns several relation types; compute ≈ one big head.
  • Self-attn (Q,K,V same seq) vs cross-attn (Q from decoder, K/V from encoder). Causal mask hides future tokens in a decoder.
  • ! Permutation-invariant → needs positional encoding for order. Cost is O(n²) in sequence length. ViT = image split into patch tokens.
  • Q,K,V = 3 learned projections of the input: query "what am I looking for", key "what do I offer", value "what I pass on if matched". Self-attn shapes: X[n,d] → scores [n,n] → out [n,d].
  • Cost: the n×n score matrix is O(n²) time and memory in sequence length → the long-context bottleneck. FlashAttention keeps it exact but tiles to cut memory; sparse/linear-attn approximate it.
  • Block = Attn → +skip → LayerNorm → FFN → +skip → LayerNorm (FFN ≈ 4× width, most of the params). GPT/KV-cache/tokenization/pretraining → LLM sheet.

Gradient Highways (why it trains)

flowchart LR X["x"] --> F["F(x)
conv/attn+FFN"] X -->|"identity skip
∂ = 1"| ADD(("+")) F --> ADD ADD --> Y["y = F(x)+x"]

Residual + normalization keep the backward Jacobian near 1, so gradients reach early layers un-vanished. The same F(x)+x block powers deep ResNets and every transformer layer — depth is only trainable because signal has a clear path both forward and backward.

seq2seq & the Attention Origin

  • Encoder–decoder: encoder reads input → context; decoder generates output token-by-token (translation, summarization).
  • ! The bottleneck: a fixed-size context vector can't hold a long sentence → quality collapses with length. Attention was invented to fix exactly this — let the decoder look back at all encoder states.
  • Teacher forcing: feed ground-truth prev token at train (fast, parallel) → exposure bias at inference (model sees its own errors) !
  • Decoding: greedy vs beam search (keep top-k hypotheses).

Training in Practice

  • Batch size: large = stable, hardware-efficient, less gradient noise (may generalize worse, needs warmup + LR scaling); small = noisy, regularizing. Grad accumulation simulates a big batch on small memory.
  • Mixed precision (fp16/bf16): ~2× speed & half memory; fp16 needs loss scaling to stop grad underflow (bf16 usually doesn't) !
  • Pipeline: overfit a single batch first (sanity), then scale. Monitor grad norms, LR, train+val loss.
  • Reproducibility: seed everything; some GPU ops still nondeterministic !
  • Grad accumulation: sum grads over k micro-batches before step() → simulate batch k× larger on fixed memory (remember to divide loss by k).
  • Gradient checkpointing: don't cache every activation — recompute them in the backward pass → trade ~30% compute for large memory savings, letting you fit deeper nets / longer sequences.
  • Checkpoint best-on-val; log with TensorBoard/W&B.

Transfer Learning & Fine-Tuning

  • Reuse a pretrained backbone: early layers = general features (edges, syntax), late layers = task-specific.
  • Feature extraction: freeze backbone, train a new head (small/similar data, fast, low overfit risk). Fine-tuning: unfreeze some/all, train at a low LR so you don't wreck pretrained weights !
  • Decision: small+similar → freeze most; large+different → fine-tune more/all. Discriminative LRs (lower for early layers) help.
  • PEFT (LoRA, adapters): freeze the base, inject small trainable matrices (LoRA = low-rank ΔW=BA added to attention projections) → fine-tune a huge model on one GPU, swap adapters per task.
  • Decision matrix: small+similar data → freeze most, train head; large+different → fine-tune all. Discriminative LRs (lower for early general layers, higher for late task-specific ones) protect the transferable features.
  • ! Fine-tune at a low LR and often with a short warmup — a big step early wrecks pretrained weights before the head has adapted (catastrophic forgetting).

Generative Models Deep-Dive

FamilyObjective · trait
Autoencoderreconstruct via bottleneck; code = compressed x
VAEreconstruction + KL to prior; stable, blurry
GANgen vs disc minimax; sharp, unstable
Diffusionlearn to denoise; best quality, slow sampling
  • VAE: encoder outputs a distribution (μ, σ), sample via the reparameterization trick (z=μ+σ·ε) so gradients flow through the sample; KL term pulls the latent toward N(0,1) so you can sample new data. Blur = the Gaussian likelihood averaging.
  • GAN: generator fools a discriminator; at equilibrium disc is 50/50. ! Mode collapse = generator emits a few outputs that fool disc, ignoring diversity; training is a delicate two-player balance (needs tricks: WGAN, spectral norm).
  • Diffusion: forward process adds Gaussian noise over many steps; a net learns to reverse it one denoise step at a time. Quality ≫ GAN/VAE, but many sampling steps = slow (distillation/latent diffusion speed it up).
  • Quality/stability spectrum: GAN (sharp, unstable) → VAE (stable, blurry) → Diffusion (best, expensive). Self-supervised (contrastive, masked prediction) is the unlabeled-pretraining engine behind modern DL.

★ Interview Playbook

Must be able to derive / state cold

  • ☐ Backprop from scratch: chain rule backward; linear dL/dW = xᵀ(dL/dy); ReLU gates where x>0; forks sum; why backward (O(1) fwd passes).
  • ☐ Softmax+CE gradient = p − y; why CE over MSE for classification.
  • ☐ Vanishing/exploding gradients + the full fix stack (ReLU/init/norm/residual/gating/clip).
  • ☐ He vs Xavier init; why never all-zeros.

Tradeoffs to argue

  • ☐ SGD+momentum vs Adam/AdamW; LR schedule (warmup→cosine); AdamW ≠ Adam+L2.
  • ☐ BatchNorm: 4 steps + γ/β + train/inference gotcha; BN vs LayerNorm axis (why transformers use LN).
  • ☐ Dropout = ensemble, off at inference; residual = gradient highway + degradation fix.
  • ☐ CNN (images, param-share/locality) vs RNN/LSTM (sequences, sequential) vs Transformer (parallel, O(1) path, O(n²) cost).
  • ☐ Attention softmax(QKᵀ/√d_k)V: role of each matrix, the √d_k scaling, why positional encoding.
  • ☐ Overfit vs underfit from train/val curves → the matching lever.
