Building Blocks

neuron: y = act(w·x + b)
layer:  Y = act(X @ W + b)
net = stack of (linear + non-linearity)

Depth → hierarchical features learned end-to-end. Params = weights+biases; activations cached for backprop.

Activations

Note
sigmoid/tanhsaturate → vanish
ReLU max(0,x)default; dying-ReLU !
Leaky/GELUfix dying ReLU
softmaxoutput probs

Non-linearity is essential — without it a deep net = 1 linear layer.

Losses

MSE  = mean((y-yhat)^2)            # regression
CE   = -sum y_i * log(p_i)         # classification
softmax+CE grad = p - y            # clean!

! Use cross-entropy (not MSE) for classification — better gradients, matches MLE.

Backpropagation

chain rule, BACKWARD through the graph:
dL/dW = dL/dy · x^T      (linear)
ReLU: gradient passes only where x>0
forward caches acts; backward reuses them

= reverse-mode autodiff. Feeds the optimizer.

Optimizers

Idea
SGDw -= lr*grad
+momentumvelocity, accelerate
RMSPropper-param adaptive LR
Adam/AdamWmomentum+RMSProp; decoupled decay

! LR is THE knob. Warmup + cosine decay. SGD may generalize better; Adam is robust default.

Init & Gradient Flow

  • He init for ReLU, Xavier for tanh/sigmoid. All-zeros breaks symmetry. !
  • Vanishing/exploding gradients (deep + saturating + repeated ·W).
  • Fixes: ReLU, good init, norm, residuals, LSTM gates, grad clipping (RNN).

Normalization

BN: normalize feature over the BATCH,
    then learnable scale+shift (gamma,beta)
  • Faster/stabler training, higher LR, mild regularization.
  • ! Train uses batch stats; inference uses running stats (classic bug).
  • LayerNorm (per example) → transformers/RNNs.

Regularization

  • Dropout p: zero units in training (an implicit ensemble); off at inference. !
  • Weight decay (AdamW), early stopping.
  • Data augmentation = biggest lever for vision; label smoothing, mixup.

CNNs

feature map = conv(input, filter) + b
out = (n + 2p - k)/s + 1
  • Parameter sharing + local receptive fields → translation equivariance, few params.
  • Pooling / stride downsample; 1x1 conv mixes channels.
  • LeNet→AlexNet→VGG→Inception→ResNet.

ResNets

y = F(x) + x     # skip / residual
  • Fixes the degradation problem (deep plain nets train worse). !
  • Identity path = gradient highway → 100+ layers.
  • One of DL's most important ideas (reappears in transformers).

RNN / LSTM / GRU

RNN: h_t = tanh(W_x x_t + W_h h_{t-1})
train by BPTT; grads vanish over long seq !
  • LSTM: cell state + forget/input/output gates → gradients flow far.
  • GRU: reset+update gates (fewer params).
  • Sequential (no time-parallelism) → transformers won.

Attention & Transformers

Attn = softmax(Q K^T / sqrt(d_k)) V
  • Every position attends to every other → parallel + long-range (O(1) path).
  • Replaced RNNs; encoder/decoder; positional encoding; ViT = image patches.
  • O(n^2). ! Internals (GPT/KV-cache/pretraining) → Large Language Models sheet.

Transfer Learning

  • Reuse a pretrained backbone; early layers = general features.
  • Feature extraction (freeze + new head) vs fine-tune (unfreeze, low LR).
  • Small+similar → freeze most; large+different → fine-tune more.

Train in Practice + Zoo

  • Batch size (memory vs noise vs generalization); mixed precision; grad accumulation.
  • NaN loss → clip/lower LR; flat loss → LR/init/data bug; gap → regularize.
  • Zoo: autoencoder, VAE, GAN, embeddings, GNN, diffusion.
