Method & What's Being Tested

The hard part is rarely the algorithm — it's modelling the system with the right Python idiom: data model, generator, context manager, decorator, asyncio, Protocol, or match?

Attack Plan — the loop every kata runs

Turn the prompt into an idiom + an API before writing any body.

  • 1 · What's the system & its rules? State them back (a cell holds literal-or-formula; a txn commits whole or rolls back). The rules are your tests.
  • 2 · Which idiom does the shape call for? See the picker table below.
  • 3 · What's the API? Name public methods + their types. Prefer dunders where container-/value-shaped. Signatures first — they encode the idiom choice.
  • 4 · Immutable or mutable? Frozen dataclass + replace for state transitions; plain class for stateful services.
  • 5 · Errors? Custom, data-carrying exceptions on rule violations; pytest.raises in tests. Raise loudly — never clamp or return a sentinel.
  • 6 · Tests first, then implement. Rules → edges (empty/missing/error) → concurrency where relevant. Then implement to green.

pytest Playbook (no plugin)

A test is a plain def test_*() that returns (pass) or raises AssertionError (fail). pytest rewrites assert to print both sides — no assertEqual, no unittest.TestCase.

def test_x():                 # auto-discovered
    assert got == want        # bare assert
with pytest.raises(CycleError): ...   # error paths
with pytest.raises(ValueError, match="boom"): ...
@pytest.mark.parametrize("a,b", [     # table cases
    ("=1+2*3", 7.0), ("=(1+2)*3", 9.0)])
def test_prec(a, b): ...

Deterministic time — inject a clock

class FakeClock:
    def __init__(self, t=0.0): self.t = t
    def advance(self, dt): self.t += dt
    def __call__(self): return self.t
kv = KVStore(clock=FakeClock())   # advance(), never sleep

Async with no plugin — the test IS the loop

def test_cap():                 # plain def, NOT async def
    seen = {"cur":0, "max":0}
    async def fetch(_):
        seen["cur"]+=1; seen["max"]=max(seen["max"],seen["cur"])
        await asyncio.sleep(0)  # bare yield, no real delay
        seen["cur"]-=1
    asyncio.run(gather_capped([fetch(u) for u in range(8)], 2))
    assert seen["max"] == 2     # cap saturated
  • Async: a coroutine does nothing till a loop runs it — call asyncio.run(main()) inside a normal test. No pytest-asyncio, no async def test_ (it just returns a never-awaited coroutine).
  • Assert the invariant (cap held, order preserved), never wall-clock timing. Drive order with asyncio.Event + await asyncio.sleep(0), released in reverse — deterministic.
  • Prove laziness of a generator with an input that raises if fully drained; next(gen) must return without tripping it.
  • Each kata is a package: from . import Sheet, CycleError. Run one: pytest solution/<kata> -q · filter -k name.

spreadsheet — Data Model + Lazy DFS

Idiom: data model + lazy recompute + DFS cycle detect. Cells hold a literal or "=A1+B2*3"; sheet["C1"] reads a computed value; empty reads 0.0.

class Sheet:
    def __setitem__(self, ref, content): ...  # store RAW
    def __getitem__(self, ref) -> float:  ...  # compute on read
    def __contains__(self, ref) -> bool:  ...
class CycleError(Exception): ...
  • Store raw content, compute nothing till read → "dependents update on edit" falls out free, no write-time DAG: editing A1 replaces its content; any formula naming A1 re-reads the new value next pull. Say the eager-DAG trade-off (fast reads, more bookkeeping, write-time cycle check), pick lazy.
  • Cycle guard = DFS visiting set threaded down recursion as a frozenset (visiting | {ref} for the deeper call, caller's set untouched — clean backtrack, no manual pop); a ref already in it is a back-edge → raise CycleError.
  • Precedence = structure: two-level recursive descent expr(+ -)→term(* /)→factor(number or recursive cell read). No table, no shunting-yard for four operators.
def _value(self, ref, visiting):
    if ref in visiting: raise CycleError(ref)   # back-edge
    c = self._cells.get(ref)
    if c is None: return 0.0                     # empty → 0
    if isinstance(c, float): return c            # literal
    return self._eval(c[1:], visiting | {ref})   # formula

! Gotcha: a recursion-depth limit gives RecursionError, not CycleError, and only after wasted work — thread the visiting set. And isinstance(x,int) lets bool through (True is an int): reject it, normalise numbers to float so division never truncates.

kvstore — Context-Manager Txns + TTL

Idiom: context managers + unit-of-work. Mini-Redis: set/get/delete, per-key TTL, and a transaction that commits whole or rolls back.

def set(k, v, ttl=None); def get(k)->v|None
def delete(k)->bool; __len__; __contains__
@contextmanager
def transaction(self): ...   # buffer→commit/rollback
  • Buffer-then-commit: while open, writes queue in a side dict, live store untouched → a read inside sees committed state (Redis MULTI). Clean exit replays atomically; a raise drops the buffer. Later writes to the same key overwrite in the buffer; commit is one deterministic replay.
  • Lazy TTL: stamp an absolute deadline (clock()+ttl, not a duration); one _live_entry helper prunes on access, shared by get/in/len. No sweeper thread — idle keys free, a big unread key lingers till touched.
  • Inject clock: Callable[[],float]=time.monotonic (monotonic can't jump back on an NTP step); tests advance a FakeClock.
@contextmanager
def transaction(self):
    if self._pending is not None: raise RuntimeError("nested")
    self._pending = {}
    try: yield
    except BaseException:
        self._pending = None; raise      # rollback + RE-RAISE
    else:
        buf, self._pending = self._pending, None
        self._commit(buf)                # atomic on clean exit

! Gotcha: the manager must roll back and re-raise — the generator's except: ...; raise (class form: __exit__ returns falsy). Returning True / not re-raising silently eats the caller's error. Also len/in must filter through liveness, not len(self._data) (counts expired-but-unpruned keys).

feedstats — Lazy Generators (OHLC+VWAP)

Idiom: generator (yield, O(1) memory) over an unbounded feed. Aggregate (ts,price,qty) ticks into fixed-window OHLC + VWAP bars; window = (ts // period) * period.

def bars(ticks: Iterable[Tick],
         period: int) -> Iterator[Bar]:
    # yield each bar the instant a later-window
    # tick proves it complete; flush tail at end
  • Generator not list: a return [...] reads the whole feed first (can't terminate on a live tape, buffers the session). yield is lazy, pull-based, O(1) — only the ~7 running scalars of the in-progress bar live.
  • One-tick look-ahead: a bar closes only when the next window's first tick arrives — that same tick flushes the old bar and seeds the new. No tick buffer.
  • VWAP is qty-weighted: Σ(price·qty)/Σqty (10@2, 20@1 → 40/3 ≈ 13.3, not 15). Carry two running sums.
  • OHLC: open=first, high=max, low=min, close=latest print; volume=Σqty.
for tick in ticks:
    w = (tick.ts // period) * period
    if start is None: ...seed...; continue
    if w != start:                      # boundary
        yield Bar(start,o,h,l,c,vol,wt/vol)
        ...re-seed from tick...; continue
    h=max(h,tick.price); l=min(l,tick.price)
    c=tick.price; vol+=tick.qty; wt+=tick.price*tick.qty
if start is not None:
    yield Bar(...)                      # TAIL FLUSH — mandatory

! Gotcha: the tail flush after the loop is mandatory — the last window never sees a later tick. And a generator defers its body: bars(x, 0) never runs the period<=0 guard — drive it with next(...); prove laziness with an input that raises if fully drained.

feedparser — Streaming + Error-as-Value

Idiom: generator + reject-as-data. Ingest edge: parse SYMBOL|BID|ASK|QTY lines from a firehose, skip # comments/blanks, never abort the batch on one bad line — yield each reject with its 1-based physical line number.

@dataclass(frozen=True)
class ParseError(Exception):   # a VALUE, not raised
    line: int; kind: ErrorKind
@dataclass(frozen=True)
class Parsed: line:int; quote:Quote|None; error:ParseError|None
def parse_feed(lines) -> Iterator[Parsed]: ...   # lazy
  • Error-as-value: a malformed line becomes a ParseError wrapped in a Parsed and yielded like any success — one bad venue print doesn't black out the market; the caller logs/alerts/halts.
  • Physical line numbers: enumerate(lines, start=1); comments/blanks continue after the counter advanced, so an error points at the real line in the raw capture.
  • Fixed validation order, first failure wins: field-count → empty-symbol → bid → ask → qty. A short line with a bad price is deterministically a WRONG_FIELD_COUNT.
  • qty: non-negative int — 0 is valid, negative rejected, int("1.5") raises → INVALID_QTY.
for line_no, raw in enumerate(lines, start=1):
    t = raw.strip()
    if not t or t.startswith("#"): continue   # counter moved
    f = t.split("|")
    if len(f) != 4:
        yield _error(line_no, WRONG_FIELD_COUNT); continue
    ...checks in order, continue at first fail...
    yield Parsed(line_no, Quote(...), None)

! Gotcha: skipping comments without advancing the counter mis-numbers every later reject. And raise on a bad line kills the good 999 — model the reject as a value and keep flowing. Extension: resumable across recv() chunks, holding a partial trailing line.

middleware — Decorators / Closures (Onion)

Idiom: higher-order fns + closures. compose([m1,m2,m3], handler) stacks layers: request in m1→m2→m3→h, response back out — m1 is outermost.

Handler    = Callable[[Request], Response]
Middleware = Callable[[Handler], Handler]  # +1 level
def compose(mws, handler) -> Handler:
    return functools.reduce(
        lambda nxt, mw: mw(nxt),
        reversed(mws), handler)
  • Type is the insight: a middleware is Handler→Handler (a closure over next_handler), not Request→Response (that's a handler). Stacking = function composition = a runtime @decorator stack applied to a value, not a name.
  • Fold direction: to make m1 outermost it must be applied last — so fold reversed(mws): wrap handler in m3, that in m2, that in m1. Fold forwards → onion inside-out (auth runs too late).
  • Short-circuit = just return Response(401) without calling next_handler; no exceptions/sentinels. Everything "inside" a layer only runs because next was called. Bracket the call to mutate request-in and response-out.
  • compose([], h) == h — fold of nothing returns the seed. Callable from collections.abc, not deprecated typing.

! Gotcha: a middleware that calls next_handler(req) but returns None silently drops the result — bracket it: r = next(req); ...; return r. Prove skip with calls == [], not just the status code. Async form is ASGI: await next_app(...), same fold.

crawler — asyncio Semaphore + gather

Idiom: asyncio bounded-concurrency fan-out. Fetch N URLs concurrently under a hard cap, retry transients, results in input order.

async def gather_capped(aws, limit):
    if limit <= 0: raise ValueError
    sem = asyncio.Semaphore(limit)
    async def run(aw):
        async with sem: return await aw
    return list(await asyncio.gather(
        *(run(a) for a in aws)))   # order kept
  • Single-threaded cooperative: one loop, one coroutine at a time; every await yields. No data races, no locks — between awaits nothing else touches your state.
  • Semaphore = the cap (permit pool sized to limit); the rest park on acquire(). gather preserves input order for free (positional) — no sorting, no as_completed. Plain gather propagates the first error + cancels siblings.
  • Retry: 1 + retries attempts; catch, retry, and let the last failure escape. Test both recover-then-succeed and exhausted-and-propagate.
  • fetch_all builds one retry-coroutine per url and delegates to gather_capped — inherits cap + order for nothing.

! Gotcha: asyncio gives overlapped I/O, not CPU parallelism — name the GIL (CPU-bound → multiprocessing). Awaiting in a for loop serialises. A bare gather over 10k urls exhausts FDs — the Semaphore is deliberate backpressure. Test order with asyncio.Event released in reverse, cap with max_seen == limit (not <=).

workflow — Enums + match/case (FSM)

Idiom: FSM as Enum + structural pattern matching. Order lifecycle; apply(order,event) is a pure fn over (state,event) — rows are the truth table.

def apply(order, event) -> Order:
  match (order.state, event):
    case (NEW, Accept()):  return replace(order, state=ACCEPTED)
    case (ACCEPTED | PARTIALLY_FILLED, Fill(qty=q)):
        nf = order.filled + q
        if nf > order.total: raise Overfill(...)
        st = FILLED if nf == order.total else PARTIALLY_FILLED
        return replace(order, state=st, filled=nf)
    case _: raise IllegalTransition(...)
  • State = Enum(auto()); order = @dataclass(frozen=True); one match tuple is the truth table. Class patterns destructure (Fill(qty=q)), OR-patterns merge rows sharing a rule.
  • Pure: every arm returns replace(order,…) — a new frozen value, input untouched. Same inputs → same output. Distinct Overfill vs IllegalTransition; raise, never clamp (clamping books a different quantity than the venue reported → real unhedged position).
  • Terminal states (FILLED/CANCELLED/REJECTED) are absorbing — every event from them raises.

! Gotcha: Python's match is not exhaustive — drop the case _ and an unhandled pair falls through returning None, silently corrupting state. Also case Fill: is a capture (matches anything, rebinds the name) — you need case Fill():. frozen=True only blocks attribute assignment, not a mutable field.

notifier — Protocols + Observer

Idiom: structural typing + Observer. Pub/sub: subscribe a channel to a topic (+optional filter); publish fans out in subscription order, publisher oblivious to who listens.

@runtime_checkable
class Channel(Protocol):
    def send(self, event: Event) -> None: ...
def subscribe(topic, channel, *, predicate=None)
def publish(event)          # walks per-topic list
  • Protocol = structural typing: a channel is anything with send — any plain class conforms with no base class / no import. Beats an ABC (which forces subclassing, locks out 3rd-party objects you don't own).
  • Storage: dict[str, list[_Subscription]] (subject holds observers). Filters are first-class Callable[[Event],bool] — pass a lambda, not a FilterChannel subclass.
  • Unknown topic = no-op via .get(topic, ()) (not [topic] → KeyError); keep a list for deterministic order, not a set.
def publish(self, event):
    for sub in self._subscribers.get(event.topic, ()):
        if sub.predicate is None or sub.predicate(event):
            sub.channel.send(event)   # dynamic dispatch, any conformer

! Gotcha: @runtime_checkable only checks a send attr exists — not its signature. The proving test: a bare class (no base) passing isinstance(it, Channel). Extensions: unsubscribe handle, async send + gather, per-channel retry.

filesystem — Recursion + Dunder

Idiom: tree data model + recursion. Nodes nest by absolute /-path: mkdir -p, write/read, ls, find, mv.

@dataclass class File: content: str
@dataclass class Dir: children: dict[str,Node] = ...
Node = File | Dir
def mkdir/write/read/ls/find/mv(...)
def __contains__(self, path) -> bool   # "/a/b" in fs
  • Model = tree of nodes (Dir holds name→child dict). Write _resolve (walk path, raise on missing node / file-where-dir) once; every op shares it, so the failure modes live in one place.
  • Subtree mv is free: a Dir node is its subtree — del from old parent, assign to new, done. No child copying (O(1) structural, not O(descendants)). find = DFS over the whole tree by basename, sorted.
  • Flat dict[path]=content alternative tempts you (one-lookup read/write) but makes ls a prefix scan and mv rewrite every descendant key. Tree pays a cheap path-walk on read to make ls/mv structural — name it, pick tree.
  • mkdir over an existing dir is a no-op (don't clobber children); over a file it raises.

! Gotcha: "/".split("/")==["",""] — filter blanks so "/"→[] and leading/double slashes don't leak empty components. Use __contains__ (try _resolve, except→False), not an exists() method.

Deep-dive: Generators (the streaming idiom)

Shared engine of feedstats & feedparser, and the extension of filesystem (walk()).

  • A fn containing yield returns an iterator; each yield emits one value and suspends the frame, resuming on the next next(). Control is inverted: the consumer pulls.
  • O(1) memory — only the current item's state lives; contrast return [...] which buffers everything and must read the whole input first (fatal on an unbounded source).
  • Lazy = deferred body: nothing runs until the first next(). So a guard like if period<=0: raise at the top does not fire on the bare call — only when driven. Test guards with next(...).
  • Composes with for, itertools.islice (take N), groupby, takewhile — all still lazy. An early break stops the producer mid-stream.
  • State-machine pattern: hold the minimum running state, emit on a boundary, flush the tail after the loop (the last window/record has no successor to trigger it).
def take(gen, n):                 # first n, lazily
    return list(itertools.islice(gen, n))
def proof_of_lazy():
    def s():
        yield "a"
        raise AssertionError("drained — not lazy")
    assert next(parse_feed(s())).quote is not None

Extensions: yield from delegation · async generators over a socket · rolling-VWAP stacked on bars.

@contextmanager
def txn(self):
    self._pending = {}
    try: yield
    except BaseException:

  • ! Returning True / not re-raising silently eats the caller's error — the classic bug. Rollback and propagation are separate obligations; do both.
  • Reach for the class form when the manager must carry per-level state (nested txns / savepoints); the generator is cleaner for linear teardown.

Deep-dive: asyncio & the GIL

  • Cooperative, single-threaded: one event loop runs one coroutine at a time. Concurrency = overlapped waiting, not parallel execution. Two CPU-heavy coroutines run no faster than sequentially.
  • Every await is a yield point where the loop can run another coroutine. Between awaits you run uninterrupted → no locks needed for plain state. A coroutine that never awaits starves the loop.
  • asyncio.Semaphore(limit) = permit pool; async with sem: holds one for the wrapped await's duration → backpressure. Contrast a Queue + fixed worker pool for true producer/consumer backpressure.
  • gather returns results positionally (input order) despite out-of-order completion; propagates the first exception and cancels siblings. return_exceptions=True collects per-item instead. Use as_completed only when you want results as they land.
  • The GIL: CPython runs one thread of bytecode at a time → asyncio/threads help only I/O-bound work. CPU-bound → multiprocessing/ProcessPoolExecutor; blocking libs → run_in_executor (thread pool).
async with asyncio.timeout(2):   # 3.11+, per-op deadline
    return await fetch(url)
async with asyncio.TaskGroup() as tg:   # structured
    tasks = [tg.create_task(run(a)) for a in aws]

! The senior tell is reaching the GIL boundary unprompted: "this only helps because fetching is I/O-bound."

match/case pitfalls

  • ! Not exhaustive — a missing arm returns None, silently. A case _ is load-bearing, turning "unhandled" into a loud error.
  • case Fill: is a capture (matches anything, rebinds Fill). You want case Fill(): — parentheses make it a class pattern (a type test).
  • Fill(qty=q) destructures + binds the payload. A | B OR-pattern collapses rows sharing a rule. match (state, event): matches the tuple.

Typestate alternative

Give each state its own type (NewOrder.accept()→AcceptedOrder, no fill method) so illegal transitions fail to type-check — statically impossible, but explodes into N classes. Reach for the single-fn match first.

Frozen dataclasses + replace

@dataclass(frozen=True)
class Order: state: OrderState; total: int; filled: int = 0
new = replace(order, state=ACCEPTED)   # new value, input untouched
  • Frozen → hashable, no field assignment; the functional way to "transition". Pure fns become trivial to test and safe to share/log.
  • ! frozen=True is shallow — a mutable field (a list) is still mutable. Use field(default_factory=dict) — never a mutable default arg.
  • Model closed sets with Enum(auto()): typo-proof, iterable, compare with is. Distinct data-carrying exceptions per rule violation.

Typing You Must Write (senior default)

  • Unions: X | None (not Optional[X]), File | Dir. Builtins as generics: list[str], dict[str, Node], tuple[int, ...] — not List/Dict from typing.
  • Callable, Iterable, Iterator, Awaitable from collections.abc — the typing aliases are deprecated since 3.9.
  • Program to the protocol: accept Iterable[Tick] (a list, file, socket, another generator), return Iterator[Bar] — not concrete types.
  • from __future__ import annotations to reference a type before it's defined (forward refs) cheaply.
  • Callable[[Request], Response], Callable[[Event], bool] — first-class functions get full signatures.

★ Senior Signals & Pre-flight Checklist

Cross-cutting tells

  • Purity/immutability: frozen dataclass + replace for transitions; never mutate the input.
  • Determinism: inject a clock, advance a FakeClock / drive with asyncio.Event — never time.sleep.
  • Errors raise loudly: custom, data-carrying exceptions on rule violations; test with pytest.raises. Distinguish kinds (Overfill vs IllegalTransition).
  • Typed throughout: X | None, list[str], Callable from collections.abc.
  • Name the trade-off out loud (lazy vs eager, tree vs flat, Protocol vs ABC, generator vs list), then pick — the framing is the signal.
