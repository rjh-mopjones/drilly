Method & Testing (pytest, no plugin)

  • ! the load-bearing gotcha for each kata   the senior tell is idiom fluency under a real scenario.
  • Scope: 8 katas from a blank file. The hard part is rarely the algorithm — it's modelling the system with the right Python idiom: data model, generator, context manager, decorator, asyncio, Protocol, or match?
  • The prompt's shape picks the tool: container→dunders · stream→generator · acquire/release→context mgr · wrap→decorator · I/O concurrency→asyncio · pluggable→Protocol · states→enum+match.
  • Loop: clarify the rules → design the class/fn API (dunders where container/value-shaped) → write pytest tests first → implement. Full type hints (X | None, list[str]) are part of the answer.

pytest model

def test_x():                 # plain fn, auto-discovered
    assert got == want        # bare assert; prints both sides
with pytest.raises(CycleError): ...        # error paths
@pytest.mark.parametrize("a,b", [...])     # table cases
  • Async, no plugin: a coroutine does nothing till a loop runs it — the test is the loop: def test_x(): asyncio.run(main()). No pytest-asyncio, no async def test_.
  • Determinism: never time.sleep — inject a FakeClock you advance(); for async drive with asyncio.Event + await asyncio.sleep(0) (bare yield). Assert the invariant (cap held, order preserved), not timing.
  • Each kata is a package: from . import Sheet, CycleError. Run one: pytest solution/<kata> -q.

spreadsheet — Data Model + Lazy DFS

Idiom: data model + lazy recompute + DFS cycle detect. Cells hold a literal or "=A1+B2*3"; sheet["C1"] reads a computed value; empty reads 0.0.

class Sheet:
    def __setitem__(self, ref, content): ...  # store RAW
    def __getitem__(self, ref) -> float:  ...  # compute on read
    def __contains__(self, ref) -> bool:  ...
class CycleError(Exception): ...
  • Idiom: store raw content, compute nothing till read → "dependents update on edit" falls out free, no write-time DAG. Say the eager-DAG trade-off, pick lazy.
  • Cycle guard = DFS visiting set threaded down recursion (a frozenset, visiting | {ref}); a ref already in it is a back-edge → raise CycleError.
  • Precedence = structure: two-level expr(+ -)→term(* /)→factor recursive descent. No table.

! Gotcha: a recursion-depth limit gives RecursionError, not CycleError, and only after wasted work — thread the visiting set. And isinstance(x,int) lets bool through (it's an int): reject it, normalise to float.

kvstore — Context-Manager Transactions + TTL

Idiom: context managers + unit-of-work. Mini-Redis: set/get/delete over strings, per-key TTL, and a transaction that commits whole or rolls back.

def set(k, v, ttl=None); def get(k)->v|None
def delete(k)->bool; __len__; __contains__
@contextmanager
def transaction(self): ...   # buffer→commit/rollback
  • Buffer-then-commit: while open, writes queue in a side dict, live store untouched → a read inside sees committed state (Redis MULTI). Clean exit replays atomically; a raise drops the buffer.
  • Lazy TTL: stamp an absolute deadline (clock()+ttl); one _live_entry helper prunes on access, shared by get/in/len. No sweeper thread.
  • Inject clock: Callable[[],float]=time.monotonic; tests advance a FakeClock.

! Gotcha: the manager must roll back and re-raise — the generator's except: ...; raise (or __exit__ returning falsy). Returning True / not re-raising silently eats the caller's error. Also len/in must filter through liveness, not len(self._data).

feedstats — Lazy Generators

Idiom: generator (yield, O(1) memory) over an unbounded feed. Aggregate (ts,price,qty) ticks into fixed-window OHLC + VWAP bars.

def bars(ticks: Iterable[Tick],
         period: int) -> Iterator[Bar]:
    # yield each bar the instant a later-window
    # tick proves it complete; flush tail at end
  • Generator not list: a return [...] reads the whole feed first (can't terminate on a live tape). yield is lazy, pull-based, O(1) — only the in-progress bar's running scalars live.
  • One-tick look-ahead: a bar closes only when the next window's first tick arrives — that same tick flushes the old bar and seeds the new. No tick buffer.
  • VWAP is qty-weighted: Σ(price·qty)/Σqty (10@2, 20@1 → 40/3, not 15).

! Gotcha: the tail flush after the loop is mandatory — the last window never sees a later tick. And a generator defers its body: bars(x, 0) never runs the period<=0 guard — drive it with next(...); prove laziness with an input that raises if fully drained.

middleware — Decorators / Closures (Onion)

Idiom: higher-order fns + closures. compose([m1,m2,m3], handler) stacks layers: request in m1→m2→m3→h, response back out — m1 is outermost.

Handler    = Callable[[Request], Response]
Middleware = Callable[[Handler], Handler]  # +1 level
def compose(mws, handler) -> Handler:
    return functools.reduce(
        lambda nxt, mw: mw(nxt),
        reversed(mws), handler)
  • Type is the insight: a middleware is Handler→Handler (a closure over next_handler), not Request→Response. Stacking = function composition = a runtime @decorator stack.
  • Short-circuit = just return Response(401) without calling next_handler; no exceptions/sentinels. Bracket the call to mutate request-in and response-out.

! Gotcha: fold reversed(mws) so m1 ends up outermost — folding forwards silently inverts the onion (auth runs too late). Prove skip with calls == [], not just the status code.

crawler — asyncio Semaphore + gather

Idiom: asyncio bounded-concurrency fan-out. Fetch N URLs concurrently under a hard cap, retry transients, results in input order.

async def gather_capped(aws, limit):
    sem = asyncio.Semaphore(limit)
    async def run(aw):
        async with sem: return await aw
    return list(await asyncio.gather(
        *(run(a) for a in aws)))   # order kept
  • Single-threaded cooperative: one loop, one coroutine at a time; every await yields. No data races, no locks — between awaits nothing else touches your state.
  • Semaphore = the cap (permit pool sized to limit); gather preserves input order for free (positional) — no sorting, no as_completed. Plain gather propagates the first error + cancels siblings.
  • Retry wrapper: 1 + retries attempts; last failure escapes.

! Gotcha: asyncio gives overlapped I/O, not CPU parallelism — name the GIL (CPU-bound → multiprocessing). Awaiting in a for loop serialises; test order with asyncio.Event released in reverse, not sleeps.

workflow — Enums + match/case

Idiom: FSM as Enum + structural pattern matching. Order lifecycle; apply(order,event) is a pure fn over (state,event).

def apply(order, event) -> Order:
  match (order.state, event):
    case (NEW, Accept()):  return replace(...)
    case (ACCEPTED | PARTIALLY_FILLED, Fill(qty=q)): ...
    case _: raise IllegalTransition(...)
  • State = Enum; order = @dataclass(frozen=True); one match tuple is the truth table. Class patterns destructure (Fill(qty=q)), OR-patterns merge rows.
  • Pure: every arm returns replace(order,…) — a new frozen value, input untouched. Distinct Overfill vs IllegalTransition; raise, never clamp.

! Gotcha: Python's match is not exhaustive — drop the case _ and an unhandled pair falls through returning None, silently corrupting state. Also case Fill: is a capture (matches anything) — you need case Fill():.

notifier — Protocols + Observer

Idiom: structural typing + Observer. Pub/sub: subscribe a channel to a topic (+optional filter); publish fans out in subscription order.

@runtime_checkable
class Channel(Protocol):
    def send(self, event: Event) -> None: ...
def subscribe(topic, channel, *, predicate=None)
def publish(event)          # walks per-topic list
  • Protocol = structural typing: a channel is anything with send — any plain class conforms with no base class / no import. Beats an ABC (which forces subclassing, locks out 3rd-party objects).
  • Storage: dict[str, list[_Subscription]] (subject holds observers). Filters are first-class Callable[[Event],bool] — pass a lambda, not a subclass.
  • Unknown topic = no-op via .get(topic, ()); keep a list for deterministic order.

! Gotcha: @runtime_checkable only checks a send attr exists — not its signature. The proving test: a bare class (no base) passing isinstance(it, Channel).

filesystem — Recursion + Dunder

Idiom: tree data model + recursion. Nodes nest by absolute /-path: mkdir -p, write/read, ls, find, mv.

@dataclass class File: content: str
@dataclass class Dir: children: dict[str,Node] = ...
Node = File | Dir
def mkdir/write/read/ls/find/mv(...)
def __contains__(self, path) -> bool   # "/a/b" in fs
  • Model = tree of nodes (Dir holds name→child dict). Write _resolve (walk path, raise on missing / file-where-dir) once; every op shares it.
  • Subtree mv is free: a Dir node is its subtree — del from old parent, assign to new, done. No child copying. find = DFS over the whole tree by basename.

! Gotcha: the flat dict[path] tempts you (easy read/write) but makes ls a prefix scan and mv rewrite every descendant key. Also "/".split("/")==["",""] — filter blanks so "/"→[]. Use __contains__, not exists().

Cross-cutting senior tells

  • Purity/immutability: frozen dataclass + replace for transitions; never mutate the input.
  • Determinism: inject a clock, advance a FakeClock / drive with asyncio.Event — never time.sleep.
  • Errors raise loudly: custom, data-carrying exceptions on rule violations; test them with pytest.raises.
  • Typed throughout: X | None, list[str], Callable from collections.abc (not deprecated typing).
  • Name the trade-off out loud (lazy vs eager, tree vs flat, Protocol vs ABC), then pick — the framing is the signal.
