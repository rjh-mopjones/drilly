Bias-Variance

error = bias^2 + variance + irreducible
  • Bias = too simple → underfit (train & val both bad).
  • Variance = too complex → overfit (train good, val bad). !
  • Diagnose from the train/val gap. More capacity ↓bias ↑variance.

Regularization

PenaltyEffect
L2 / Ridgesum(w^2)shrink, no zeros
L1 / Lassosum(|w|)sparse (feature select)
  • Also: dropout, early stopping, data augmentation.
  • Trades a little bias for less variance; pick strength by CV.

Cross-Validation

  • k-fold: rotate the val fold, average (beats one split).
  • Stratified (keep class ratios); time-series CV (never train on the future). !
  • Nested CV: inner tunes, outer estimates.
  • ! Golden rule: touch the test set once, at the end.

Classification Metrics

precision = TP/(TP+FP)   recall = TP/(TP+FN)
F1 = 2*P*R/(P+R)
  • ! Accuracy lies under imbalance (99% by predicting majority).
  • Threshold trades precision vs recall; ROC-AUC (balanced) vs PR-AUC (rare positives).
  • Cost of FP vs FN picks the metric (fraud/cancer → recall).

Regression Metrics

RMSE = sqrt(mean((y-yhat)^2))   # outlier-sensitive
MAE  = mean(|y-yhat|)           # robust
R2   = 1 - SS_res/SS_tot

Rank (search/recsys): NDCG, MAP, MRR. Match metric to the objective.

Feature Engineering

  • Categoricals: one-hot (low card) / target-encode (high card, ! leakage).
  • Scale for distance/gradient models (kNN, SVM, linear, NN); trees don't care.
  • Interactions, text (TF-IDF), date/geo features.
  • Select: filter (corr/MI) / wrapper (RFE) / embedded (L1, tree). Features > model.

Data Leakage

  • ! Model sees at train what it won't at predict → great offline, dead in prod.
  • Target leak (feature encodes/follows the label), temporal (future info), preprocessing on full data, group leak.
  • Tell: too-good metrics. Fix: split first, fit preprocessing inside CV folds; ask "known at predict time?".

Imbalanced Data

  • Resample (SMOTE / under), class weights, tune threshold.
  • Use F1 / PR-AUC, not accuracy.
  • Missing: impute + indicator; outliers: clip/robust.

Gradient Descent

w := w - lr * grad(loss)
  • Batch (stable/slow) / SGD (noisy/fast) / mini-batch (default).
  • ! LR too big → diverge; too small → crawl. Momentum / Adam.
  • Convex (linear/logistic) vs non-convex (NN: local minima, saddles).

Interpretability & Practice

  • Global vs local; coefficients, permutation importance, SHAP / LIME, PDP.
  • ! Baseline first; simplest model that works.
  • Watch train/serve skew & drift → monitor + retrain.
  • 80% of ML is data; reproducibility (seed + version).

☐ Interview Playbook

  • ☐ Frame: task, data, baseline, metric, validation, deploy/monitor.
  • ☐ "Train 99% / val 70%" → overfit → more data / regularize / less capacity.
  • ☐ "99% accuracy, useless" → imbalance → precision/recall/PR-AUC.
  • ☐ "Great offline, bad in prod" → leakage / train-serve skew / drift.
  • ☐ Pick metric from FP-vs-FN cost.
  • ☐ Spot leakage: is every feature known at prediction time?
  • ☐ Tabular? try GBM. Scale for kNN/SVM. Try the linear baseline first.
