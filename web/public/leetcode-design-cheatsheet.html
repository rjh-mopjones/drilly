  • Each card: problem → structure → invariant → ops complexity → template → trap. Full solutions (Py/Java/Rust/Go/C++) live in the primer.
  • Print: Ctrl/⌘-P → A4, margins None, scale 100%, background graphics on. 4 columns built-in.

The Design Method

  • 1. Clarify ops + target: write each method's required complexity (O(1)? O(log n)? amortized?). The target dictates the structure — an O(1) requirement usually rules out heaps/BSTs.
  • 2. Pick structure from the quick-pick table. Almost every "all O(1)" design = hashmap + a second structure (DLL / array / bucket list) kept in sync.
  • 3. State the invariant maintained between calls — the sentence you'd say out loud ("list is in MRU→LRU order", "heaps differ by ≤1", "buckets sorted by count").
  • 4. Edge cases: empty, single element, at capacity/full, duplicate keys, wraparound, get-on-missing-key.
  • ! If two ops each demand O(1) and one is "min/max", you almost never use a heap — reach for bucketed DLL or index tricks.

LRU Cache (#29)

Structure: hashmap key→node + doubly linked list. Invariant: DLL ordered MRU(head)→LRU(tail); map points into it. get/put O(1).

class Node: key,val,prev,next
head<->tail sentinels
get(k):  if miss -1; move node to front; ret val
put(k,v):if hit update+move front
         else add front; map[k]=node
         if len>cap: evict tail.prev; del map[key]

! Update recency on get too, not just put. ! Use sentinel head/tail so add/remove never null-check. Stdlib shortcut: Py OrderedDict.move_to_end/popitem(last=False), Java LinkedHashMap(cap,0.75,true) + override removeEldestEntry.

LFU Cache (#30)

Structure: key→node, key→freq, and freq→DLL of nodes at that freq, plus minFreq. Invariant: each freq bucket ordered LRU within the freq; ties broken by recency. get/put O(1).

touch(k): f=freq[k]; move node freq[f]->freq[f+1]
          if freq[f] empty && minFreq==f: minFreq++
put full: evict LRU of freq[minFreq]
new key:  freq=1; minFreq=1

! On insert reset minFreq=1. ! Evict the LRU node of the lowest freq — need per-freq ordering, not just per-freq set. Empty a bucket → bump minFreq only if it was the min.

All O(1) — inc/dec/max/min (#24)

Structure: DLL of count-buckets (each bucket = count + set of keys) + key→bucket map. Invariant: buckets sorted by count → head=min, tail=max, both O(1). Heap is banned (O(log n)).

inc(k): c=bucket[k].count; move to c+1 bucket
        (splice new bucket after if neighbor!=c+1)
dec(k): move to c-1 (remove key if c==1)
        unlink any bucket that becomes empty
getMax: tail.prev.anyKey   getMin: head.next.anyKey

! Always unlink emptied buckets or min/max drift. Check the neighbor bucket's count before splicing a new one.

Insert/Delete/GetRandom O(1) (#22–23)

Structure: dynamic array vals[] + map val→index. Invariant: array is dense (no gaps) so random = uniform index. All ops O(1).

insert(v): if v in map ret false
           map[v]=len; vals.append(v)
remove(v): i=map[v]; last=vals[-1]
           vals[i]=last; map[last]=i    # swap-with-last
           vals.pop(); del map[v]
getRandom: vals[rand(0,len-1)]

Duplicates variant (#23): map value→set of indices; on remove pick any index, swap-with-last, fix the moved element's index set. ! Swap-with-last is the whole trick — a plain array delete is O(n).

Min / Max Stack (#1–2)

Min Stack: second stack of running mins (or store (val, curMin) pairs). Every op O(1).

push(x): st.push(x); mins.push(min(x, mins.top or x))
pop():   st.pop(); mins.pop()
getMin():mins.top

Max Stack (#2) also needs popMax(): main stack + a TreeMap/balanced BST value→count → O(log n) popMax (pop-and-repush the values above it). ! Duplicates: store counts, not a set. Don't confuse the O(1) Min Stack with the O(log n) Max Stack.

Stacks & Queues via Each Other

Queue via 2 stacks (#3)in-stack + out-stack; pour in→out only when out empty. Amortized O(1).
Stack via queues (#4)on push, enqueue then rotate n-1 → newest at front. push O(n), pop O(1).
Circular Queue/Deque (#5,6)fixed array + head/tail mod cap; track size to tell full from empty.
Front-Mid-Back Q (#7)two deques, rebalance so left.size∈{right, right+1}.
Stack w/ Increment (#8)stack + lazy inc[] delta array; apply on pop.
Online Stock Span (#9)monotonic stack of (price, span); pop ≤ current, sum spans.

! Two-stack queue is O(1) amortized, not worst-case — say "amortized" aloud. ! Circular buffer: reserve a size counter or one empty slot to disambiguate full vs empty.

Iterators — Lazy Traversal

Rule: do work in next()/hasNext(), never eager-flatten in the constructor (that's O(n) space and defeats the point).

BST Iterator (#12)explicit stack, push-left chain; next=pop+push-right's-left. O(h) space, amort O(1).
Peeking Iterator (#13)cache one lookahead element + hasPeeked flag.
Nested List (#14)stack of iterators; peel integers lazily in hasNext.
Zigzag (#16)queue of active sub-iterators, round-robin, drop empties.
Flatten 2D (#15)row+col cursors; advance past empty rows in hasNext.
RLE / Compressed (#17,40)index into (count,val) pairs, decrement remaining.
Combination (#18)bitmask / next-combination in lex order.

! BST iterator: the invariant is "stack top = next smallest". ! Put the skip-empties logic in hasNext, and make next call it first.

Linked List · History · Editor

Design Linked List (#10)sentinel head, walk by index; track size for bounds.
Browser History (#11)array + cursor; visit truncates forward stack. back/forward clamp by steps.
Text Editor (#19)two stacks split at cursor (gap buffer): left holds text before cursor, right after. move/insert/delete = shuffle between stacks, all O(moved).

! Browser visit must discard everything after the cursor. ! Editor: cursor moves are O(k) for k chars moved — a StringBuilder gives O(n) deletes, the two-stack gap buffer gives O(1) at the cursor.

Design HashMap / HashSet (#20–21)

Structure: fixed array of buckets + separate chaining (linked list / list per bucket). Invariant: a key lives in bucket hash(key) % B. Avg O(1), worst O(n/B).

put(k,v): b=buckets[k%B]; find node → update else append
get(k):   scan bucket b for k
remove(k):unlink from bucket list

Pick B prime-ish (e.g. 769) to spread hashes. ! Interviewers want the collision strategy stated (chaining vs open addressing) — don't just wrap the language map.

Tries & Prefix Search

Structure: node = children map (26-array or dict) + isEnd. Invariant: path from root spells the prefix; isEnd marks a full word.

insert(w): node=root; for c: node=node.child[c] or new; node.isEnd=true
search(w): walk; return node && node.isEnd
startsWith(p): walk; return node!=null
Add/Search Words (#34)trie + DFS branching on . wildcard.
Magic Dictionary (#35)DFS allowing exactly one char mismatch.
Stream of Characters (#36)trie of reversed words; match a growing suffix of the stream (keep last L chars).
Autocomplete (#39)trie + top-3 by frequency (heap/sort at node).
In-Memory FS (#41)trie of dir/file nodes (name→node).

! Stream-of-chars: reversing words lets you match against the reversed recent stream — otherwise you'd re-scan every prefix.

Encode/Decode · TinyURL

Encode Strings (#37): length-prefix each string: len#payload. Invariant: decode reads a number up to #, then exactly that many chars — unambiguous for any payload.

encode: ''.join(f"{len(s)}#{s}" for s in strs)
decode: read digits→n, skip '#', take n chars, repeat

! A plain delimiter (comma/space) breaks when the payload contains it — length-prefix is the correct answer. TinyURL (#38): two maps long↔short + counter or random 6-char base62 code; check collision on random.

Serialize / Deserialize Trees

Binary Tree (#42)preorder with null markers ("#"); rebuild by consuming the same order (queue/index).
BST (#43)preorder only, no nulls — BST bounds (min,max) reconstruct shape. More compact.
N-ary (#44)preorder + child-count per node (or null sentinel after each child list).
# binary tree
ser(n): "#" if !n else f"{n.val},{ser(L)},{ser(R)}"
des():  v=next; if v=="#" ret null; node; node.L=des(); node.R=des()

! BST trick: don't emit nulls — use value bounds while rebuilding. ! Keep a single cursor/queue so left subtree fully consumes before right.

Heaps — Median · Top-K · Streams

Median from Stream (#45): max-heap low + min-heap high. Invariant: every low ≤ every high, and |low|−|high|∈{0,1}. median = low.top or avg of tops. add O(log n).

add(x): low.push(x); high.push(low.pop())     # funnel
        if high>low: low.push(high.pop())     # rebalance
Kth Largest Stream (#46)size-k min-heap; top = kth largest; push+pop if over k.
Stock Price Fluct (#47)map ts→price + max-heap + min-heap with lazy deletion of stale entries.
Food Rating (#48)per-cuisine heap/TreeSet by (−rating, name); lazy-skip stale.

! Median: rebalance every insert; funnel-through the other heap to keep them ordered. ! Kth-largest wants a min-heap of size k, not a max-heap.

Lazy-Delete Heaps & Leaderboards

Pattern: heaps have no decrease-key/remove. When a value changes, push the new entry and mark the old stale; on top(), discard heap-tops that disagree with the authoritative map. Amortized O(log n).

top(): while heap.top disagrees with map[key]: pop
       return heap.top
Leaderboard (#49)map player→score; top(K)=heapify/sort the K largest scores.
Graph Shortest Path (#50)adjacency list + Dijkstra per query (heap), or Floyd-Warshall if dense/many queries.

! Lazy delete grows the heap with dead entries — fine for amortized bounds, but state it. Keep the map as source of truth.

Versioned · Sparse · Bitset

Snapshot Array (#27)per-index list of (snapId,val); get=binary search ≤ snapId. snap() just bumps a counter — O(1). ! don't copy the whole array per snap.
Number Container (#25)map idx→num + num→sorted set of idx; find=min idx for that num.
Phone Directory (#26)free-set / queue of available slots + released set.
Bitset (#28)bit array + a flip flag; flipAll toggles the flag in O(1), reads XOR it.

! Bitset: track ones count so all/one are O(1); on flipAll, ones = n − ones.

Time · Rate Limit · Calendar

Logger Rate Limiter (#51)map msg→next-allowed ts; allow iff t ≥ next.
Hit Counter (#52)queue of timestamps; evict > 300s old on each op.
Moving Average (#53)fixed ring buffer + running sum; O(1).
Calendar I (#54)TreeMap start→end; check floor/ceiling neighbor overlap. O(log n).
Calendar II (#55)keep booked + overlaps lists; reject if new hits an overlap.
Calendar III (#56)difference map: +1 at start, −1 at end; answer = running max of prefix sums.
Auth Manager (#57)map token→expiry; renew resets, lazy-expire on read.
ATM (#58)5 denom counts; greedy largest-first with a dry-run before committing.

! Calendar III: the diff-array + running max is the clean k-booking pattern (a TreeMap of deltas keeps it ordered). ! ATM: dry-run first — never partially dispense then fail.

Range Sum — Prefix vs BIT vs SegTree

Immutable 1D (#67): prefix array, sum(i,j)=P[j+1]−P[i], query O(1). Mutable 1D (#68): Fenwick (BIT) — update & query O(log n).

# Fenwick (1-indexed)
update(i,d): for(;i<=n;i+=i&-i) t[i]+=d
query(i):    for(s=0;i>0;i-=i&-i) s+=t[i]; ret s
rangeSum(l,r)=query(r)-query(l-1)
2D Immutable (#69)2D prefix sums, inclusion-exclusion; query O(1).
2D Mutable (#70)2D BIT; update & query O(log m·log n).

! Prefix sums = static only; a single point update forces O(n) rebuild — switch to BIT/segtree once updates appear. BIT indices are 1-based.

Memory Allocator · Skiplist · Excel

MRU Queue (#31)Fenwick / sqrt-decomposition for O(√n) or O(log n) fetch-to-front.
Memory Allocator (#32)array of mIDs (0=free); allocate scans for a run of size, free clears an id.
Skiplist (#71)randomized multi-level linked list; coin-flip level on insert. search/add/erase O(log n) expected — simpler code than a balanced BST.
Excel Sum Formula (#72)cell dependency graph; set clears formula, sum stores deps + topologically recomputes dependents.

! Skiplist: cap max level (~16); update-pointer array per level on insert/delete. ! Excel: a set on a formula cell must break its old dependencies.

OO Systems & Games

Design Twitter (#59)follow map + per-user tweet list (with global tick); feed = merge k followees' latest via heap, take 10.
Underground System (#60)checkIn map id→(station,t) + (start,end)→(totalTime,count) for O(1) average.
Parking System (#61)3 size counters, decrement on park.
Snake Game (#62)deque body + set for O(1) self-collision; pop tail before checking (unless eating).
Tic-Tac-Toe (#63)row/col/diag/anti counters +1/−1 per player; win when |count|==n.
Movie Rental (#64)maps + per-movie TreeSet(price,shop) available + global rented TreeSet.
Video Platform (#65)id recycler (min-heap of freed ids) + per-video stat maps.
Todo List (#66)per-user tasks; filter by tag, sort by due date.

! Twitter: don't merge all tweets — heap only the k followees' newest. ! Snake: check collision after removing the tail, or a straight follow-the-tail move false-triggers.

★ Interview Playbook

  • ☐ Restate the ops + each op's target complexity before coding.
  • ☐ Name the structure out loud + why it hits the target.
  • ☐ O(1) get/put/evict → hashmap + DLL (LRU); order-by-freq → freq-bucket DLLs (LFU).
  • ☐ O(1) insert/delete/random → array + index map, swap-with-last.
  • ☐ O(1) min/max + inc/dec → sorted count-bucket DLL, not a heap.
  • ☐ Running median → two heaps, rebalanced every insert; top-of-stream → size-k min-heap.
  • ☐ Prefix / ordered / bounds → trie or TreeMap/BST.
  • ☐ Range sum: static → prefix; with updates → BIT/segtree (1-indexed).
  • ☐ Overlap/booking → TreeMap neighbors or diff-array sweep + running max.
  • ☐ Iterators: lazy — work in next()/hasNext(), never the constructor.
  • ☐ Encode: length-prefix, never a bare delimiter.
  • ☐ State the invariant held between calls; then edges: empty, full, dup, wraparound, missing key.
  • ☐ Mention the stdlib shortcut (OrderedDict, LinkedHashMap, TreeMap, heapq, SortedList) but be ready to hand-roll it.
