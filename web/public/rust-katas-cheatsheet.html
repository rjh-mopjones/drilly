Attack Plan — Ownership First

Turn the prompt into an ownership plan before writing logic. The borrow checker is a design partner, not an adversary — a borrow error means two things want the same data; the fix is a design choice.

The loop, every kata

  • 1. Clarify the spec → they're really ownership questions (who keeps the bytes? does a read mutate?).
  • 2. Design the API ownership-first — who owns / move vs &/&mut / lifetime 'a? / dyn vs generic? Write signatures + key types; they encode every decision.
  • 3. Write the inline #[test]s first — contract → core → edges → concurrency stress.
  • 4. Implement to compile and pass. The compile is the design proof.
  • 5. State complexity + the one gotcha you dodged.

Receiver decides the API !

fn get(&mut self, k: &K) -> Option<&V>
// &mut: a cache hit reorders recency → a read IS a write.
// Getting the receiver right up front avoids a rewrite.

Errors: a custom enum Error + Result + ?, never panics (panics only for genuine bugs / #[should_panic]).

! The naive DLL wants two owners per node (prev+next) — safe Rust allows one. The idiomatic fix is indices, not pointers:

slab: Vec<Node<V>>,   // arena owns all nodes
map:  HashMap<K, usize>, // idx, NOT a reference
free: Vec<usize>,      // recycle slots on evict

! Rc<RefCell<Node>> for a linked list compiles — that's the seduction — then borrow_mut() panics at runtime + refcount tax. Prefer the arena.

The Rust Concurrency Twist

Data races DON'T COMPILE. A bare i64 shared across threads fails the borrow checker: &mut can't cross a thread boundary, & can't mutate. Only Sync types share by &; Send types move across threads. So there is no "prove the race" exercise — the compiler deleted that bug class for free.

The bugs that survive safe code !

BugFix
Lost update — split read-modify-write across two .lock() callshold the guard across the RMW: *g += q
Deadlock — two locks, opposite orderglobal lock order (e.g. smaller symbol first)
Channel discipline — lost jobs / no shutdowndrop sender → recv errs → workers join
UB in unsafe — bad ordering / aliasingwritten // SAFETY: + Miri

"Rust is safe" means no data race / UB in safe code — deadlock, lost update, and unsafe UB are still on you. Say that unprompted.

! Miri is the UB detector (cargo +nightly miri test) — the -race/TSan analogue. A green cargo test proves nothing about unsafe soundness.

Concurrency Test Harness

No sleeps (flaky coin-flips). Gate threads with a Barrier inside thread::scope, then assert an invariant — conservation, exactly-once, no-deadlock — never an exact interleaving.

#[test]
fn concurrent_transfers_conserve() {
    let book = PositionBook::new();
    book.set("a", 1000); book.set("b", 1000);
    let n = 8;
    let gate = std::sync::Barrier::new(n);
    std::thread::scope(|s| {
        for _ in 0..n {
            s.spawn(|| {
                gate.wait();          // release together → max contention
                for _ in 0..10_000 {
                    book.transfer("a","b",1);
                    book.transfer("b","a",1);
                }
            });
        }
    }); // scope auto-joins → borrow locals, no Arc
    assert_eq!(book.net("a")+book.net("b"), 2000);
}
  • scope joins all threads before returning, so spawned closures borrow locals (&book) — no Arc, no 'static.
  • Barrier::new(n).wait() is the start-gate: every thread blocks until all N arrive.
  • A deadlock hangs the test (never returns) — that's the failure signal, not a red assert.
  • For unsafe: cargo +nightly miri test proves the ordering/aliasing.

Testing Toolkit

No third-party framework — #[test] + cargo test, std-only. Tests live inline in the same file as the code.

#[cfg(test)]
mod tests {
    use super::*;                    // reach the code

    #[test]
    fn parses() -> Result<(), ParseError> {
        let cases = [                 // table-driven
            ("AAPL,101.5,200", ("AAPL",101.5,200)),
            ("MSFT,42.0,1",    ("MSFT",42.0,1)),
        ];
        for (input, want) in cases {
            let t = parse(input)?;    // ? works: test returns Result
            assert_eq!((t.sym,t.px,t.qty), want);
        }
        Ok(())
    }

    #[test]
    fn rejects() {                    // match a specific Err variant
        assert!(matches!(parse("AAPL"), Err(ParseError::MissingField)));
    }

    #[test]
    #[should_panic(expected = "capacity")]
    fn zero_cap_panics() { Lru::<u8,u8>::new(0); }
}
  • assert_eq! / assert! / assert_ne! — failures print both values.
  • Model failure as Result & test the Err variants, not just the happy path — that's the signal.
  • -- --nocapture to see println!; #[should_panic] for genuine caller-bug preconditions.

tickparser — Lifetimes / Zero-Copy

Topic: lifetimes & zero-copy borrowing. Parse "LIV-MUN|1.95|2.05|1234" at millions/sec — no alloc. The Quote borrows the symbol straight out of the caller's buffer.

pub struct Quote<'a> {
    pub symbol: &'a str,   // borrows input — no String, no alloc
    pub bid: f64, pub ask: f64, pub seq: u64,
}
// signature IS the design: output borrows input, fallible
pub fn parse(line: &str) -> Result<Quote<'_>, ParseError>;
  • Move: &'a str not String. str::split('|') yields borrowed slices — lazy, zero-copy. Quote derives Copy only because symbol is &str.
  • Types as validation: seq: u64 makes "-1" fail for free.
  • Errors: own a ParseError enum; map_err(|_| ParseError::InvalidBid)? — don't leak std's ParseFloatError.
  • Test: std::ptr::eq(q.symbol.as_ptr(), line.as_ptr()) proves no copy — the load-bearing test.

! Gotcha: don't .to_owned() "to be safe" — that reintroduces the exact alloc the kata exists to kill.

calc — Enum AST + Box Recursion

Topic: recursive enum + match. eval("1+2*(3-4)/5") by hand. Precedence is tree shape, not a scanning rule — build the AST, then walk it.

pub enum Expr {
    Num(f64),
    Neg(Box<Expr>),                        // Box: recursive → infinite size otherwise
    Bin { op: Op, lhs: Box<Expr>, rhs: Box<Expr> },
}
// recursive descent, one fn per precedence level:
// expr(+ -) → term(* /) → factor(- , (), number)
  • Move: precedence = which fn calls which; left-associativity = a while loop folding lhs, NOT right-recursion.
  • Eval = exhaustive match recursing into children — no wildcard on Op.
  • Tests: "10-2-3"==5 (left-assoc), "1+2*3"==7 (precedence), "1+2)"→TrailingInput, div-by-zero, and assert the AST shape.

! Gotchas: forget Box → "recursive type has infinite size". Skip the pos != tokens.len() check → 1+2) silently returns 3.0.

candles — Iterator by Hand

Topic: implement Iterator manually — lazy, O(1) space over an unbounded feed. Aggregate ticks into OHLCV candles per time window.

pub struct Candles<I: Iterator<Item=Tick>> {
    ticks: I, period: u64,
    pending: Option<Tick>,   // ONE tick of look-ahead
    cur: Option<Candle>,     // in-progress candle
}
impl<I: Iterator<Item=Tick>> Iterator for Candles<I> {
    type Item = Candle;
    fn next(&mut self) -> Option<Candle> { /* state machine */ }
}
  • Move: own the upstream iterator (ticks: I); be generic over IntoIterator<Item=Tick>, store I::IntoIter (monomorphized, zero dispatch).
  • Iterators are cursors, not lists. Read a next-window tick you can't un-read → stash it in pending, emit the finished candle. Option::take is the workhorse.
  • Tests: window split (boundary tick not lost), end-flush (None => self.cur.take()), laziness (.next() minimal work).

! Gotcha: collect+group is the wrong answer — eager, O(n), hangs on infinite feed. And Box<dyn Iterator> is needless alloc/dispatch.

eventbus — Trait Objects (dyn Fn)

Topic: traits & dispatch. Sync pub/sub; store handlers of wildly different shapes in one Vec. Every closure has a unique anonymous type → Vec<F> is homogeneous → must erase.

type Handler = Box<dyn Fn(&Event)>;   // type-erased: the enabling choice
handlers: HashMap<String, Vec<Handler>>,
pub fn subscribe<F: Fn(&Event) + 'static>(&mut self, topic: &str, h: F);
pub fn publish(&self, e: &Event);     // Fn: fires repeatedly via &self
  • Move: generic at the call site (subscribe<F>, inlinable), erase to dyn in storage. Box<dyn Fn> = fat pointer (data, vtable).
  • Fn not FnMut — FnMut forces publish(&mut self), serialising all publishes. Observe side-effects via Rc<Cell/RefCell> captures.
  • Tests: 3 different closures on one topic fire in order (only compiles with dyn); unknown topic = no-op (if let Some).

! Gotcha: missing + 'static → boxing a closure that borrows a local won't compile. Vs closed set: enum Handler+match (no heap/vtable).

lru — The DLL Ownership Lesson

Topic: ownership in a linked structure — THE Rust lesson. O(1) LRU wants a hashmap + doubly-linked list. Pointer DLL needs two owners/node → doesn't port. Answer: an arena of indices.

map:  HashMap<K, usize>,   // key → slab idx (not a ref)
slab: Vec<Entry<K,V>>,     // arena owns every node
free: Vec<usize>,          // recycle slots on evict
head/tail: Option<usize>,  // prev/next are usize indices
pub fn get(&mut self, k: &K) -> Option<&V> // &mut: hit reorders recency
  • Move: arena + usize indices, not Rc<RefCell>, not unsafe. K: Clone so eviction lifts the tail key to delete its map row.
  • get is &mut self (a hit is a write); peek is the &self read.
  • Tests: get updates recency so a different key is evicted; update-in-place doesn't grow len; free-list reuses slots.

! Gotcha: never Vec::remove a slot — it shifts every later element, invalidating all stored indices. Recycle via the free-list.

orderstate — Enums + Exhaustive match

Topic: enum states + exhaustive transitions. Order lifecycle as an enum; one match (state, event) IS the whole transition table, audited by the compiler.

pub enum OrderState {
    New{total:u64}, Accepted{total:u64},
    PartiallyFilled{filled:u64,total:u64},
    Filled, Cancelled, Rejected,          // terminal
}
pub fn apply(self, e: Event)              // self BY VALUE: old state moves out
    -> Result<OrderState, TransitionError>;
  • Move: take self by value → transitioning consumes the old state; a stale handle can't be reused (compile-time "once you leave, it's gone").
  • Match each state explicitly; fold only illegal pairs into a trailing (state,event) => Err. Add a variant → build breaks until handled.
  • Custom TransitionError (#[non_exhaustive]) impl Error. Test the 3×4 terminal truth table.

! Gotcha: a catch-all _ on the state axis kills exhaustiveness. Typestate (Order<Filled>) makes illegal calls not compile — but can't hold a runtime-chosen state.

positionbook — Arc<Mutex>: Deadlock & Lost Update

Topic: shared-state concurrency. Per-symbol net keeper. No data race (won't compile) — the bugs left are deadlock + lost update.

positions: RwLock<HashMap<String, Arc<Mutex<i64>>>>,
pub fn apply(&self, f: &Fill);            // &self — shared
pub fn hedge(&self, from: &str, to: &str, qty: i64);
// LOST-UPDATE fix: RMW inside ONE lock hold
let mut pos = slot.lock().unwrap();
*pos += fill.qty;
// DEADLOCK fix: sorted lock order, NOT hedge direction
if from < to { let a=fs.lock()?; let b=ts.lock()?; *a-=q; *b+=q; }
else         { let b=ts.lock()?; let a=fs.lock()?; *a-=q; *b+=q; }
  • Move: per-symbol Arc<Mutex> for parallelism (say the tradeoff vs coarse Mutex<HashMap>). Always lock the lexicographically-smaller symbol first, whichever way the hedge goes.
  • Test: Barrier conservation stress — total == THREADS*ITERS (lost update) + opposite-direction hedges (deadlock hangs).

! Gotchas: split RMW across two .lock() = lost update. Direction-based lock order = deadlock. Don't hold the registry lock across a per-symbol lock.

threadpool — Channel + Drop Shutdown

Topic: concurrency ownership. Fixed pool draining one MPSC queue; drop = clean shutdown, no lost jobs, all threads joined.

type Job = Box<dyn FnOnce() + Send + 'static>;
sender: Option<Sender<Job>>,          // Option so Drop can take() → close
workers: Vec<Worker>,                 // each: Option<JoinHandle>
receiver: Arc<Mutex<Receiver<Job>>>,  // ONE receiver, shared (not Clone)
// worker: lock → recv → DROP GUARD → run unlocked
let msg = receiver.lock().unwrap().recv();  // guard dies at ;
match msg { Ok(job)=>job(), Err(_)=>break } // sender dropped → err
// Drop: take sender (close), THEN join every handle
drop(self.sender.take());
for w in &mut self.workers { w.handle.take().unwrap().join()?; }
  • Move: recv() errs only when all senders dropped, after draining the buffer → that's your shutdown signal AND no-lost-jobs guarantee. No sentinel/poison message.
  • Option::take() moves the handle out of &mut self in Drop (join consumes).

! Gotchas: while let Ok(job)=rx.lock()?.recv(){job()} holds the guard for the whole body → all jobs serialised. Receiver isn't Clone.

connpool — RAII Guard (Drop = release)

Topic: RAII — ownership + Drop as resource management. Bounded pool of reusable connections; acquire hands back a guard, the return happens in the guard's Drop — no release() to forget. Same shape as MutexGuard/File/Box.

pub struct PooledConn<T> {
    conn: Option<T>,       // Option so Drop can move it out of &mut self
    inner: Arc<Inner<T>>,  // where to return it
}
// Deref/DerefMut -> T (guard IS the connection);
struct Inner<T> { free: Mutex<VecDeque<T>>, available: Condvar, capacity: usize }
impl<T> Drop for PooledConn<T> {
    fn drop(&mut self) {
        if let Some(c) = self.conn.take() {            // move out
            self.inner.free.lock().unwrap().push_back(c);
            self.inner.available.notify_one();          // wake one blocked acquirer
        }
    }
}
  • Move: return rides on ownership, not caller discipline → leak-free on every ?/early-return/panic. Three mechanics: Option<T> (move out of &mut self), Deref/DerefMut (ergonomic), Drop (the return).
  • acquire blocks on the Condvar in a while loop (spurious wakeups); try_acquire is a single pop_front()?, never waits.
  • Tests: Barrier-gated thread::scope — max_seen <= capacity (never over-hands) + available() == capacity at end.

! Gotchas: a release(conn) method reintroduces the leak RAII deletes. if free.is_empty() before wait (must be while). Forgetting notify_one → returned conn sits idle while acquirers sleep forever.

circuitbreaker — 3-State FSM + Injected Clock

Topic: FSM as enum+match, Mutex-shared state, injected clock for deterministic time. Fronts a flaky downstream; trips Open after N consecutive fails, fast-fails without calling f, probes after cooldown.

pub enum State { Closed, Open, HalfOpen }
pub enum CallError<E> { Open, Inner(E) }  // Open: f NOT run · Inner: real err kept
pub struct CircuitBreaker {
    inner: Mutex<Inner>,   // State + counters + opened_at, one lock
    clock: Box<dyn Fn() -> Instant + Send + Sync>,  // Instant::now prod, fake in test
}
pub fn call<T,E>(&self, f: impl FnOnce()->Result<T,E>) -> Result<T, CallError<E>>;
Stateon call
Closedrun f; success resets count; Nth consecutive fail → Open + stamp time
Opendon't run f, return Open; after cooldown → HalfOpen (lazy, next call)
HalfOpenrun f; Nth success → Closed; first fail → Open, restart timer
  • Move: run f inside the lock hold — decision + transition atomic, or two threads both trip. Clock is a Box<dyn Fn> seam → test advances a shared Instant, zero real sleeps.
  • state() is &self + interior mutability (applies pending cooldown expiry); no timer thread.

! Gotchas: counting total not consecutive fails (a success must reset). Moving Open→HalfOpen on a background timer (it's lazy). Running f before locking splits check from transition.

parkinglot — Enums + Best-Fit

Topic: closed-set modelling — enums, exhaustive match, ticket-as-capability. Two closed sets + one lookup table. Best-fit = smallest free spot that fits, so a bike doesn't burn a Large a truck needs.

enum VehicleKind { Motorcycle, Car, Truck }
#[derive(PartialOrd, Ord)] enum SpotKind { Small, Medium, Large } // decl order = size
struct Ticket { spot_kind: SpotKind, index: usize, plate: String } // unforgeable receipt
// fit rules AND best-fit order in one exhaustive match, smallest-first:
fn fit_order(k: VehicleKind) -> &'static [SpotKind] {
    match k {
        VehicleKind::Motorcycle => &[Small, Medium, Large],
        VehicleKind::Car        => &[Medium, Large],
        VehicleKind::Truck      => &[Large],
    }
}
  • Move: enums over Box<dyn Vehicle> — closed set → no alloc, no vtable, and the compiler enforces the fit rules. Add Bus → build breaks until every match places it.
  • Best-fit is free: park walks the ascending fit_order slice, takes first free spot — that is best-fit, not a separate algorithm.
  • Ticket = capability: unpark consumes it by value, frees only if the plate still matches → double-free unrepresentable, UnknownTicket otherwise.

! Gotchas: a _ => arm in fit_order silently mis-parks the next kind. First-fit (largest-first / any free) starves trucks. unpark trusting the index alone lets a stale ticket evict a live car.

vending — Transaction + Greedy Change

Topic: stateful transaction + greedy change-making. Three state buckets: slots (stock+price), float (coins to give), inserted (punter escrow). select is one all-or-nothing transition.

enum Coin { Nickel, Dime, Quarter }  // cents() via match — invalid coin unrepresentable
enum VendError {
    SoldOut,
    InsufficientFunds { needed: u32, balance: u32 }, // data carries the UI hint
    ExactChangeOnly,                                 // affordable, float can't make change
}
struct Dispensed { product: String, change: Vec<Coin> }
// select: validate slot+stock, balance>=price, float can make change — THEN commit
  • Move: every failure path returns before the first mutation → atomic without rollback. A punter who gets InsufficientFunds keeps their money; the slot stays buyable.
  • balance() is derived (sum the escrow), one source of truth — no drift vs a stored counter. Inserted coins join the float in the change pool.
  • Greedy change: largest coin first — optimal for canonical 5/10/25 with enough supply. A finite float can strand greedy → that's ExactChangeOnly, not a bug (DP is the robust fix).

! Gotchas: mutate-as-you-validate corrupts the machine on the error path. "Greedy always works" — only canonical + unlimited. Making InsufficientFunds a bare tag drops the needed/balance the caller needs.

spscring — Unsafe Capstone + Miri

Topic: unsafe, atomics ordering, hand-written Send/Sync. Wait-free SPSC ring — no locks, no per-item alloc.

struct Ring<T> {
    buf: Box<[UnsafeCell<MaybeUninit<T>>]>,
    head: AtomicUsize,  // consumer owns
    tail: AtomicUsize,  // producer owns
}
// SAFETY: producer only writes tail's slot, consumer only reads
// head's slot, hand-off ordered by release/acquire → never aliases.
unsafe impl<T: Send> Sync for Ring<T> {}
  • Ordering: read your own index Relaxed; read the other's Acquire; publish your own Release. That one release→acquire edge is the entire soundness proof — name it aloud.
  • Allocate N+1 slots, keep one empty → tell full from empty with no shared counter. PhantomData<Cell<()>> makes handles !Sync (enforces single producer/consumer).
  • Drop uses get_mut() (single owner, no atomics); drops only [head,tail).
  • Why unsafe at all: safe Rust forbids two threads touching one buffer slot; the ring proves via the release→acquire edge that producer and consumer never touch the same slot at the same time, so the aliasing is sound — you assert what the borrow checker can't see. Hence the hand-written unsafe impl Send/Sync.

! Gotcha: green cargo test proves nothing — run cargo +nightly miri test -p solution spscring. SeqCst everywhere works but hides that you don't know which pair matters.

Dispatch, Errors & Idioms

Static vs dynamic dispatch

Generic <T: Trait>Box<dyn Trait>
monomorphized, inlined, zero costvtable indirection + heap
one concrete type per siteheterogeneous, stored together

Rule: generics at the edge, trait objects in the container.

Error model (every fallible kata)

  • Custom enum Error, one variant per failure mode; impl Display + std::error::Error.
  • ? propagates; map_err(|_| MyError::X)? translates std errors at the boundary — don't leak them.
  • Exhaustive match in Display — no wildcard, so a new variant won't compile until handled.

Idioms worth knowing

  • let-else: let Some(x) = opt else { return }; — guard clause.
  • ? on Option: let idx = *self.map.get(k)?;
  • matches!(x, Err(E::Missing)) in tests.
  • Option::take() — move out of &mut self (Drop-shutdown, Drop-release, iterator flush).
  • entry(k).or_default() / or_insert_with(|| ..) — insert-or-get in one lookup.
  • map_or(0, Vec::len) — default when the key is absent, no unwrap.
  • #[non_exhaustive] on public error enums — add a variant without breaking callers.

Where the type system's guarantees stop

  • Safe Rust kills: data races, use-after-free, double-free, null deref, iterator invalidation.
  • Still on you: deadlock, lost update, logic bugs, RefCell runtime panics, unsafe UB, resource leaks (unless RAII). Name the boundary unprompted — that's the senior tell.

★ Pre-Code Checklist

Design (before typing)

  • ☐ Decided ownership first: who owns each value; move vs & vs &mut per method.
  • ☐ &mut self wherever a "read" actually mutates state (LRU get, order transition).
  • ☐ Static (<T>) vs dynamic (dyn) dispatch chosen deliberately — generics at edge, dyn in storage.
  • ☐ Recursive / dyn type wrapped in Box; lifetime 'a added where output borrows input.

Data shape

  • ☐ Arena + usize indices for any linked/graph structure — not Rc<RefCell>, not unsafe.
  • ☐ Types encode invariants (u64 rejects negatives; enum makes illegal states unrepresentable).

Errors & matching

  • ☐ Failures modelled as enum + Result + ?, never panic (panic only for caller bugs / #[should_panic]).
  • ☐ match exhaustive on the closed axis (states, ops, variants) — no catch-all that hides a missing case.

Concurrency

  • ☐ RMW held inside one lock guard (no lost update).
  • ☐ Multiple locks acquired in a global sorted order (no deadlock); registry lock not held across a per-item lock.
  • ☐ Shutdown by closing the channel (drop sender), then join — no sentinel, no sleep.
  • ☐ Condvar::wait guarded by a while predicate (spurious wakeups), paired with a notify_one on release.
  • ☐ unsafe: every block has a checkable // SAFETY:; minimal Acquire/Release; verified with Miri.

Resources & time

  • ☐ Borrowed resource returned by RAII Drop, never a release() the caller can forget — held as Option<T> so Drop can move it out; Deref/DerefMut for ergonomics.
  • ☐ Time-dependent logic reads an injected clock (Fn() -> Instant), so tests advance time by hand — no real sleep.
  • ☐ Multi-step transaction (vend, hedge) validates every path before the first mutation — atomic commit-or-abort, no half-mutated rollback.

Tests first

  • ☐ Inline #[cfg(test)] mod tests written before bodies; Err variants tested, not just happy path.
  • ☐ Concurrency = Barrier-gated thread::scope asserting an invariant.
