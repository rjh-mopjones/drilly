Architecture

flowchart TD U["kubectl / CI"] --> API["kube-apiserver"] API --> ETCD["etcd (state)"] API --> SCH["scheduler"] API --> CM["controller-mgr"] API --> KUBELET["kubelet (per node)"] KUBELET --> CRI["containerd → Pods"] KUBELET --> KP["kube-proxy"]

Control plane = api-server + etcd + scheduler + controller-manager. Node = kubelet + kube-proxy + runtime. Everything goes through the api-server; etcd is the single source of truth.

Debug order: describe (events) → logs → exec → node/scheduler !

Minimal Deployment + Service

apiVersion: apps/v1
kind: Deployment
metadata: { name: web }
spec:
  replicas: 3
  selector: { matchLabels: { app: web } }
  template:
    metadata: { labels: { app: web } }
    spec:
      containers:
      - name: web
        image: my-registry/web:1.2.3   # never :latest !
        ports: [{ containerPort: 8080 }]
        resources:
          requests: { cpu: 100m, memory: 128Mi }
          limits:   { cpu: 500m, memory: 256Mi }
        readinessProbe:
          httpGet: { path: /healthz, port: 8080 }
---
apiVersion: v1
kind: Service
metadata: { name: web }
spec:
  selector: { app: web }   # must match pod labels !
  ports: [{ port: 80, targetPort: 8080 }]

Config & Secrets

kubectl create configmap app-cfg --from-file=app.conf
kubectl create secret generic db --from-literal=pass=s3cr3t
  • Secret = base64, NOT encryption ! Enable etcd encryption-at-rest / KMS; lock down RBAC.
  • env vars are fixed at pod start — change a ConfigMap and you must restart pods to pick it up; mounted volumes update (with lag) !
  • Roll pods on change via a checksum annotation. Never bake secrets into images.
  • External Secrets Operator / Vault / CSI Secrets Store for real secret mgmt.

Probes & Lifecycle

ProbeFail →
livenesskubelet restarts container
readinessremoved from Service endpoints (no restart)
startupguards slow start; gates the other two
  • Liveness ≠ readiness. A liveness probe that checks a dependency → cascading restarts !
  • Shutdown: SIGTERM → terminationGracePeriodSeconds → SIGKILL. Use a preStop sleep to cover the endpoint-removal race !
  • PodDisruptionBudget protects availability during drains/upgrades.

Resources & QoS

  • requests = scheduling & reservation; limits = hard cap.
  • Over memory limit → OOMKilled (137). Over CPU limit → throttled, not killed !
QoSWhen
Guaranteedrequests == limits (all ctrs) — evicted last
Burstablerequests < limits
BestEffortnone set — evicted first !
  • CPU in millicores (500m); memory Mi. LimitRange/ResourceQuota per namespace.

Scheduling

  • nodeSelector = simple label match. Affinity = required/preferred rules (node & pod).
  • Taints repel, tolerations allow — control-plane/GPU nodes are tainted; effects NoSchedule/PreferNoSchedule/NoExecute.
  • Pod anti-affinity spreads replicas; topologySpreadConstraints (maxSkew) balances across zones.
  • Priority + preemption evicts lower-priority pods under pressure.
tolerations:
- key: node-role.kubernetes.io/control-plane
  effect: NoSchedule

Autoscaling

ScalerScales
HPApod replicas (CPU/mem/custom)
VPApod requests/limits (recreates)
Cluster Autoscalernodes (Pending pods)
Karpenterjust-in-time right-sized nodes
  • HPA: ceil(replicas × current/target); needs requests set + metrics-server !
  • HPA + VPA on the same metric conflict. KEDA for event-driven / scale-to-zero.
  • Pods with local storage / PDBs can block node scale-down.

RBAC & Security

  • Request pipeline: authn → authz (RBAC) → admission.
  • Role/RoleBinding = namespaced; ClusterRole/ClusterRoleBinding = cluster-wide. Rules = apiGroups × resources × verbs.
  • Pods authenticate via a ServiceAccount token; least-privilege, avoid cluster-admin/wildcards !
  • kubectl auth can-i --as=… to test.

Pod hardening

  • SecurityContext: runAsNonRoot, drop ALL caps, readOnlyRootFilesystem, no privileged !
  • Pod Security Admission (baseline/restricted). NetworkPolicy = default-allow until a policy selects the pod, then default-deny (needs Calico/Cilium).

Networking & DNS

  • Model: every pod gets its own IP; pods talk without NAT. CNI wires it (Calico/Cilium/Flannel/AWS-VPC-CNI).
  • CoreDNS resolves services/pods. Watch ndots:5 — unqualified lookups fan out and add latency ! (NodeLocal DNSCache helps).
  • kube-proxy programs Service VIPs (iptables/IPVS); Cilium can replace it with eBPF.
  • Service mesh (Istio/Linkerd) = mTLS + traffic mgmt + observability — often more complexity than you need !

Helm · Kustomize · GitOps

  • Helm: templated charts + values.yaml; helm install/upgrade/rollback; releases & history. Powerful but YAML-templating is error-prone.
  • Kustomize: template-free bases + per-env overlays/patches; built into kubectl -k.
  • GitOps (ArgoCD/Flux): Git is desired state; pull-based reconcile + drift detection — beats kubectl apply from CI.
  • Secrets in Git: sealed-secrets / SOPS / external secrets !

Cluster Ops

  • Upgrade order: control plane first, then nodes. Kubelet may lag api-server by a couple minors but never lead; go one minor at a time !
  • Node ops: cordon → drain (respects PDBs) → replace → uncordon.
  • etcd: odd member count for quorum; etcdctl snapshot save; back it up — it's the whole cluster !
  • Backups: Velero (PVs + objects). Managed clusters run the control plane/etcd for you.
  • Cost: right-size requests, spot node pools, autoscaler/Karpenter, bin-packing.

★ Troubleshooting Playbook

Pending

  • ☐ describe pod events → insufficient cpu/mem, taints, affinity, unbound PVC, quota.

CrashLoopBackOff

  • ☐ logs --previous, exit code, bad config/cmd, failing liveness probe.

ImagePullBackOff / ErrImagePull

  • ☐ image name/tag typo, private registry needs imagePullSecrets, registry/network.

OOMKilled (137)

  • ☐ memory limit too low or leak — raise limit / fix app; check describe.

Service returns nothing

  • ☐ get endpoints svc empty → selector mismatch / no ready pods / wrong port / NetworkPolicy.

DNS failing

  • ☐ CoreDNS pods/logs, ndots, test with kubectl run -it --rm dnsutils.

Stuck Terminating

  • ☐ finalizers, node gone, grace period; patch/remove finalizer as last resort !

☐ Manifest Review Checklist

  • ☐ resources.requests & limits set (mem limit == request for Guaranteed critical apps).
  • ☐ readiness (and liveness/startup where apt) probes — not checking dependencies in liveness.
  • ☐ Image is a pinned tag/digest, never :latest.
  • ☐ runAsNonRoot, drop ALL caps, read-only rootfs, no privileged/hostPath/hostNetwork.
  • ☐ Least-privilege ServiceAccount + RBAC; automountServiceAccountToken:false if unused.
  • ☐ Labels match Service/selector; multiple replicas + PodDisruptionBudget.
  • ☐ preStop + terminationGracePeriod for graceful shutdown; NetworkPolicy in place.
  • ☐ No secrets in env plaintext / image; config externalised.
