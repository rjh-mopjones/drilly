The Big Picture

  • Trained to predict the next token; that's the whole objective.
  • Transformer (2017) replaced RNNs — parallel + attention.
  • Decoder-only (GPT) = generation; encoder-only (BERT) = understanding.
  • Everything is matrices + attention + a next-token loop.

Tokenization

  • Text → integer IDs via subword vocab (BPE / SentencePiece), ~30k-130k.
  • ! Tokens != words: " apple" vs "apple" vs "App" differ.
  • ! Strawberry: the model sees token IDs, not letters → can't count the r's.
  • Tokens = the unit of cost & context.

Embeddings & Position

emb: (vocab, d_model) lookup by token id
meaning = geometry (nearby vectors ~ similar)
  • Attention is order-agnostic (a set op) → must inject position. !
  • RoPE (rotary, relative, extrapolates) dominates; also sinusoidal / learned / ALiBi.

Attention (QKV)

Q=x@Wq  K=x@Wk  V=x@Wv
Attn = softmax(Q @ K^T / sqrt(d_k)) @ V
flowchart LR X["token x"] --> Q & K & V Q --> S["scores Q·K^T"] K --> S S --> W["softmax weights"] W --> O["weighted sum of V"] V --> O

Q asks, K advertises, dot = relevance, softmax = weights, out = weighted avg of V. ! /sqrt(d_k) keeps softmax from saturating.

Masking & Heads

  • Causal mask: set future scores to -inf before softmax → a token can't see the future. !
  • Self-attn (same seq) vs cross-attn (Q from decoder, K/V from encoder).
  • Multi-head: h heads of dim d_k=d_model/h, each learns different relations; concat + W_o.

Transformer Block & Stack

x = x + MHA(LN(x))     # attention sublayer
x = x + FFN(LN(x))     # feed-forward sublayer
# (pre-LN); stack N identical blocks
flowchart TB E["embed + pos"] --> B["block x N"] B --> N["final norm"] N --> H["LM head (unembed)"] H --> L["logits (seq, vocab)"]

FFN, Norm & Residuals

  • FFN: W2·act(W1·x), hidden = 4·d_model, GELU/SwiGLU — most params live here (the "facts").
  • Residual x+f(x) = gradient highway → deep nets train. !
  • RMSNorm (modern) / LayerNorm; pre-LN is stabler than post-LN.

Forward Pass (shapes)

ids (B, T)
  -> embed (B, T, d_model)
  -> N blocks (shape preserved)
  -> norm -> LM head
  -> logits (B, T, vocab)
gen: take last position -> logits (vocab,)

! Logits are raw scores, not probabilities — softmax comes at sampling.

Sampling & Decoding

p = softmax(logits / temperature)
top-k: keep k highest
top-p: smallest set with cumsum(p) >= p
  • T→0 ≈ greedy; T>1 more random.
  • Sampling → same prompt, different answers. ! Even T=0 can vary (float/batch/MoE).

Autoregressive + KV Cache

loop: forward -> sample next -> append -> repeat
  • Naive = re-encode the whole prefix each step (wasteful).
  • KV cache: store past K,V per layer → new token attends over cache, ~O(1)/token. !
  • Prefill (prompt, parallel, compute-bound) vs decode (1/token, memory-bound).

Pretraining

objective: predict next token
loss = -log( p_model(true next token) )   # cross-entropy
self-supervised (text is its own label)

Trillions of tokens → a base model (a text-completer, not yet an assistant).

Training & Scaling

  • Backprop gets grads; gradient descent updates the weights (not activations/data). !
  • AdamW, LR warmup+decay, grad accumulation, bf16.
  • Chinchilla: ~20 tokens/param compute-optimal; FLOPs ~ 6·N·D.

Post-Training

  • ! Base != chat.
  • SFT: fine-tune on (instruction, response) demos + chat template.
  • RLHF: reward model on human prefs → PPO with KL penalty.
  • DPO: preference optimization directly, no reward model / RL loop.
  • Alignment = helpful/honest/harmless (+ alignment tax, sycophancy).
