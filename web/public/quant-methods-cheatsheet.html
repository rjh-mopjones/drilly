Probability — Moments & Conditioning

  • Expectation is linear, variance is not: E[aX+bY]=aE[X]+bE[Y] always; but Var(aX)=a^2 Var(X) and Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y) — the cross-term is where all diversification lives.
  • Var(X)=E[X^2]-E[X]^2; Cov(X,Y)=E[XY]-E[X]E[Y]; Corr=Cov/(sigma_X sigma_Y) in [-1,1].

Tower rule (most-used identity)

E[ E[X|Y] ] = E[X]
E[X|Y] is a RANDOM VARIABLE (function of Y) !
Var(X) = E[Var(X|Y)] + Var(E[X|Y])   // law of total var
  • Bayes: P(A|B)=P(B|A)P(A)/P(B). Keep base rates straight under pressure.
  • ! Uncorrelated ≠ independent. Corr=0 kills only the linear link; X and X^2 can be uncorrelated yet fully dependent. Independence ⇒ Cov=0, not the reverse.

Estimation — LLN, CLT, MLE

  • LLN: sample mean Xbar_n -> mu. CLT: sqrt(n)(Xbar_n - mu) -> N(0,sigma^2); the error shrinks like 1/sqrt(n) and is Gaussian regardless of the underlying shape ! (that's the whole point — data need not be Normal).
  • Standard error of the mean = sigma/sqrt(n). "How accurate is my estimate?" is almost always a CLT question.

MLE & bias

  • MLE = argmax likelihood; maximise log L. Gaussian: mu_hat=Xbar, sigma^2_hat=(1/n)Sum(x-Xbar)^2.
  • ! That variance MLE divides by n → biased low. n-1 (Bessel) is unbiased. More data shrinks variance, never removes bias.
  • bias = E[estimator] - true; MSE = bias^2 + variance (bias–variance decomposition).

Brownian Motion & Processes

Wiener process W_t — 4 axioms

W_0=0
independent increments
W_t - W_s ~ N(0, t-s)          // spreads like sqrt(time)
continuous paths, NOWHERE differentiable !
  • E[W_t]=0, Var(W_t)=t, E[W_t^2]=t, Cov(W_s,W_t)=min(s,t).
  • Quadratic variation [W]_T = T (not 0!) — squared increments accumulate to real time; first variation (path length) is infinite. This single fact forces a new calculus.
  • Markov = future depends only on present. Martingale = E[X_t|F_s]=X_s ("fair game", no drift). W_t is both.
  • GBM: dS=mu S dt + sigma S dW — the workhorse asset model; returns i.i.d., prices lognormal, always >0.
  • OU / mean-reverting: dX=theta(m-X)dt+sigma dW — rates, spreads, pairs.

Itô's Lemma & Stochastic Calculus

Multiplication table (keep to order dt)

(dW)^2 = dt      dt*dW = 0      dt^2 = 0
// dW ~ sqrt(dt), so (dW)^2 is FIRST order — not negligible !

Itô's lemma (stochastic chain rule)

dS = a dt + b dW
df = (f_t + a f_S + 1/2 b^2 f_SS) dt + b f_S dW
        ^^^^^^^^^^^ Ito correction, from (dW)^2=dt

Canonical: f = ln S, GBM

d(ln S) = (mu - sigma^2/2) dt + sigma dW
S_T = S_0 exp((mu - sigma^2/2)T + sigma W_T)   // lognormal
  • ! ln S drifts at mu - sigma^2/2, not mu. Pure calculus, appears under any measure.
  • ! E[S_T]=S_0 e^(mu T) (Jensen cancels the −σ²/2); exp((mu-sigma^2/2)T) is the median, not the mean.
  • Itô integral uses left-endpoint sums → non-anticipating → martingale. Stratonovich (midpoint) obeys the ordinary chain rule but isn't a martingale, so finance uses Itô.

Fixed Income — Duration & Convexity

  • Price = PV of coupons + principal at yield y; price moves inversely with yield.
  • Macaulay duration = PV-weighted average time to cashflows (years).
  • Modified duration D_mod = D_mac/(1+y/m) = % price sensitivity: dP/P ≈ -D_mod * dy.
  • Convexity C is second-order: dP/P ≈ -D_mod dy + 1/2 C dy^2.

Key relations

  • ! Duration alone underestimates price for large yield moves — convexity is a positive correction for vanilla bonds (price–yield curve is convex).
  • Higher coupon → lower duration; zero-coupon duration = maturity.
  • DV01 / PV01 = price change per 1bp = D_mod * P * 0.0001 — the desk's hedge unit.
  • Bootstrapping builds the zero curve from par instruments; YTM assumes flat reinvestment at y !.

Portfolio Theory & Optimization

Portfolio return  mu_p = w^T mu
Portfolio var     s_p^2 = w^T Sigma w
2-asset  s_p^2 = w1^2 s1^2 + w2^2 s2^2 + 2 w1 w2 rho s1 s2
  • Diversification works whenever rho < 1; risk of a large equal-weight book → average covariance, not average variance (idiosyncratic risk vanishes, systematic remains).
  • Efficient frontier = min variance per target return (upper half). Min-variance weights ∝ Sigma^-1 1.
  • Tangency / max-Sharpe: w ∝ Sigma^-1 (mu - r_f 1). With a risk-free asset everyone holds the same risky tangency portfolio + cash (two-fund / CML).
  • Sharpe =(mu_p - r_f)/sigma_p; Sortino uses downside dev; Information ratio = active return / tracking error.

! Markowitz is error-maximising: tiny changes in estimated mu/Sigma swing weights wildly. Shrinkage (Ledoit-Wolf), risk-parity, or Black-Litterman tame it in practice.

CAPM & Factor Models

CAPM:  E[R_i] = r_f + beta_i (E[R_m] - r_f)
beta_i = Cov(R_i, R_m) / Var(R_m)          // regression slope
  • Total = systematic + idiosyncratic: sigma_i^2 = beta_i^2 sigma_m^2 + sigma_eps^2. Only systematic (beta) risk is priced — idiosyncratic is diversifiable, earns no premium !.
  • Alpha = intercept above the CAPM line = skill/mispricing. SML plots E[R] vs beta.
  • Multifactor (APT): R_i = a + Sum beta_k F_k + eps. Fama-French: market, SMB (size), HML (value); +momentum (Carhart), +RMW/CMA (5-factor).
  • R^2 = variance fraction explained by factors; beta_portfolio = Sum w_i beta_i.

! CAPM is empirically weak (low-beta anomaly, value/momentum premia) but it's the vocabulary — know its assumptions (one period, homogeneous beliefs, no frictions) and why they fail.

Put-call parity (European, no-arb)

C - P = S - K e^(-rT)        (+ PV of divs on the S side)
  • Breaks ⇒ arbitrage: synthesise the cheap side, short the rich. Model-free — no vol assumption.
  • Moneyness: ITM / ATM / OTM. Intrinsic = payoff now; time value = premium − intrinsic, ≥0, decays to 0 at expiry.
  • ! American call on a non-dividend stock: never early-exercise (time value + interest on K > 0) — same value as European. American puts, and calls with dividends, can be optimal to exercise early.
  • Bounds: max(S-Ke^(-rT),0) ≤ C ≤ S. Structures: spreads, straddle (long vol), strangle, butterfly, collar.

Black-Scholes-Merton

C = S N(d1) - K e^(-rT) N(d2)
P = K e^(-rT) N(-d2) - S N(-d1)
d1 = [ln(S/K) + (r + sigma^2/2)T] / (sigma sqrt(T))
d2 = d1 - sigma sqrt(T)
  • Derivation: Itô on V(t,S), form a delta-hedged Pi=V-Delta*S; the dW cancels → riskless → must earn r → BSM PDE: V_t + rS V_S + 1/2 sigma^2 S^2 V_SS = rV.
  • Reading it: N(d2) = risk-neutral P(finish ITM); N(d1) = delta = PV of receiving the stock conditional on exercise.
  • ! Assumptions that fail in reality: constant σ & r, GBM (no jumps), frictionless continuous hedging, lognormal S. The volatility smile is the market pricing in these violations.
  • ! mu is absent from the price — the drift is hedged away; only r and sigma enter.

  • Δ = hedge ratio (shares per option). Delta-hedge to be first-order flat; rebalance as Δ moves.
  • ! Γ and Θ trade off: long options = +Γ (convexity, gain on big moves) but −Θ (pay time decay). Hedged PnL ≈ 1/2 Gamma (dS)^2 + Theta dt — you win iff realized var > implied var. That is the entire vol-trading game.
  • Vega is largest ATM and longer-dated; Γ spikes ATM near expiry (pin risk, hard to hedge).
  • Gamma-hedge with another option (Δ can't touch Γ), then delta-hedge the residual.

Risk-Neutral Pricing & Martingales

Price_0 = e^(-rT) E^Q[ payoff(S_T) ]
Under Q:  dS = r S dt + sigma S dW^Q   // drift replaced by r
  • Fundamental theorem of asset pricing: no-arbitrage ⇔ ∃ risk-neutral measure Q; market complete ⇔ Q is unique.
  • Under Q every discounted tradable S_t e^(-rt) is a martingale — expected discounted future = today's price. Pricing = discounted expectation, no risk premia needed.
  • Girsanov: a change of measure shifts the drift (mu→r) and leaves sigma dW unchanged — you can't change volatility by changing measure !.
  • ! Q is not real-world probability — it's a pricing device weighting by state prices. Don't forecast with Q; price & hedge with it.
  • Feynman-Kac links the PDE and expectation forms — two faces of one value.

Volatility Modeling

  • Realized vol = from history (sqrt(252)*std of daily). Implied vol = the σ that reprices a market option via BSM.
  • Volatility smile/skew: implied vol varies by strike — equities show a downward skew (OTM puts richer: crash fear + leverage effect) !. A flat smile would mean BSM holds; it never is.
  • Term structure + smile = vol surface sigma(K,T), the desk's core object.

Vol clustering → GARCH

GARCH(1,1): s_t^2 = omega + alpha e_(t-1)^2 + beta s_(t-1)^2
persistence = alpha+beta (->1 = long memory)
long-run var = omega/(1-alpha-beta)
  • Captures volatility clustering (big moves cluster) & fat tails; EWMA is the omega=0 special case (RiskMetrics λ≈0.94).
  • Local vol (Dupire) fits the surface deterministically; stochastic vol (Heston) gives vol its own SDE + correlation → smile dynamics.

Numerical Methods — MC, Trees & PDEs

Monte Carlo

Price = e^(-rT) * mean( payoff(S_T^i) )
GBM step:  S_(t+dt) = S_t exp((r - sigma^2/2)dt + sigma sqrt(dt) Z)
Z ~ N(0,1) i.i.d.
  • ! Error ~ O(1/sqrt(N)) — 100× paths for 10× accuracy. Slow but dimension-independent, so it wins for baskets, path-dependent & high-dim payoffs where trees/PDEs explode.
  • Std error = sample_sd / sqrt(N) — always report it. Variance reduction: antithetic (±Z), control variates (subtract a correlated known-price payoff), importance sampling (deep OTM), quasi-MC (Sobol → ~O(1/N)).
  • American MC: Longstaff-Schwartz — regress continuation value for the exercise boundary. Reuse the same seed across bumped runs for stable finite-difference Greeks.

Binomial tree (CRR)

u = e^(sigma sqrt(dt)),  d = 1/u
q = (e^(r dt) - d)/(u - d)      // risk-neutral prob, NOT real p !
value = e^(-r dt)(q V_up + (1-q) V_down)   // roll back
  • Backward induction from payoffs; at each node American = max(exercise, continuation). Converges to BSM as steps→∞. ! q is the risk-neutral probability, never the real-world one — common blunder.

Finite-difference (solve the BSM PDE)

  • Explicit: simple but conditionally unstable (dt limited by dx²) !. Implicit: unconditionally stable, solve a tridiagonal system. Crank-Nicolson: 2nd-order accurate + stable — the default.
  • Great for 1–2 factors with early exercise / barriers; curse of dimensionality above ~3 factors → switch to MC.

Value at Risk & Risk Measures

  • VaR_α = loss not exceeded with prob α over a horizon (e.g. 1-day 99% VaR). ES / CVaR = expected loss beyond VaR — the average tail.
MethodTrait
Parametric (Normal)VaR=z_a sigma sqrt(h) V; fast, thin tails !

  • Normal quantiles: 95%→1.645σ, 99%→2.33σ. Scale by sqrt(time) (iid).
  • ! VaR is not sub-additive — VaR(A+B) can exceed VaR(A)+VaR(B), i.e. it can penalise diversification. ES is coherent (sub-additive) — regulators (FRTB) moved to ES.
  • ! VaR says nothing about how bad the loss is beyond the threshold; it ignores the tail. Complement with ES + stress tests.

Time Series Analysis

  • Stationarity (constant mean/var/autocov) is required by most models — test with ADF (unit root). Difference / take log-returns to induce it !.
  • ACF/PACF diagnose order: MA(q) → ACF cuts at q; AR(p) → PACF cuts at p.
ModelForm
AR(p)X_t = c + Sum phi_i X_(t-i) + e
MA(q)X_t = mu + e_t + Sum th_j e_(t-j)
ARIMA(p,d,q)AR+MA on d-differenced series
GARCHmodels the variance, not the mean
  • Cointegration (Engle-Granger / Johansen): two I(1) series with a stationary linear combo → basis of pairs trading. Correlation ≠ cointegration !.
  • ! Spurious regression: regressing two independent random walks yields high R² and "significant" t-stats — nonsense. Check stationarity first.
  • Select order by AIC/BIC; validate out-of-sample, never on in-sample fit.

Linear Algebra & Optimization

  • Covariance matrix Σ is symmetric PSD; a valid Σ has all eigenvalues ≥0. Estimated Σ from short samples is ill-conditioned / singular when #assets > #obs ! — shrink/regularise.
  • PCA = eigendecomposition of Σ (or correlation): eigenvectors = orthogonal factors, eigenvalues = variance explained. Yield-curve PCs ≈ level/slope/curvature.
  • SVD A=U S V^T — robust, works for non-square; PCA via SVD of centered data.
  • Cholesky Sigma=L L^T — correlate Monte Carlo normals: correlated = L z. Needs Σ PSD.

Optimization

  • Convex problems (QP for mean-variance) have a unique global optimum — Lagrange multipliers for equality constraints, KKT for inequalities.
  • Gradient descent / Newton for unconstrained; quadratic programming for constrained portfolios (long-only, budget).
  • ! Non-convex (cardinality, integer weights) → local minima; needs heuristics / MIP.

Statistical Arbitrage & Strategies

  • Pairs / mean-reversion: find a cointegrated pair, trade the spread when it deviates > k·σ, exit at the mean. Z-score entry/exit; the spread must be stationary, not merely correlated !.
  • Signals / alpha: momentum, value, carry, reversal. Combine, neutralise to factors, size by conviction/vol.
  • ! Backtest hygiene: look-ahead bias (future data), survivorship bias (dead names dropped), overfitting / p-hacking, ignoring transaction costs + slippage + market impact. A backtest without costs is fiction.
  • Sharpe deflation: multiple testing inflates the best-looking backtest — deflate by number of trials.

Execution & microstructure

  • Bid-ask spread, order-book depth, market impact (≈ concave in size). VWAP / TWAP / implementation-shortfall algos minimise cost.
  • Kelly sizing f*=edge/odds maximises log-growth; desks run fractional Kelly (½) — full Kelly's drawdowns are brutal !.

Brainteasers — Patterns & Tricks

  • EV by symmetry / conditioning: set E = recursion, condition on the first step, solve. E.g. expected flips for HH = 6, for HT = 4 (waiting-time asymmetry) !.
  • Random walk / gambler's ruin: fair walk from k with barriers 0,N → P(hit N)=k/N; expected steps = k(N−k).
  • Linearity of expectation beats casework — sum indicator variables even when dependent (expected fixed points of a random permutation = 1).
  • Tower rule / states: collapse nested expectations; use absorbing Markov states for "expected time until…".
  • Bayes updates: disease/test, Monty Hall, two-envelope — write the joint, normalise, keep base rates.
  • Order statistics: E[max of n U(0,1)] = n/(n+1); expected uniform spacing = 1/(n+1).
  • Continuous: expected distance, Buffon's needle, min of exponentials (min of exps is exp with summed rate).
  • ! State assumptions aloud, sanity-check magnitude, and give the method even if arithmetic slips — interviewers grade the approach.

★ Interview Review Checklist

Probability reflexes

  • ☐ Kept the covariance cross-term in Var of a sum; didn't claim variance is linear.
  • ☐ Said uncorrelated ≠ independent; flagged the n vs n-1 variance bias.

Stochastic calculus

  • ☐ Applied (dW)^2=dt; got the +½σ²·f_SS Itô term's sign right.
  • ☐ ln S drifts at mu−σ²/2; E[S_T]=S_0 e^(muT) (not the median).

Pricing

  • ☐ Priced as a discounted risk-neutral expectation; drift = r under Q; μ absent from BSM.
  • ☐ Stated put-call parity is model-free; no early exercise for an American call on a non-div stock.
  • ☐ Named BSM's failing assumptions and tied them to the vol smile.

Greeks & risk

  • ☐ Explained the Γ–Θ tradeoff (realized vs implied var) as the vol-trading PnL.
  • ☐ ES coherent, VaR not sub-additive; VaR ignores tail depth.

Empirical / strategy

  • ☐ Checked stationarity before regressing; distinguished correlation from cointegration.
  • ☐ Named look-ahead / survivorship / overfitting and included transaction costs.
