Probability Essentials

Var(X) = E[X^2] - E[X]^2
Cov(X,Y) = E[XY] - E[X]E[Y]
Corr = Cov(X,Y)/(sd_X * sd_Y)
E[E[X|Y]] = E[X]        (tower rule)
CLT: mean of n iid -> N(mu, sigma^2/n)

Bayes: P(A|B) = P(B|A)P(A)/P(B).

Distributions

  • Prices lognormal, returns normal: if ln(S)~N then S is lognormal. !
  • Skew (asymmetry), kurtosis (fat tails, excess > 0 for returns).
  • Normal underestimates tail risk → Student-t, jumps.
  • Stylized facts: fat tails, vol clustering, negative skew, leverage.

Brownian Motion & GBM

W_t: W_0=0, W_t - W_s ~ N(0, t-s),
     indep increments, continuous,
     nowhere differentiable
Martingale: E[X_t | F_s] = X_s
GBM: dS = mu*S*dt + sigma*S*dW

Scaling: sd of W over time t is sqrt(t).

Itô's Lemma

Rules: (dW)^2 = dt,  dt^2 = 0,  dt*dW = 0
df = (f_t + mu*S*f_S + 0.5*sigma^2*S^2*f_SS) dt
     + sigma*S*f_S dW
f = ln(S):
  d(ln S) = (mu - sigma^2/2) dt + sigma dW
  S_T = S_0*exp((mu - sigma^2/2)T + sigma*W_T)

! The -sigma^2/2 is the Itô correction.

TVM & Bonds

PV = FV * exp(-r*T)        (continuous)
ModDur = -(1/P) dP/dy
dP/P ~ -ModDur*dy + 0.5*Convexity*dy^2
  • Duration = rate sensitivity; convexity helps the holder.
  • Forward rate from spots by no-arbitrage; bootstrap the curve.

Portfolio & CAPM

var_p = w' Sigma w
Sharpe = (r_p - r_f)/sigma_p
CAPM: E[r_i] = r_f + beta*(E[r_m]-r_f)
beta = Cov(r_i, r_m)/Var(r_m)
  • Diversification cuts variance when corr < 1.
  • Only systematic risk is priced; idiosyncratic diversifies away.

Options & Parity

Call payoff = max(S-K, 0)
Put  payoff = max(K-S, 0)
Put-call parity: C - P = S - K*exp(-r*T)
Forward: F = S*exp((r - q)*T)

Value = intrinsic + time value; moneyness = ITM/ATM/OTM.

Black-Scholes

PDE: V_t + 0.5 sigma^2 S^2 V_SS + r S V_S - r V = 0
C = S*N(d1) - K*exp(-r*T)*N(d2)
d1 = (ln(S/K) + (r + sigma^2/2)T)/(sigma*sqrt(T))
d2 = d1 - sigma*sqrt(T)

! Derive via a delta-hedged riskless portfolio. N(d2) = risk-neutral P(finish ITM). Constant vol is the big lie → smile.

The Greeks

Long gamma ~ 0.5*Gamma*(dS)^2, pays theta. !

Risk-Neutral Pricing

V_0 = E^Q[ exp(-int_0^T r dt) * payoff ]
  • Under Q, discounted prices are martingales.
  • Girsanov: drift mu -> r (removes risk premium). !
  • No-arb ⇔ Q exists; complete ⇔ Q unique (FTAP).
  • Works via replication — no view on real drift needed.

Volatility

  • Implied vol = backed out of the price; realized usually lower (variance risk premium).
  • Smile/skew: constant-vol BSM is wrong; equities skew down (crash risk). !
  • GARCH (clustering), Heston (stoch vol), local vol (Dupire); VIX ~ 30d implied.

Monte Carlo

S_{t+dt} = S_t*exp((r - sigma^2/2)dt + sigma*sqrt(dt)*Z)
price = exp(-r*T) * mean(payoff)
error ~ O(1/sqrt(N))   # 4x paths -> half error
  • Variance reduction: antithetic, control variates.
  • Best for path-dependent/high-dim; weak for American (→ LSM). !

Binomial Tree

u, d = 1/u
p = (exp(r*dt) - d)/(u - d)   # risk-neutral
value = exp(-r*dt)*(p*V_up + (1-p)*V_down)

Backward induct; American = max(continuation, intrinsic) per node. Converges to BSM.

VaR & Risk Measures

Parametric VaR = z_alpha * sigma * sqrt(h) * V
ES (CVaR) = E[loss | loss > VaR]
  • Methods: historical / parametric / Monte Carlo.
  • ! VaR is NOT subadditive (can punish diversification); ES is coherent.
  • Backtest (Kupiec) + stress test the tails.

Time Series & Stat Arb

  • Stationarity first; AR/MA/ARMA/ARIMA; GARCH = vol clustering.
  • Cointegration (≠ correlation): I(1) pair with stationary spread → pairs trade the mean reversion.
  • PCA of the curve = level/slope/curvature; Cholesky Sigma=L L' → correlated draws X=L Z.
  • Backtest traps: look-ahead, survivorship, overfitting. ! Judge by out-of-sample Sharpe.
