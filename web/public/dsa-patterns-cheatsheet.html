DSA Patterns — Recognition Cheat Sheet

read prompt → name pattern in 30s · signal→pattern · drilly

How to read & print

  • This sheet is built for recognition at a glance: scan the signal, name the pattern, justify with complexity. Start with the 3 grid cards (4-Lens Scan, Signal→Pattern, Return-Type→Pattern), then the per-pattern reference cards.
  • ! = trap / disambiguation. ☐ = pre-code checklist item.
  • ~30 patterns cover ~95% of LeetCode. Always state the brute-force baseline first, then the pattern.
  • Print: Ctrl/⌘-P → A4, margins None, scale 100%, background graphics on. 4 columns built-in.

The 4-Lens 10-Second Scan

  • 1. Constraint lens → target complexity (see next card). Read N + time limit first !
  • 2. Shape lens → data structure. sorted array·linked list·tree·graph·grid·stream·string each branch to a pattern set.
  • 3. Objective lens → the verb. find / count / max-min / shortest / longest / all-possible / Kth / range / order.
  • 4. Clue lens → keyword drops the final hint. palindrome · brackets · cycle · prefix · in-place · 1..N · XOR.

Output = a shortlist of 1–3 patterns, ranked. Commit after stating tradeoffs. Most prompts reveal the pattern from the statement alone — constraints just confirm.

Two Pointers

See: sorted array · pair/triplet · palindrome · in-place partition · merge two sorted.

l, r = 0, n-1
while l < r:
  s = a[l] + a[r]
  if s == t: return [l, r]
  elif s < t: l += 1      # need bigger
  else: r -= 1            # need smaller
  • Opposite-ends (sorted) · same-direction (fast/slow) · two-arrays (merge).
  • O(N) time, O(1) space — beats the hash-map version on a sorted input ! (no alloc).
  • 3Sum = sort + fix i + two-pointer the rest; skip dupes for uniqueness !

Sliding Window

See: contiguous subarray/substring + longest/shortest/"at most K" + monotonic condition.

l = 0; best = 0
for r in range(n):
  add(a[r])
  while invalid():        # shrink
    remove(a[l]); l += 1
  best = max(best, r-l+1)
  • Fixed window (size k) vs variable (grow r, shrink l on violation).
  • Amortised O(N): each element enters/leaves once.
  • "exactly K" = atMost(K) − atMost(K−1). Delete from freq map when count hits 0 !
  • Only valid when contiguous and condition monotonic in window size ! (else DP).

Prefix Sum & Hashing

See: subarray sum = K · range sum queries · count subarrays · equal 0/1.

# count subarrays summing to k
seen = {0: 1}; s = 0; cnt = 0
for x in a:
  s += x
  cnt += seen.get(s-k, 0)   # prior prefix
  seen[s] = seen.get(s,0)+1
  • prefix[i] = a[0..i]; range(l,r) = prefix[r] − prefix[l−1].
  • Pair prefix with a hash of "prefix value → count/index" for =K / equal-count problems.
  • 2D → integral image; O(1) rectangle sums after O(NM) build.

Monotonic Stack / Deque

See stack: next greater / previous smaller / largest rectangle / stock span / temperatures.

# next greater element
st = []                    # decreasing indices
for i, x in enumerate(a):
  while st and a[st[-1]] < x:
    ans[st.pop()] = x
  st.append(i)
  • Each index pushed/popped once → O(N).
  • Largest Rectangle / Sum of Subarray Minimums = width via stack distance.
  • Monotonic deque: sliding-window max/min in O(N) — pop from back while smaller, front is the answer.

Binary Search (+ on the answer)

See: sorted lookup · rotated array · "smallest X such that cond()" · min-capacity/max-min.

lo, hi = min_ans, max_ans
while lo < hi:
  mid = (lo+hi)//2
  if feasible(mid): hi = mid   # shrink toward boundary
  else: lo = mid+1
return lo
  • On the answer when the decision feasible(x) is monotonic (true for all x ≥ threshold) ! — Koko bananas, Ship-within-D-days, Split-array-largest-sum.
  • Pin the invariant (lo=first-true) to avoid off-by-one / infinite loops !
  • Rotated/find-min = compare mid to hi to pick the sorted half.

Fast & Slow / Linked List

See: cycle detection · middle node · Nth-from-end · reorder · in-place reverse.

slow = fast = head
while fast and fast.next:
  slow = slow.next
  fast = fast.next.next
  if slow is fast: return True   # cycle
  • Floyd's tortoise/hare: cycle + cycle-start (reset one to head, advance together).
  • Middle = slow when fast hits end. Nth-from-end = gap of N then advance both.
  • Reverse in place with prev/cur/next; use a dummy head to simplify edge cases !

Trees

See: traversal · depth/height · path sum · BST search · LCA · serialize.

def dfs(node):
  if not node: return base
  L = dfs(node.left); R = dfs(node.right)
  return combine(node.val, L, R)   # post-order
  • DFS (pre/in/post) recursion for most tree problems; in-order of a BST is sorted !
  • BFS (queue) for level-order / min-depth / right-side view → returns List<List>.
  • BST op is O(h): O(log n) balanced, O(n) skewed !
  • LCA: recurse; node where left & right both return non-null.

Graph Traversal (BFS / DFS)

See: shortest unweighted · connected components · islands (grid) · flood fill · bipartite.

# grid = graph; 4-dir
DIRS = [(1,0),(-1,0),(0,1),(0,-1)]
q = deque([src]); seen = {src}
while q:
  cur = q.popleft()
  for d in DIRS:
    nx = step(cur, d)
    if valid(nx) and nx not in seen:
      seen.add(nx); q.append(nx)
  • BFS = shortest path in unweighted graph (layer = distance) ! DFS does not give shortest.
  • Grid is a graph with a directions array; mark visited on enqueue (not dequeue) to avoid dupes !
  • Components/islands = count DFS/BFS launches; bipartite = 2-colour BFS.

Topological Sort

See: prerequisites · build/compile order · task scheduling · alien dictionary.

# Kahn (BFS on in-degree)
q = [v for v in V if indeg[v]==0]
order = []
while q:
  u = q.pop(); order.append(u)
  for w in adj[u]:
    indeg[w] -= 1
    if indeg[w]==0: q.append(w)
# len(order) < V  ⇒  cycle
  • DAG only; Kahn detects cycles (short output = cycle) !
  • DFS variant: post-order append, then reverse. O(V+E).

Union-Find (DSU)

See: dynamic connectivity · number of groups · redundant edge · account merge · Kruskal.

def find(x):
  while p[x] != x:
    p[x] = p[p[x]]      # path compression
    x = p[x]
  return x
def union(a,b): p[find(a)] = find(b)
  • Near-O(1) amortised (α) with path compression + union by rank/size.
  • Choose over DFS when edges arrive incrementally / you keep merging groups !
  • Count components = distinct roots; cycle in undirected = union of already-connected pair.

Heap / Top-K / Two Heaps

See: Kth largest · top-K frequent · merge K lists · median of stream · task scheduler.

# K largest → size-K MIN heap
h = []
for x in a:
  heappush(h, x)
  if len(h) > k: heappop(h)   # evict smallest
return h[0]                    # Kth largest
  • Top-K in O(N log K) with a size-K heap; static Kth = quickselect O(N) avg !
  • Two heaps (max-heap low half + min-heap high half) = running median, O(log N) insert.
  • Python heapq is min-only → push negatives for a max-heap !

Backtracking

See: all subsets/permutations/combinations · N-Queens · word search · Sudoku · partition.

def bt(start, path):
  res.append(path[:])          # record
  for i in range(start, n):
    if skip(i): continue       # prune / dedupe
    path.append(a[i])
    bt(i+1, path)              # i (reuse) vs i+1
    path.pop()                 # undo
  • Choose → explore → un-choose. Returns List<List>.
  • Subsets pass i+1; combinations-with-reuse pass i; permutations use a used[] set.
  • Prune early (bounds, sorted-skip dupes) or it's O(2ᴺ)/O(N!) ! — only viable for small N (≤20).

Dynamic Programming

See: number of ways · min/max cost · can-partition · subsequence (non-contiguous) · overlapping subproblems.

FamilyState
1D (climb, house robber)dp[i] from dp[i−1..]
Knapsack / subset-sumdp[i][cap]
2D grid / edit distancedp[i][j]
LISdp[i] or patience O(N log N)
interval (burst balloons)dp[l][r]
  • Define state, recurrence, base, order. Memoize (top-down) or tabulate (bottom-up).
  • vs sliding window: DP when subarray is a subsequence or condition non-monotonic (Kadane) !
  • vs greedy: DP enumerates all states; greedy commits locally (needs proof) !

Greedy & Intervals

See: merge intervals · meeting rooms · min arrows · jump game · scheduling · activity selection.

intervals.sort(key=lambda x: x[0])   # by start → merge
# OR sort by end → greedy non-overlap pick
for s,e in intervals:
  if s > cur_end: pick += 1; cur_end = e
  • Sort by start to merge; by end to pick max non-overlapping / min removals.
  • Meeting rooms (min rooms) = min-heap of end times, or sweep-line +1/−1.
  • Greedy must be provable (exchange argument) ! if unsure, DP is the safe fallback.

Clue Patterns — Cyclic Sort · Bits · Trie

Cyclic Sort !

  • See: "numbers in 1..N", missing/duplicate, O(1) space. Place a[i] at index a[i]−1, then scan for the mismatch.

Bit Manipulation

  • See: single number → XOR all (pairs cancel). power of 2 → n & (n-1) == 0. subsets → iterate bitmasks. count bits → Brian Kernighan.

Trie

  • See: prefix search, autocomplete, word dictionary, "startsWith". Node = children map + isEnd. Insert/search O(L).

★ Disambiguation Traps

Both fit… choose by
Sliding window vs DP: contiguous+monotonic → window; subsequence / non-monotonic → DP !
Two pointers vs hash: sorted → two ptr (O(1) space); unsorted → hash (avoid sort cost) !
BFS vs Dijkstra: unweighted → BFS; weighted ≥0 → Dijkstra; neg → Bellman-Ford !
Greedy vs DP: provable local choice → greedy; else DP !
Heap vs quickselect: streaming/Top-K → heap; static Kth → quickselect O(N)
DFS vs Union-Find: static graph → DFS; incremental edges → DSU

☐ Before You Code

  • ☐ Read constraints → committed to a target complexity; stated the brute-force baseline.
  • ☐ Named the pattern from shape + objective + clue; have a 1–3 shortlist, picked one with reason.
  • ☐ Edge cases listed: empty · single · all-same · duplicates · negatives · overflow · N=0/1.
  • ☐ Sliding window: delete-on-zero from freq map; two ptr: skip duplicates; binary search: invariant pinned !
  • ☐ Graph: visited marked on enqueue; recursion depth OK (or iterative) for deep inputs !
  • ☐ Stated final time and space complexity out loud.
