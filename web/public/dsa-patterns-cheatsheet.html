How to read & print

  • This sheet is built for recognition at a glance: scan the signal, name the pattern, justify with complexity. Start with the 3 grid cards (4-Lens Scan, Signal→Pattern, Return-Type→Pattern), then the per-pattern reference cards.
  • ! = trap / disambiguation. ☐ = pre-code checklist item.
  • ~30 patterns cover ~95% of LeetCode. Always state the brute-force baseline first, then the pattern.
  • Canonical LeetCode cards near the end list the defining problems per pattern — drill them by recognition only (30 s: name the pattern + target complexity, then check).
  • Companion: the Algorithms primer/cheat sheet holds the implementations. This sheet gets you the name; that one gets you the code — see Pattern → Implementation.
  • Print: Ctrl/⌘-P → A4, margins None, scale 100%, background graphics on. 4 columns built-in.

The 4-Lens 10-Second Scan

  • 1. Constraint lens → target complexity (see next card). Read N + time limit first !
  • 2. Shape lens → data structure. sorted array·linked list·tree·graph·grid·stream·string each branch to a pattern set.
  • 3. Objective lens → the verb. find / count / max-min / shortest / longest / all-possible / Kth / range / order.
  • 4. Clue lens → keyword drops the final hint. palindrome · brackets · cycle · prefix · in-place · 1..N · XOR.

Output = a shortlist of 1–3 patterns, ranked. Commit after stating tradeoffs. Most prompts reveal the pattern from the statement alone — constraints just confirm.

Two Pointers

See: sorted array · pair/triplet · palindrome · in-place partition · merge two sorted.

l, r = 0, n-1
while l < r:
  s = a[l] + a[r]
  if s == t: return [l, r]
  elif s < t: l += 1      # need bigger
  else: r -= 1            # need smaller
  • Opposite-ends (sorted) · same-direction (fast/slow) · two-arrays (merge).
  • O(N) time, O(1) space — beats the hash-map version on a sorted input ! (no alloc).
  • 3Sum = sort + fix i + two-pointer the rest; skip dupes for uniqueness !
  • Container-with-most-water: always move the shorter wall — the taller one can't improve area !
  • Dutch-flag (Sort Colors) = 3 pointers (low/mid/high), one pass, O(1) space.

Sliding Window

See: contiguous subarray/substring + longest/shortest/"at most K" + monotonic condition.

l = 0; best = 0
for r in range(n):
  add(a[r])
  while invalid():        # shrink
    remove(a[l]); l += 1
  best = max(best, r-l+1)
  • Fixed window (size k) vs variable (grow r, shrink l on violation).
  • Amortised O(N): each element enters/leaves once.
  • "exactly K" = atMost(K) − atMost(K−1). Delete from freq map when count hits 0 !
  • Only valid when contiguous and condition monotonic in window size ! (else DP).
  • Min-window-substring: track need counts + a formed counter; shrink while valid, record best.
  • Fixed-window (avg / max-sum of size k): slide by adding a[r] and removing a[r-k].

Prefix Sum & Hashing

See: subarray sum = K · range sum queries · count subarrays · equal 0/1.

# count subarrays summing to k
seen = {0: 1}; s = 0; cnt = 0
for x in a:
  s += x
  cnt += seen.get(s-k, 0)   # prior prefix
  seen[s] = seen.get(s,0)+1
  • prefix[i] = a[0..i]; range(l,r) = prefix[r] − prefix[l−1].
  • Pair prefix with a hash of "prefix value → count/index" for =K / equal-count problems.
  • 2D → integral image; O(1) rectangle sums after O(NM) build.

Monotonic Stack / Deque

See stack: next greater / previous smaller / largest rectangle / stock span / temperatures.

# next greater element
st = []                    # decreasing indices
for i, x in enumerate(a):
  while st and a[st[-1]] < x:
    ans[st.pop()] = x
  st.append(i)
  • Each index pushed/popped once → O(N).
  • Largest Rectangle / Sum of Subarray Minimums = width via stack distance.
  • Monotonic deque: sliding-window max/min in O(N) — pop from back while smaller, front is the answer.

Binary Search (+ on the answer)

See: sorted lookup · rotated array · "smallest X such that cond()" · min-capacity/max-min.

lo, hi = min_ans, max_ans
while lo < hi:
  mid = (lo+hi)//2
  if feasible(mid): hi = mid   # shrink toward boundary
  else: lo = mid+1
return lo
  • On the answer when the decision feasible(x) is monotonic (true for all x ≥ threshold) ! — Koko bananas, Ship-within-D-days, Split-array-largest-sum.
  • Pin the invariant (lo=first-true) to avoid off-by-one / infinite loops !
  • Rotated/find-min = compare mid to hi to pick the sorted half.
  • Find-peak = compare mid to mid+1, climb uphill — O(log N) even unsorted.
  • Two sorted arrays median = binary-search the partition of the smaller array, O(log min(m,n)).

Fast & Slow / Linked List

See: cycle detection · middle node · Nth-from-end · reorder · in-place reverse.

slow = fast = head
while fast and fast.next:
  slow = slow.next
  fast = fast.next.next
  if slow is fast: return True   # cycle
  • Floyd's tortoise/hare: cycle + cycle-start (reset one to head, advance together).
  • Middle = slow when fast hits end. Nth-from-end = gap of N then advance both.
  • Reverse in place with prev/cur/next; use a dummy head to simplify edge cases !

Trees

See: traversal · depth/height · path sum · BST search · LCA · serialize.

def dfs(node):
  if not node: return base
  L = dfs(node.left); R = dfs(node.right)
  return combine(node.val, L, R)   # post-order
  • DFS (pre/in/post) recursion for most tree problems; in-order of a BST is sorted !
  • BFS (queue) for level-order / min-depth / right-side view → returns List<List>.
  • BST op is O(h): O(log n) balanced, O(n) skewed !
  • LCA: recurse; node where left & right both return non-null.

Graph Traversal (BFS / DFS)

See: shortest unweighted · connected components · islands (grid) · flood fill · bipartite.

# grid = graph; 4-dir
DIRS = [(1,0),(-1,0),(0,1),(0,-1)]
q = deque([src]); seen = {src}
while q:
  cur = q.popleft()
  for d in DIRS:
    nx = step(cur, d)
    if valid(nx) and nx not in seen:
      seen.add(nx); q.append(nx)
  • BFS = shortest path in unweighted graph (layer = distance) ! DFS does not give shortest.
  • Grid is a graph with a directions array; mark visited on enqueue (not dequeue) to avoid dupes !
  • Components/islands = count DFS/BFS launches; bipartite = 2-colour BFS.

Topological Sort

See: prerequisites · build/compile order · task scheduling · alien dictionary.

# Kahn (BFS on in-degree)
q = [v for v in V if indeg[v]==0]
order = []
while q:
  u = q.pop(); order.append(u)
  for w in adj[u]:
    indeg[w] -= 1
    if indeg[w]==0: q.append(w)
# len(order) < V  ⇒  cycle
  • DAG only; Kahn detects cycles (short output = cycle) !
  • DFS variant: post-order append, then reverse. O(V+E).
  • Alien Dictionary = build edges from adjacent-word first-difference, then topo-sort the letters !
  • Layered Kahn (process a whole in-degree-0 wave per round) = minimum semesters / parallel courses.

Union-Find (DSU)

See: dynamic connectivity · number of groups · redundant edge · account merge · Kruskal.

def find(x):
  while p[x] != x:
    p[x] = p[p[x]]      # path compression
    x = p[x]
  return x
def union(a,b): p[find(a)] = find(b)
  • Near-O(1) amortised (α) with path compression + union by rank/size.
  • Choose over DFS when edges arrive incrementally / you keep merging groups !
  • Count components = distinct roots; cycle in undirected = union of already-connected pair.
  • Path compression alone = O(log N); add union-by-rank for the tight O(α(N)) !
  • No efficient delete — for "connected as edges are removed", process events backwards as unions.
  • Only detects undirected cycles; directed cycles need three-colour DFS or Kahn !

Heap / Top-K / Two Heaps

See: Kth largest · top-K frequent · merge K lists · median of stream · task scheduler.

# K largest → size-K MIN heap
h = []
for x in a:
  heappush(h, x)
  if len(h) > k: heappop(h)   # evict smallest
return h[0]                    # Kth largest
  • Top-K in O(N log K) with a size-K heap; static Kth = quickselect O(N) avg !
  • Two heaps (max-heap low half + min-heap high half) = running median, O(log N) insert.
  • Python heapq is min-only → push negatives for a max-heap !

Backtracking

See: all subsets/permutations/combinations · N-Queens · word search · Sudoku · partition.

def bt(start, path):
  res.append(path[:])          # record
  for i in range(start, n):
    if skip(i): continue       # prune / dedupe
    path.append(a[i])
    bt(i+1, path)              # i (reuse) vs i+1
    path.pop()                 # undo
  • Choose → explore → un-choose. Returns List<List>.
  • Subsets pass i+1; combinations-with-reuse pass i; permutations use a used[] set.
  • Prune early (bounds, sorted-skip dupes) or it's O(2ᴺ)/O(N!) ! — only viable for small N (≤20).

Greedy & Intervals

See: merge intervals · meeting rooms · min arrows · jump game · scheduling · activity selection.

intervals.sort(key=lambda x: x[0])   # by start → merge
# OR sort by end → greedy non-overlap pick
for s,e in intervals:
  if s > cur_end: pick += 1; cur_end = e
  • Sort by start to merge; by end to pick max non-overlapping / min removals.
  • Meeting rooms (min rooms) = min-heap of end times, or sweep-line +1/−1.
  • Greedy must be provable (exchange argument) ! if unsure, DP is the safe fallback.

Clue Patterns — Cyclic Sort · Bits · Trie

Cyclic Sort !

  • See: "numbers in 1..N", missing/duplicate, O(1) space. Place a[i] at index a[i]−1, then scan for the mismatch.

Bit Manipulation

  • See: single number → XOR all (pairs cancel). power of 2 → n & (n-1) == 0. subsets → iterate bitmasks. count bits → Brian Kernighan.

Trie

  • See: prefix search, autocomplete, word dictionary, "startsWith". Node = children map + isEnd. Insert/search O(L).

Arrays & Hashing

See: "find pair" · duplicates · anagrams · frequency · group-by-signature. Hashing is the universal time-for-space trade: collapse the O(N²) inner "search for a match" into an O(1) lookup.

# Two Sum, one pass
seen = {}                    # value -> index
for i, x in enumerate(a):
  if t-x in seen: return [seen[t-x], i]
  seen[x] = i                # insert AFTER check
  • Three moves: set = membership, map = index lookup, Counter = frequency.
  • Group Anagrams: bucket by canonical key — sorted string O(L log L) or 26-char count tuple O(L) !
  • Longest Consecutive O(N): only start a run at n where n-1 ∉ set — else it degrades to O(N·len) !
  • Keys must be immutable: tuple not list, frozenset not set ! "unhashable type: 'list'".
  • "O(1)" is average — worst case O(N) under collisions; say "O(1) amortised".

DP — The 5-Question Framing

State the answer to all five before writing code — a vague state is the #1 cause of wrong DP.

  1. State — what does dp[i][j] mean, in one precise sentence?
  2. Transition — dp[i] in terms of smaller states (the recurrence).
  3. Base case — dp[0] / dp[empty].
  4. Order — bottom-up direction, or top-down + memo.
  5. Answer — which cell? dp[N] or max(dp)?
  • "dp[i] = answer for first i" is vague; "dp[i] = max non-adjacent sum ending at ≤ i" is precise !
  • Space-optimise only if dp[i] depends on dp[i-1] alone — not when you need the full table to reconstruct !

Tree Recursion Idioms

Postorder thinking: each node asks children "what's your answer?" then combines — height = 1+max(L,R), sum = val+L+R.

# "two values up" — diameter
best = 0
def depth(n):
  if not n: return 0
  L, R = depth(n.left), depth(n.right)
  best = max(best, L+R)     # thru node
  return 1 + max(L, R)      # to parent
  • Return value = what flows up; nonlocal best = what accumulates. Don't mix them in one var ! (Diameter, Max Path Sum, Longest Univalue).
  • BST validate: compare to immediate children is wrong — pass (lo,hi) down and tighten !
  • Inorder of a BST is sorted (→ Kth smallest, iterative stack).
  • Reconstruct: pre+in or post+in with distinct values is unique; pre alone is not.

Trie & Bit Trie

See: prefix · autocomplete · "startsWith" · word dictionary · max XOR pair. Structures a corpus so prefix queries are O(L), not O(N·L).

class Node: children={}; end=False
def insert(w):
  n = root
  for c in w:
    n = n.children.setdefault(c, Node())
  n.end = True                # path encodes the word
  • Node = children map + isEnd flag. Store only the flag, not the word !
  • Ops are O(L) (word length), not O(N words). Wildcard . → recurse over all children.
  • Word Search II = build trie of targets, one grid DFS prunes by trie branch (drops the ×W factor).
  • Bit trie (depth 32): for Max XOR, greedily walk the opposite bit each level → O(N log U) beats O(N²).
  • Memory O(N·L·alphabet) worst case — a hash map beats it for exact-only lookup !

Cyclic Sort & Index-as-Hash

See: values in [1..N] + find missing/duplicate + O(1) space. The array is its own hash — position or sign encodes presence.

# place a[i] at index a[i]-1
i = 0
while i < n:
  j = a[i] - 1
  if a[i] != a[j]: a[i], a[j] = a[j], a[i]
  else: i += 1
# then: index where a[i]!=i+1 is missing
  • Cyclic sort: swap value k to index k-1; amortised O(N) (each value lands once) ! (not O(N²)).
  • Index-as-hash: mark seen by negating a[abs(x)-1]; still-positive index = missing. Handle zeros first !
  • First Missing Positive (hard): cyclic sort, ignore values outside [1,N].
  • Find the Duplicate: treat a[i] as a next-pointer → Floyd's cycle, O(1) space.
  • Both mutate the input — document or restore !

Intervals & Sweep Line

See: merge · meeting rooms · min arrows · car pooling · calendar / max-concurrent · skyline.

# sweep: +1 on start, -1 on end
ev = []
for s,e in iv: ev += [(s,+1),(e,-1)]
ev.sort()
cur = best = 0
for _, d in ev: cur += d; best = max(best,cur)
  • Sort by start to merge; by end for max non-overlap / min removals.
  • Min rooms = min-heap of end times, or the sweep above (best = peak concurrency).
  • Sweep is the difference-array idea in disguise (start +1, end −1, integrate) !
  • Tie-break at equal coordinate: process end (−1) before start (+1) if touching endpoints don't overlap !

Graph Modelling Tricks

Half of "hard" graph problems are really "model it as a graph, then run a standard algo". Name the nodes, edges, and objective before coding.

  • State as a node: (node, hops), (cell, keys_bitmask), (r, c, dir) — the shortest-path stays BFS/Dijkstra over the expanded state graph !
  • Grid → graph: each cell is a node, 4/8 neighbours are edges; weighted cells → Dijkstra, 0/1 edges → 0-1 BFS deque.
  • Implicit graph: word ladder (edge = one-letter change), gene mutation, sliding puzzle — build neighbours on the fly, don't materialise the whole graph.
  • Bidirectional BFS halves the frontier when start and goal are known — expand the smaller side each step.
  • Currency arbitrage = negative cycle on -log(rate) edges → Bellman-Ford.
  • 2-colour BFS = bipartite check / "can split into two groups".

String Patterns

See: palindrome · anagram window · substring search · lexicographic build · encode/decode.

# longest palindrome: expand center
def grow(l, r):
  while l>=0 and r<n and s[l]==s[r]:
    l -= 1; r += 1
  return r-l-1               # length
# try 2N-1 centers (odd + even)
  • Palindrome: two-pointer check O(N); expand-center O(N²); Manacher O(N) if pushed.
  • Anagram / permutation in string: fixed sliding window + 26-count array; compare counts as you slide.
  • Substring search: brute O(N·M); KMP / Z O(N+M) single pattern; Rabin-Karp rolling hash for multi-pattern / dup-substring !
  • Lexicographic smallest (Remove K Digits): monotonic stack, pop bigger char while budget left.
  • Encode/decode list of strings: length-prefix each (len#word) — delimiters are unsafe !

Grid / Matrix Moves

See: islands · flood fill · rotting oranges · shortest maze path · spiral · rotate.

DIRS = [(1,0),(-1,0),(0,1),(0,-1)]
def nbrs(r, c):
  for dr, dc in DIRS:
    nr, nc = r+dr, c+dc
    if 0<=nr<R and 0<=nc<C:   # bounds first
      yield nr, nc
  • Grid = graph with a directions array; flatten cell → id via r*C+c for Union-Find.
  • Shortest maze (unweighted) = BFS; weighted cells = Dijkstra; 0/1 weights = 0-1 BFS (deque) !
  • Multi-source BFS (rotting oranges, nearest-0): seed the queue with all sources at level 0.
  • Rotate 90° in place = transpose then reverse each row; spiral = shrink 4 bounds.
  • Mark visited in-place ('#') to save space — but that mutates input !

DP Worked Recurrences

0/1 vs Unbounded Knapsack

for item in items:            # 0/1: cap DESC
  for c in range(C, w-1, -1):
    dp[c] = max(dp[c], dp[c-w] + v)
# unbounded: inner loop cap ASC (reuse item)
  • Loop direction is the whole difference: backward = use each item once; forward = reuse !

Edit Distance (2D)

if a[i]==b[j]: dp[i][j]=dp[i-1][j-1]
else: dp[i][j]=1+min(dp[i-1][j],    # delete
                     dp[i][j-1],    # insert
                     dp[i-1][j-1])  # replace

LIS in O(N log N)

  • Keep tails[]; binary-search the first tail ≥ x, replace it. len(tails) = LIS length (tails is not a real subsequence) !

Two Heaps & Running Stats

See: median of a stream · sliding-window median · IPO / regret · schedule by two keys.

# lo = max-heap (negated), hi = min-heap
def add(x):
  heappush(lo, -x)
  heappush(hi, -heappop(lo))     # balance top
  if len(hi) > len(lo):
    heappush(lo, -heappop(hi))
median = -lo[0] if len(lo)>len(hi) else (-lo[0]+hi[0])/2
  • Invariant: |len(lo) − len(hi)| ≤ 1, bigger heap holds the median.
  • Sliding-window median = two heaps + lazy deletion (skip stale tops on pop) !
  • IPO / "regret": one heap by cost (affordable gate) feeds a max-heap by profit.
  • Tie-break stability: push tuples (key, counter, item) — heapq isn't stable !

★ Disambiguation Traps

Both fit… choose by
Sliding window vs DP: contiguous+monotonic → window; subsequence / non-monotonic → DP !
Two pointers vs hash: sorted → two ptr (O(1) space); unsorted → hash (avoid sort cost) !
BFS vs Dijkstra: unweighted → BFS; weighted ≥0 → Dijkstra; neg → Bellman-Ford !
Greedy vs DP: provable local choice → greedy; else DP !
Heap vs quickselect: streaming/Top-K → heap; static Kth → quickselect O(N)
DFS vs Union-Find: static graph → DFS; incremental edges → DSU

☐ Before You Code

  • ☐ Read constraints → committed to a target complexity; stated the brute-force baseline.
  • ☐ Named the pattern from shape + objective + clue; have a 1–3 shortlist, picked one with reason.
  • ☐ Edge cases listed: empty · single · all-same · duplicates · negatives · overflow · N=0/1.
  • ☐ Sliding window: delete-on-zero from freq map; two ptr: skip duplicates; binary search: invariant pinned !
  • ☐ Graph: visited marked on enqueue; recursion depth OK (or iterative) for deep inputs !
  • ☐ Stated final time and space complexity out loud.
