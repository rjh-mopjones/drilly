Linear Regression

yhat = w·x + b   min MSE
normal eq: w = (X^T X)^-1 X^T y   (O(p^3))
or gradient descent for big/sparse

Assumes linearity/homoscedasticity/independence. ! Multicollinearity → unstable coefficients.

! Standardize first; pick lambda by CV.

Logistic Regression

p = sigmoid(w·x + b),  log(p/(1-p)) = w·x + b
min log-loss (convex);  grad = X^T (p - y)
  • Classification, linear boundary; multiclass via softmax/OvR.
  • Interpret via odds ratios; the honest baseline.

Naive Bayes / kNN

  • NB: P(y|x) ∝ P(y)·prod P(x_i|y); naive independence; Laplace smoothing; text/spam. ! Log-space.
  • kNN: lazy, vote of k nearest; k = bias/variance. ! MUST scale; curse of dimensionality.

Decision Trees

split to cut impurity: Gini = 1 - sum(p_k^2)
(or entropy);  regression -> variance/MSE
  • No scaling, mixed types, interpretable.
  • ! High variance → prune / max_depth / min_leaf. Unstable.

Random Forest

  • Bagging (bootstrap) + random feature subset per split → decorrelate → average → less variance.
  • OOB error = free validation. Parallel, robust, low tuning.
  • Knobs: n_estimators, max_features, max_depth. ! Can't extrapolate.

Gradient Boosting

F_m = F_{m-1} + eta * h_m
h_m fits the NEGATIVE GRADIENT of the loss
(= residuals for MSE)
  • eta (shrinkage) vs n_estimators; depth = interaction order.
  • Low bias, overfits → early stopping / subsample. !

SVM & Kernels

max margin = min 0.5*||w||^2 (+ C*slack)
support vectors define the boundary
  • C: large = hard fit, small = wide margin.
  • Kernel trick: K(x,x') = implicit high-dim dot product → non-linear.
  • RBF `exp(-gamma·||x-x'||^2)`; gamma = reach. ! Scale; O(n^2)-O(n^3).

k-Means

min within-cluster SS (inertia)
Lloyd: assign nearest centroid -> recompute -> repeat
init: k-means++
  • Local min (restart); choose k by elbow/silhouette.
  • ! Assumes spherical/equal clusters; scale; sensitive to outliers.

Hierarchical / DBSCAN / GMM

  • Hierarchical: linkage (Ward), dendrogram, cut for k, O(n^2).
  • DBSCAN: density (eps, min_samples), arbitrary shapes + noise, no k. ! Varying density.
  • GMM + EM: soft, elliptical clusters; k-means = GMM special case.

PCA

directions of max variance =
eigenvectors of Cov = (1/n) X^T X
(compute via SVD of centered X)
  • Rank by explained variance; pick #comp by cumulative %.
  • ! Standardize; linear + unsupervised; = min reconstruction error.

t-SNE / UMAP / LDA

  • t-SNE: local structure, VIZ only. ! Don't cluster on it / read distances.
  • UMAP: faster, more global; general-purpose.
  • LDA: SUPERVISED, max between/within-class variance (≤ C-1 dims).

☐ Which Algorithm? / Interview

  • ☐ Tabular → gradient-boosted trees (XGB/LGBM) by default.
  • ☐ Need interpretability/baseline → linear/logistic.
  • ☐ Small-medium, high-dim → SVM; text → Naive Bayes; simple → kNN (scale!).
  • ☐ Cluster: spherical→k-means, shapes+noise→DBSCAN, soft→GMM.
  • ☐ Reduce dims: linear/decorrelate→PCA, viz→t-SNE/UMAP, supervised→LDA.
  • ☐ Derive: logistic grad = X^T(p-y); RF cuts variance via decorrelation; GBM fits neg-gradient; PCA = eigen/SVD of covariance.
  • ☐ State the objective, the fit, the key knob, the complexity, the tradeoff.
