Goroutines & the Scheduler (G·M·P)

flowchart TD G["Goroutines (G)
2KB stack, grows"] --> P["Logical procs (P)
= GOMAXPROCS"] P --> M["OS threads (M)"] M --> CPU["CPU cores"] P -.->|"local runqueue
empty → steal"| P2["other P"]

M:N scheduler — many G multiplexed onto few M via P. Blocking syscall → M parks, P hands off to a fresh M (work continues). Preemptive since 1.14 (async, signal-based). 1.25 runtime is cgroup-aware: GOMAXPROCS respects container CPU limits natively.

  • go f() ≈ cheap (µs, 2KB). But every goroutine needs an answer to "how does this end" — closed chan, cancelled ctx, or finite loop. No answer = leak !
  • runtime.Gosched() yields; GOMAXPROCS(n) caps parallelism (default NumCPU).

Channels

close — who & rules

  • The sender closes, never the receiver. One closer only.
  • send on closed = panic !; close of closed = panic !; recv on closed = zero value + ok==false (drains buffer first).
  • v, ok := <-ch tests closed; for v := range ch exits when closed.
select {
case v := <-ch:      use(v)
case out <- x:        // send
case <-ctx.Done():    return ctx.Err()
default:              // non-blocking
}
  • select picks a ready case at random; default makes it non-blocking.

Memory Model & Races

  • A data race (concurrent access, ≥1 write, no synchronisation) is undefined behaviour ! — not "eventually consistent". Can corrupt, not just stale-read.
  • No happens-before edge → writes from one goroutine may be invisible/reordered in another.

happens-before sources

EdgeEstablishes
chan send → corresponding recvsend (and prior writes) visible to receiver
chan close → recv that observes itsame
mu.Unlock() → next mu.Lock()critical-section writes published
sync/atomic store → loadrelease/acquire ordering
once.Do returninit writes visible to all callers

Always run go test -race. The detector is sound (no false positives) but only flags races it observes at runtime — exercise the concurrent paths.

Slices, Arrays & Maps

Slice = (ptr, len, cap) header

s := []int{1,2,3}
t := s[:2]          // shares backing array !
t = append(t, 9)    // OVERWRITES s[2] if cap allows !
u := append([]int{}, s...) // safe copy
b := make([]byte, n) // pre-size to avoid regrowth
  • append reallocates only when len > cap; until then writes alias the original !
  • Re-slicing keeps the whole backing array alive (memory leak holding a small slice of a huge buffer) ! — copy out.
  • Use the 3-index slice s[a:b:c] to cap and force a fresh array on next append.

Maps

  • Write to a nil map panics !; read of nil map is fine (zero value). m := map[K]V{} or make.
  • Iteration order is randomised — never rely on it; sort keys for determinism.
  • Concurrent map read+write panics ("fatal error: concurrent map ...", not recoverable) ! — guard with a Mutex or sync.Map.
  • v, ok := m[k] distinguishes "absent" from "zero value".

Interfaces & nil

  • An interface value is a (type, value) tuple. It's nil only when both are nil.

The typed-nil trap !

func do() error {
  var e *MyErr = nil
  return e            // (*MyErr, nil) — NOT nil iface !
}
if do() != nil { /* ALWAYS true */ }
// Fix: return nil explicitly, or
//   if e == nil { return nil }
  • Assertion: v, ok := x.(T) (safe); x.(T) without ok panics on mismatch !
  • switch v := x.(type) { case T: ... } for multi-type dispatch.
  • any = alias for interface{} (1.18). Accept interfaces, return concrete types. Keep interfaces small (1–2 methods) and define them on the consumer side.

Errors

  • Errors are values, returned as the last result. No exceptions. if err != nil { return ... } — handle or propagate, don't ignore.
  • Wrap with %w to preserve the chain: fmt.Errorf("load %s: %w", id, err).
  • errors.Is(err, ErrNotFound) — sentinel match through the chain.
  • errors.As(err, &target) — extract a typed error from the chain.
  • Sentinels: var ErrX = errors.New("..."). Custom: implement Error() string (+ Unwrap()).

panic / recover — boundaries only

defer func() {
  if r := recover(); r != nil {
    log.Printf("recovered: %v", r)
  }
}()
  • recover works only inside a deferred func !. Use for true invariants / server top-of-handler — not control flow.
  • A panic in a goroutine with no recover crashes the whole process !

defer / panic / recover Timing

  • Deferred calls run LIFO at function return (not block/scope end) — including on panic-unwind.
  • Args are evaluated at the defer statement, body runs later !:
x := 1
defer fmt.Println(x)   // prints 1
x = 2                  // (captured at defer time)

// Closure sees the LATER value:
defer func(){ fmt.Println(x) }() // prints 2

Named returns + defer

func f() (err error) {
  defer func(){ if err != nil { err = wrap(err) } }()
  return doThing()      // defer can mutate err !
}

defer in a loop !

for _, p := range paths {
  f, _ := os.Open(p)
  defer f.Close()       // STACKS — none close until f() returns !
}

Receivers — value vs pointer

ReceiverEffect
func (t T) M()operates on a copy — mutations don't persist
func (t *T) M()mutates the original; required to change state
  • Use a pointer receiver to mutate, for large structs (avoid copy), or for any type holding a sync.Mutex ! (a value receiver copies the lock).
  • Be consistent: if any method needs a pointer receiver, give them all pointer receivers.

Method sets & interfaces !

  • *T's method set includes both value- and pointer-receiver methods; T's includes only value-receiver ones.
  • So if M has a pointer receiver, only *T satisfies the interface — a T value won't. (And you can't take the address of a map element / non-addressable value to call it.)

Generics (1.18+) & Iterators

func Map[T, U any](s []T, f func(T) U) []U {
  r := make([]U, len(s))
  for i, v := range s { r[i] = f(v) }
  return r
}
type Number interface{ ~int | ~float64 }
func Sum[T Number](xs []T) T { ... }
  • Constraints are interfaces; ~int = "any type whose underlying type is int". comparable for map keys / ==.
  • Type inference usually lets you omit explicit type args.
  • Don't over-reach — if one concrete type or a plain interface works, skip generics. They don't monomorphise like Rust/C++ (dictionary/shape-based) so they're not always faster.
  • (1.23) range-over-func iterators: iter.Seq[T] / iter.Seq2[K,V] drive for x := range myIter.

Runtime, GC & Performance

  • Concurrent tri-colour mark-sweep GC, non-generational, sub-ms STW pauses. You tune frequency, not pauses.
  • GOGC (default 100) — grow heap to 2× live set before next GC; raise to trade RAM for fewer GCs.
  • GOMEMLIMIT (1.19) — soft heap ceiling; turns OOM-kills into back-pressure (GC works harder near the limit).

Allocation = the latency tax

  • Escape analysis: values that outlive their frame escape to the heap. go build -gcflags=-m shows decisions.
  • Levers: pass small structs by value (stay on stack); pre-size slices/maps; sync.Pool for transient buffers; strings.Builder over +=.
  • Measure first — refactors that "look" alloc-free can defeat inlining and regress. pprof heap + -benchmem.

Context — Cancellation & Deadlines

  • Carries a Done() chan (closes when to stop) + Err() (Canceled / DeadlineExceeded). Cancellation is cooperative — closing Done() kills nothing; each goroutine must watch it.
  • Build a tree from context.Background(). Cancelling a parent cancels all descendants.
  • Pass ctx as the first param of any I/O / work-spawning func; never store it in a struct; never pass nil (context.TODO()).
ctx, cancel := context.WithTimeout(parent, 5*time.Second)
defer cancel()   // ALWAYS — else timer+node leak till deadline !
  • WithValue only for request-scoped cross-cutting data (trace/auth IDs) — never optional params !
  • Forgetting defer cancel() = the #1 ctx bug; go vet lostcancel flags it.
  • Detach fire-and-forget work with context.WithoutCancel(ctx) (1.21) — keeps values, severs cancellation — then re-bound with your own WithTimeout.

Concurrency Patterns

Pipeline

Stages joined by channels; each ranges its input, sends output, defer close(out) when input drains.

Fan-out / fan-in

func merge(cs ...<-chan int) <-chan int {
  out := make(chan int); var wg sync.WaitGroup
  for _, c := range cs {
    wg.Add(1)
    go func(c <-chan int){ defer wg.Done()
      for v := range c { out <- v } }(c)
  }
  go func(){ wg.Wait(); close(out) }() // close AFTER all senders !
  return out
}
  • Fan-in's close must run once, after wg.Wait — per-source close = send on closed chan panic !
  • Worker pool: fixed N goroutines draining one jobs chan — bounds concurrency, protects DB/FD limits vs one-goroutine-per-job.
  • Done pattern: thread ctx.Done() into every stage so early consumer exit unwinds the whole pipeline (no leak).

Timers, Tickers & time

  • time.Time holds a monotonic reading too — use it for elapsed (time.Since), wall clock for timestamps. Compare with .Equal(), not == !
  • time.After(d) in a hot select loop leaks a Timer per iteration until it fires ! — use t := time.NewTimer(d), t.Stop(), reset.
  • time.Tick can never be stopped — leaks; use time.NewTicker + defer tk.Stop().
t := time.NewTimer(timeout)
defer t.Stop()
select {
case <-t.C:            return ErrTimeout
case r := <-work:      return r
case <-ctx.Done():     return ctx.Err()
}
  • (1.23) Timers/Tickers are GC'd when unreferenced even if not stopped, and C is unbuffered — but still Stop for clarity/back-compat.

Struct Embedding & Composition

  • Field order affects size (alignment padding) — group by size to shrink hot structs.
  • Embed = type with no field name ⇒ its fields/methods are promoted to the outer type.
type Server struct {
  Logger        // embedded, no name
  addr string
}
s.Log("up")     // == s.Logger.Log("up")
  • Not inheritance ! — no subtype relation (Server is not a Logger), no virtual dispatch, no super. Pure compile-time name resolution.
  • Outer method with same name shadows the promoted one; reach the inner via s.Logger.Log().
  • Embed an interface (or a type implementing one) ⇒ outer satisfies it for free by delegation. Use for shared mechanics, not "is-a" trees.

net/http Server — Timeouts & Shutdown

! A zero-value http.Server{} / http.ListenAndServe has no timeouts — a Slowloris client dripping one byte holds a goroutine+FD forever. Always build an explicit server.

KnobPhase it bounds
ReadHeaderTimeoutaccept → end of headers (cheapest Slowloris guard)
ReadTimeoutaccept → end of body (superset of headers)
WriteTimeoutend of header read → response written
IdleTimeoutkeep-alive gap between requests
  • Blanket Write/ReadTimeout are set at accept — hostile to SSE/streaming. Use http.NewResponseController (1.20) to reset deadlines per phase.
  • Graceful shutdown: srv.Shutdown(ctx), never Close(). Treat http.ErrServerClosed as success. Use a fresh Background() ctx for the drain deadline — reusing the cancelled signal ctx returns instantly !
  • signal.NotifyContext(ctx, os.Interrupt, SIGTERM) ties SIGTERM to a ctx. Background workers/websockets aren't drained by Shutdown — track separately.

http.Client & Transport

! http.DefaultClient / http.Get have no timeout — a hung upstream blocks forever and leaks goroutines+conns under load.

client := &http.Client{
  Timeout: 10*time.Second,     // dial+redirects+body
  Transport: &http.Transport{
    MaxIdleConns:        100,
    MaxIdleConnsPerHost: 10,   // default 2 — raise for hot upstreams
    IdleConnTimeout:     90*time.Second,
}}
  • Reuse one client (the Transport is the pool). New client per request defeats keep-alive → ephemeral-port exhaustion.
  • Always defer resp.Body.Close() and drain (io.Copy(io.Discard, resp.Body)) — an unread body can't return the conn to the pool !
  • Per-request cancellation: http.NewRequestWithContext — thread r.Context() so a disconnecting client tears down the chain. Cap untrusted bodies with io.LimitReader.

database/sql — Pool, Tx, Scan

  • Import a driver for its side effect: _ "github.com/jackc/pgx/v5/stdlib" registers it; sql.Open finds it by name and does not dial — call PingContext to fail fast.
  • *sql.DB is a connection pool, not a connection — concurrency-safe. Keep one per process; a new DB per request multiplies pools and blows max_connections !
KnobDefault / trap
SetMaxOpenConns0=unlimited — cap it vs DB's limit ÷ instances
SetMaxIdleConns2 — raise near MaxOpen or churn TCP+TLS+auth
SetConnMaxLifetime∞ — set ~5m or stale conns after failover/wait_timeout !
  • Parameterised queries ($1/?) are prepared server-side ⇒ injection-safe. Never fmt.Sprintf user input into SQL !
  • Rows: always defer rows.Close() and check rows.Err() after the loop; NULLs need sql.NullString or pointers. Tx: defer tx.Rollback() (no-op after Commit).
  • pgbouncer transaction-pooling breaks database/sql prepared-statement cache — disable stmt cache / use simple protocol !

Retries, Backoff & Jitter

  • Precondition: only retry idempotent ops ! — a timed-out POST /charge may have succeeded server-side; a retry double-charges. Add an idempotency key first.
  • Only retry retryable errors: timeouts, resets, 429, 502/503/504. Never a 400 or context.Canceled.
backoff := min(cap, base*(1<<attempt))
sleep := time.Duration(rand.Int63n(int64(backoff))) // FULL jitter
select {
case <-ctx.Done(): return ctx.Err() // respect deadline !
case <-time.After(sleep):
}
  • Full jitter de-correlates clients — without it every client retries at the same instant (thundering herd). Cap the backoff; bound attempts; add a global retry budget (≤10% of traffic).
  • HTTP: the request body is consumed on attempt 1 — buffer it + set req.GetBody, or use hashicorp/go-retryablehttp.

Circuit Breaker · Bulkhead · Rate Limit

Breaker (3-state)

StateBehaviour
Closedpass through, count failures

  • Trip on a ratio over a minimum sample, not raw counts (sony/gobreaker). Pair with a per-call timeout or "open" still waits the full timeout !
  • Bulkhead = resource isolation: a buffered chan as a semaphore caps concurrency per dependency, so one sick dep can't starve the shared pool.
sem := make(chan struct{}, 10)
select {
case sem <- struct{}{}: defer func(){ <-sem }()
case <-ctx.Done():      return ctx.Err() // shed, don't queue
}

Rate limit — x/time/rate token bucket

  • Allow() reject-if-over (429) · Wait(ctx) throttle outbound · Reserve() inspect delay.
  • Per-client: map[key]*Limiter leaks — add a background sweeper evicting idle keys ! Token bucket beats fixed-window (which allows 2× burst across the boundary). Limits are per-process — true global needs Redis/gateway.

Deadline Budget & Load Shedding

  • A 2s client deadline fanning to 4 hops: passing the same ctx everywhere is right for cancellation but wrong for budget — each hop must spend a share, leaving egress reserve for the response trip !
deadline, _ := ctx.Deadline()
remaining := time.Until(deadline) - egressReserve
child, cancel := context.WithTimeout(ctx, remaining/hopsLeft)
  • Under overload, more retries make it worse. Load shedding — reject early (429/503) when queue depth / latency exceeds a threshold — beats "add retries": it protects goodput and prevents congestion collapse.
  • singleflight collapses duplicate cache-miss loads — but watch 3 failure modes: one slow leader stalls all waiters, a bad result is shared to all, and a hot key serialises; use Forget and per-key timeouts.

Security — crypto & untrusted input

  • ! crypto/rand not math/rand for anything unpredictable (tokens, salts, nonces, keys) — math/rand is a deterministic PRNG an attacker reproduces.
  • Compare secrets with subtle.ConstantTimeCompare / hmac.Equal — ==/bytes.Equal short-circuit and leak via timing.
  • Passwords: adaptive KDF — bcrypt (default, salts + cost embedded; 72-byte cap) or argon2id (memory-hard). Never plain SHA-256.
r.Body = http.MaxBytesReader(w, r.Body, 1<<20) // cap BEFORE decode
dec := json.NewDecoder(r.Body)
dec.DisallowUnknownFields()   // reject typos / mass-assignment
  • Decompression bombs: cap inflated output with io.LimitReader; a few KB gzip → GBs. JSON depth capped at 10000.
  • Data race = undefined behaviour, not a stale read — a torn interface/slice write can produce a garbage pointer the runtime derefs → real corruption from pure Go, no unsafe !

Web vulns & Supply chain

  • SSRF: user-supplied URLs can hit 169.254.169.254 (cloud metadata) / internal services. Validate the resolved IP in a custom DialContext (closes DNS-rebind window) and re-check on redirects via CheckRedirect.
  • Path traversal: filepath.Join cleans but does not contain — Join("/srv", "../etc/passwd") escapes. Prefix-check after clean, or (1.24) os.OpenRoot — traversal-proof by construction.
  • Templates: html/template auto-escapes (context-aware); text/template does not — same API, trivial to import the wrong one → XSS ! Never wrap untrusted data in template.HTML/JS/URL.

Supply chain

  • go.sum = per-module hashes (integrity); first sighting verified against GOSUMDB transparency log. Don't disable — scope private repos with GOPRIVATE, never GOSUMDB=off !
  • govulncheck adds call-graph analysis — reports only vulns you actually reach. Run in CI alongside pinned versions (MVS) + committed go.sum.

Cloud-Native & Observability

  • Minimal image: multi-stage, CGO_ENABLED=0 (static binary), -ldflags="-s -w", land in distroless/static:nonroot (ships CA certs + nonroot user). Forgetting CGO_ENABLED=0 → container exits "no such file or directory" !
  • Container CPU trap: pre-1.25 GOMAXPROCS = host NumCPU, ignoring the cgroup quota → CFS throttling + GC stalls. Fix: go.uber.org/automaxprocs (≤1.24); 1.25 runtime is cgroup-aware natively ! Set GOMEMLIMIT ≈ 90% of the mem limit to dodge the OOM-killer.

Three pillars

  • Logs: log/slog (1.21) JSON handler to stdout, key-value attrs, logger.With(traceID).
  • Metrics: prometheus/client_golang, histograms for p99; watch label cardinality (no user IDs/URLs) !
  • Traces: OpenTelemetry (otelhttp/otelgrpc). Inject the trace ID into slog records to correlate log↔trace.

Design Idioms

Functional options

type Option func(*Server)
func WithTimeout(d time.Duration) Option {
  return func(s *Server){ s.timeout = d }
}
func NewServer(addr string, opts ...Option) *Server {
  s := &Server{addr: addr, timeout: 30*time.Second}
  for _, o := range opts { o(s) }
  return s
}
  • Beats positional ctors (no overloading) & config structs (can't tell unset from zero). Add options without breaking call sites. Skip it if all fields are required.
  • Package per capability: name packages by what they do (billing), not by layer. util/common/models = import-cycle magnets ! internal/ is a compiler-enforced privacy boundary.
  • DI = pass deps as args, wire once at main(). "Accept interfaces (defined by the consumer), return structs." Reach for wire/fx only for large graphs, not correctness.

★ Code Review Checklist

Receiver type — value vs pointer

  • ☐ Pointer receiver where the method must mutate (value receiver silently no-ops).
  • ☐ No value receiver on a type holding a sync.Mutex/WaitGroup — copies the lock !
  • ☐ Receiver kind consistent across all methods of the type.

Goroutine / closure capture

  • ☐ Loop var captured by a goroutine/closure — shared-var bug pre-1.22; per-iteration & safe in 1.22+, but confirm the module's go directive !
  • ☐ Loop value passed as an arg / re-shadowed (v := v) where older semantics apply.

Concurrency / shared state

  • ☐ Every var touched by >1 goroutine (maps, slices, counters, flags) is read/written under the same lock or via atomic.
  • ☐ Map access guarded; no struct-with-mutex copies; -race clean in CI.

Error handling

  • ☐ No dropped errors (_ = or unchecked); wrap with %w where a caller inspects.
  • ☐ defer x.Close() error checked where it matters (writers/flush).

Nil

  • ☐ Nil-pointer deref guarded; no write to a nil map.
  • ☐ No typed-nil returned as an error/interface (!= nil always true) !; nil channel/func paths considered.

Channels

  • ☐ Direction-typed params; buffering size justified.
  • ☐ Exactly one closer (the sender); no send-on-closed / double-close; select has default/ctx where non-blocking intended.

Defer timing

  • ☐ Fires at function return — present on every early-return path; not stacking inside a loop body unless intended !
  • ☐ Deferred-arg value captured at the defer point is the one you mean; per-iteration cleanup extracted to a helper.

No receiver / no close ⇒ producer parks forever, its stack & captured memory never freed. Fix: ctx cancellation, a done channel, buffered/closed channels, or select with <-ctx.Done(). Every go needs a defined exit.
