Paradigm Decision Tree

  • Brute force first — get correctness + a complexity to beat.
  • Greedy: a locally-best choice is provably globally optimal (exchange argument). Fast, but prove it.
  • Divide & conquer: split into independent subproblems, combine (sort, search).
  • DP: overlapping subproblems + optimal substructure → memoize.
  • Graph: model as nodes/edges → BFS/DFS/shortest-path/flow.
  • ! Greedy fails? It usually means DP.

Recurrences & Master Thm

T(n) = a T(n/b) + O(n^d)
compare d vs log_b(a):
  d >  log_b a : O(n^d)
  d == log_b a : O(n^d log n)
  d <  log_b a : O(n^(log_b a))
  • Merge sort: 2T(n/2)+O(n) → n log n.
  • Binary search: T(n/2)+O(1) → log n.
  • Karatsuba: 3T(n/2)+O(n) → n^1.585.

Binary Search on the Answer

lo, hi = min, max
while lo < hi:
  mid = lo + (hi-lo)/2   # no overflow
  if feasible(mid): hi = mid
  else:             lo = mid+1
return lo               # first feasible

! Works when feasibility is monotonic. Nail the invariant + which side keeps mid, or you infinite-loop.

DP Recipe

  • 1. State — what minimal info defines a subproblem? (indices, remaining capacity, mask)
  • 2. Transition — how does a state build from smaller ones?
  • 3. Base case — smallest subproblems.
  • 4. Order — memoize (top-down) or fill in dependency order (bottom-up).
  • 5. Answer — which state(s) hold it. Complexity = #states x transition cost.

Classic: knapsack, LCS/edit distance, LIS (n log n w/ patience), coin change, grid, interval, bitmask, tree DP.

Traversal & Backtracking

def backtrack(state):
  if goal(state): record(); return
  for choice in options(state):
    if valid(choice):
      apply(choice)
      backtrack(state)
      undo(choice)   # the key step
  • Prune early (bounds/constraints) to cut the exponential.
  • Subsets 2^n, permutations n!, combinations nCk.

Number Theory

gcd(a,b) = gcd(b, a mod b)   # Euclid
lcm = a / gcd * b
fast pow: square-and-multiply O(log e)
sieve of Eratosthenes: O(n log log n)
Fermat: a^(p-1) == 1 (mod p), p prime
inverse: a^(p-2) mod p

! Take mod at every step to avoid overflow; watch negative mod.

Randomized & Selection

  • Quickselect: partition around a random pivot → O(n) average k-th smallest; median-of-medians = O(n) worst.
  • Reservoir sampling: pick k from a stream of unknown length, uniform, O(1) memory.
  • Fisher-Yates: unbiased shuffle in O(n) — swap i with random j in [i, n).
  • Monte Carlo (fast, maybe wrong) vs Las Vegas (always right, random time).

P, NP & When Stuck

  • P: solvable in poly time. NP: a solution is checkable in poly time.
  • NP-complete: hardest in NP (SAT, TSP-decision, subset-sum, vertex cover). No known poly algorithm.
  • Show hardness by reduction from a known NP-hard problem.
  • NP-hard in interview → say so, then: approximation, heuristic/greedy, DP over small n, or branch & bound.

☐ Interview Playbook

  • ☐ Read n / constraints → set the complexity target before choosing an algorithm.
  • ☐ Brute force first (state it), then optimize toward the target.
  • ☐ Match the paradigm: sorted/monotonic → binary search; overlap+substructure → DP; provable local → greedy; nodes/edges → graph.
  • ☐ Name the recurrence & solve it (Master Theorem) for D&C.
  • ☐ For DP: state → transition → base → order → answer, out loud.
  • ☐ Pick the graph algorithm from weights/signs (BFS / Dijkstra / Bellman-Ford / Floyd-Warshall).
  • ☐ Prove greedy (exchange argument) or fall back to DP.
  • ☐ Check edge cases: empty, single, duplicates, overflow, negative, disconnected.
