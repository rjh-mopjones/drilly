Data Model & Dunders

Everything is an object — ints, functions, classes, modules all have a type, id, and refcount. Behaviour is protocol-driven: built-in syntax dispatches to __dunder__ methods on the type, not the instance.

SyntaxCalls
len(x)type(x).__len__
x[k] / x[k]=v__getitem__ / __setitem__
for _ in x__iter__ → __next__
x == y / x < y__eq__ / __lt__
x + y__add__ (then __radd__)
x()__call__
with x__enter__/__exit__
repr(x)/str(x)__repr__/__str__
  • Implement the protocol → your object plugs into the language ("duck typing"). Don't subclass a base just to get syntax.
  • Special methods are looked up on the type, bypassing __getattr__ and the instance dict ! — a per-instance obj.__len__ won't be used by len().

Names, Binding & is vs ==

  • Python has names, not variables. x = obj binds a name to an object; a = b makes two names for the same object (aliasing) — no copy.
  • == → value equality (__eq__). is → identity (same id()). Use is only for singletons: is None, is True/False.

Identity surprises !

a = 256; b = 256; a is b   # True  (small-int cache -5..256)
a = 257; b = 257; a is b   # False (usually)
x = "hi"; y = "hi"; x is y # True  (interned literal)
  • Small-int cache & string interning are CPython optimisations — never write logic that depends on them !
  • Strong + dynamic typing: types checked at runtime, never implicitly coerced. 1 + "2" → TypeError (no JS-style concat).
  • Truthiness: if x: calls __bool__, else __len__ (empty = falsy), else True. Falsy: 0 0.0 "" [] {} () set() None.

Mutable vs Immutable · Copies

MutableImmutable
list, dict, setint, float, bool, str, bytes
bytearray, most objectstuple, frozenset, None
  • Only hashable (⇒ effectively immutable) objects can be dict keys / set members. tuple ok; list ⇒ TypeError: unhashable !
  • A tuple is immutable but not deeply frozen: t = ([1],); t[0].append(2) mutates it !

Pass-by-object-reference

def f(lst, n):
    lst.append(1)   # caller SEES this (mutation)
    n += 1          # rebinds local only — caller unaffected

Shallow vs deep !

import copy
a = [[1,2],[3,4]]
b = a[:]                 # shallow: b[0] IS a[0]
b[0].append(9)           # also mutates a[0] !
c = copy.deepcopy(a)     # fully independent

Slicing, list(), dict(), copy.copy all copy one level. Nested mutables are still shared.

Mutable Default Args & Late Binding

The def f(x, acc=[]) bug !

def add(x, acc=[]):      # default made ONCE at def time
    acc.append(x); return acc
add(1)  # [1]
add(2)  # [1, 2]  ← same list persists!

Defaults are evaluated once, when the def executes, and stored on the function object (f.__defaults__). Fix: sentinel default.

def add(x, acc=None):
    if acc is None: acc = []
    acc.append(x); return acc

Late-binding closure !

fs = [lambda: i for i in range(3)]
[f() for f in fs]        # [2, 2, 2] — i looked up at CALL
# Fix: bind now via default arg
fs = [lambda i=i: i for i in range(3)]  # [0,1,2]

Closures capture the variable, not its value at creation. Loop var is read when the lambda runs, by which point the loop finished.

dict Internals & collections

  • Hash table, open addressing. Key must be hashable: consistent __hash__ + __eq__. Equal objects must hash equal !
  • Insertion-ordered since 3.7 (language guarantee, not just CPython). Compact layout also shrank memory.
  • Mutating a key's hash/equality after insertion corrupts lookups — never use a mutable key.
  • Don't add/remove keys while iterating → RuntimeError: dict changed size ! Iterate over list(d).

Scope: LEGB · global · nonlocal

Name lookup order: Local → Enclosing → Global → Built-in. Assignment anywhere in a function makes the name local for the whole function !

x = 10
def outer():
    x = 20               # enclosing
    def inner():
        nonlocal x       # rebind enclosing x
        x += 1
    inner(); return x    # 21
  • global n → rebind a module-level name. nonlocal n → rebind the nearest enclosing function's name.
  • Reading a global is fine without global; assigning to it needs the declaration or you get UnboundLocalError !

Counter closure (needs nonlocal)

def make_counter():
    n = 0
    def inc():
        nonlocal n; n += 1; return n
    return inc

Functions & functools

Signature design

def f(a, b, /, c, *args, d, **kwargs): ...
#     |pos-only| normal |*| kw-only |
  • / → params before it are positional-only. * (or *args) → params after are keyword-only.
  • *args collects extra positionals (tuple); **kwargs extra keywords (dict).

functools

ToolUse
partial(f, x)freeze leading args
reduce(f, seq)fold; prefer sum/loop when clearer
@lru_cache(maxsize=)memoise pure fn
@cache (3.9)unbounded lru_cache
@wrapspreserve metadata in decorators

! lru_cache keeps refs to args/results forever (memory leak on unbounded/large keys), and needs hashable args. Never cache a method on a long-lived instance — it pins self.

Decorators

A decorator is a callable taking a function and returning a replacement. @dec is pure sugar:

@dec
def f(): ...
# ≡ f = dec(f)

Preserve identity !

from functools import wraps
def log(fn):
    @wraps(fn)                 # keeps __name__, __doc__, sig
    def wrapper(*a, **kw):
        print("call", fn.__name__)
        return fn(*a, **kw)
    return wrapper

Without @wraps, the function's name becomes wrapper, docstring & signature are lost, and tooling/introspection breaks.

Decorator with args = 3 layers

def retry(n):                  # 1: takes args
    def deco(fn):              # 2: takes fn
        @wraps(fn)
        def inner(*a, **kw):   # 3: the call
            for i in range(n):
                try: return fn(*a, **kw)
                except Exception:
                    if i == n-1: raise
        return inner
    return deco
@retry(3)
def flaky(): ...

Stacked decorators apply bottom-up: @a @b def f ≡ a(b(f)). Put @staticmethod/@classmethod outermost.

Generators & Iterators

  • Iterable: has __iter__ (can be looped). Iterator: has __next__ + returns self from __iter__; stateful, exhausts once.
  • next() past the end raises StopIteration (the loop's stop signal).

yield = lazy

def read_big(path):
    with open(path) as fh:
        for line in fh:     # O(1) memory
            yield line.strip()

Calling a generator fn returns a generator (runs nothing yet); each next() resumes to the next yield. State (locals, position) is preserved between resumes.

genexpr vs list-comp

sum(x*x for x in big)   # streams, no list built
squares = [x*x for x in big]  # materialises all

! A generator is consumed once — a second loop yields nothing. yield from sub delegates; send/throw/close drive coroutine-style generators. itertools: chain islice groupby count cycle tee.

Comprehensions & Functional

[x*2 for x in xs if x>0]          # list
{k: v for k, v in pairs}          # dict
{x % 3 for x in xs}               # set
(x*2 for x in xs)                 # generator (lazy)

Nested & conditional

flat = [x for row in matrix for x in row]   # outer-to-inner
labels = [a if c else b for c in flags]     # ternary in expr
  • Read nested loops left-to-right, same order as written fors. Beyond 2 levels ⇒ use a real loop for readability !
  • Comprehensions have their own scope (3.x) — the loop var does not leak. Faster than an append loop (specialised bytecode).
  • Prefer comprehensions over map/filter + lambda; map only wins with an existing named fn.

Walrus :=

while (line := f.readline()):
    process(line)
[y for x in data if (y := f(x)) > 0]   # reuse computed y

Classes & OOP

MethodRole
__new__(cls)allocates/returns the instance (rare; immutables, singletons)
__init__(self)initialises the already-made instance
class C:
    def m(self): ...              # instance
    @classmethod
    def from_str(cls, s):        # alt constructor
        return cls(...)

    def util(x): ...             # no self/cls
  • @classmethod → alternative constructors; gets cls so it respects subclasses. @staticmethod → namespaced helper, no state.
  • __repr__ unambiguous (devs); __str__ readable (falls back to repr).
  • Define __eq__ ⇒ you must define __hash__ or the class becomes unhashable !

property = descriptor

class Temp:
    @property
    def celsius(self): return self._c
    @celsius.setter
    def celsius(self, v):
        if v < -273.15: raise ValueError
        self._c = v

A property is a descriptor (__get__/__set__/__delete__) — attribute access runs code. Write a custom descriptor to reuse validation across attributes.

__slots__

class Point:
    __slots__ = ("x", "y")   # no per-instance __dict__

Saves memory (no dict) + blocks stray attributes; costs: no dynamic attrs, weakref/multiple-inheritance caveats. Worth it for millions of small objects.

@dataclass

from dataclasses import dataclass, field
@dataclass(frozen=True, slots=True)
class User:
    name: str
    tags: list = field(default_factory=list)  # not []!

Generates __init__/__repr__/__eq__. frozen=True ⇒ immutable + hashable. Mutable defaults ⇒ default_factory !

Inheritance, MRO & super()

  • Method resolution uses C3 linearization → a single deterministic order in Cls.__mro__. Solves the diamond by visiting each base once, children before parents.
  • super() follows the MRO, not "the parent" — in multiple inheritance it can dispatch to a sibling. Every cooperating class must call super().__init__(...) and accept **kwargs.
class A:  ...
class B(A): ...
class C(A): ...
class D(B, C): ...
D.__mro__  # D, B, C, A, object

Lightweight hooks over metaclasses

  • abc.ABC + @abstractmethod → enforce an interface (can't instantiate until implemented).
  • Metaclass (type subclass) → customise class creation (registration, validation). Powerful but heavy.
  • __init_subclass__ (per-subclass hook) & __set_name__ (descriptor learns its attr name) replace most metaclass needs !

Typing & Type Hints

  • Hints are not enforced at runtime — they're for mypy/pyright, IDEs, and docs. CPython ignores them (beyond storing __annotations__).
def f(x: int, s: str = "") -> bool: ...
name: str | None = None          # 3.10 union (was Optional[str])
items: list[dict[str, int]] = []  # builtin generics (3.9+)

Generics (3.12 syntax)

def first[T](xs: list[T]) -> T:
    return xs[0]
class Box[T]:
    def __init__(self, v: T): self.v = v

Protocol vs ABC

from typing import Protocol
class Sized(Protocol):
    def __len__(self) -> int: ...
# structural: ANY class with __len__ matches, no subclassing

Protocol = static duck typing (nominal not required); ABC = nominal (must subclass). Optional[X] ≡ X | None; forgetting the None branch is the classic bug !

match / case (3.10+)

match command.split():
    case ["go", ("n"|"s"|"e"|"w") as d]:
        move(d)
    case ["drop", *items]:      # capture rest
        drop(items)
    case Point(x=0, y=y):       # class pattern
        on_axis(y)
    case {"type": t, **rest}:   # mapping pattern
        handle(t, rest)
    case _:                     # wildcard (default)
        unknown()
  • Structural matching — deconstructs by shape/type, binds names. Not a C switch (no fallthrough).
  • case x: (bare name) always matches and binds — use a dotted constant (case Color.RED) to compare by value !
  • Class patterns need __match_args__ (dataclasses/namedtuples get it free) for positional matching.

The GIL, Threads & Processes

The GIL is a CPython mutex: only one thread executes bytecode at a time. It exists to make refcounting thread-safe cheaply. It's released around blocking I/O and by C extensions (numpy).

WorkloadUse
I/O-bound (net, disk, db)threads or asyncio — GIL released during waits
CPU-bound (crunching)multiprocessing — real parallel cores
either, pooledconcurrent.futures executors
  • Threads share memory (cheap, but need locks); processes = separate memory ⇒ IPC/pickling cost, no shared-state races.
  • ! x += 1 on a shared int is not atomic (load/add/store — can lose updates). list.append happens to be atomic in CPython, but don't rely on it — use a Lock.
  • 3.12 per-interpreter GIL (subinterpreters); 3.13 free-threaded build (PEP 703) can disable the GIL — future of real threading.

asyncio

Single-threaded cooperative concurrency. One event loop runs many coroutines; await yields control back to the loop at an I/O point so another task runs. No preemption — a coroutine holds the loop until it awaits.

import asyncio
async def fetch(u): ...
async def main():
    async with asyncio.TaskGroup() as tg:   # 3.11
        tg.create_task(fetch(a))
        tg.create_task(fetch(b))
asyncio.run(main())
PrimitiveBehaviour
gather(*aws)run all; one fail → others keep running
TaskGroup (3.11)structured; one fail → cancels siblings, raises group
create_taskschedule & return a Task handle

! A blocking/CPU call inside a coroutine freezes the whole loop. Offload: await asyncio.to_thread(fn) (I/O) or a ProcessPoolExecutor (CPU). Async ≠ faster; it's for many concurrent I/O waits.

Memory Management & GC

  • Primary mechanism = reference counting. Each binding/arg/container-slot increments; going out of scope / del / rebinding decrements. Refcount 0 ⇒ freed immediately (deterministic).
  • Refcounting can't free reference cycles (a↔b). A separate generational cyclic GC (gen 0/1/2) periodically finds and collects them. Newly-created objects are gen 0, collected most often.

weakref & __del__ !

import weakref
cache = weakref.WeakValueDictionary()  # entry drops
                                        # when value unref'd
  • __del__ is a footgun: non-deterministic timing, can resurrect objects, exceptions are swallowed, and it can break cyclic collection. Prefer context managers / weakref.finalize.
  • Leaks in a long service: global caches/lists that only grow, unbroken cycles with __del__, C-ext leaks. Diagnose with tracemalloc (snapshots/diffs), gc, objgraph.

Exceptions & Context Managers

  • Hierarchy: BaseException ⊃ Exception. Catch Exception, not BaseException — the latter swallows KeyboardInterrupt/SystemExit ! Never bare except:.
try:      risky()
except ValueError as e:
    handle(e)
else:     ...      # ran only if NO exception
finally:  cleanup() # always

Chaining

raise RuntimeError("load failed") from err  # preserve cause
raise                                        # re-raise, keep tb

Bare raise inside except re-raises with the original traceback. from err sets __cause__. ExceptionGroup + except* (3.11) handle concurrent failures from a TaskGroup.

Context managers · EAFP

from contextlib import contextmanager
@contextmanager
def tx(conn):
    conn.begin()
    try: yield conn; conn.commit()
    except: conn.rollback(); raise

__exit__ returning truthy suppresses the exception. EAFP ("try, catch") > LBYL ("check first") — idiomatic & race-free.

Strings, Bytes & Encoding

  • str = Unicode code points; bytes = raw octets. Boundary: str.encode(enc) → bytes, bytes.decode(enc) → str. Decode on the way in, encode on the way out.
  • "café".encode("utf-8") is 5 bytes for a 4-char string — non-ASCII takes multiple bytes; len(str) ≠ len(bytes) !
  • Strings are immutable: s += x in a loop is O(n²) (new object each time). Build a list and "".join(parts) — O(n).

f-strings

f"{x:.2f}"      # 2 decimals
f"{n:,}"        # thousands sep
f"{x:>8}"       # right-align width 8
f"{val=}"       # 3.8 debug: "val=42"

! At I/O boundaries always pass encoding="utf-8" to open() — the platform default (e.g. cp1252 on Windows) causes UnicodeDecodeError. errors="replace" for lossy tolerance.

Imports, Packaging & Perf

  • Module = a .py; package = a dir. if __name__ == "__main__": guards script-only code (module name is "__main__" only when run directly).
  • Modules run once then cache in sys.modules — import side effects fire once. Circular imports break at module top-level; fix by importing inside a function or restructuring !
  • Modern packaging: pyproject.toml + a build backend; wheels (built) over sdist. Replaced setup.py/distutils.
  • Isolate deps in a venv; pin/lock with uv/poetry. Reproducible installs.

Performance model

  • Interpreted bytecode + C builtins. Slow = Python-level loops/attribute lookups; fast = pushing work into C (builtins, numpy, comprehensions, str.join).
  • Profile, don't guess: cProfile (which fn), line_profiler (which line), tracemalloc/memray (allocs). Bind hot-loop lookups to locals.

★ Code Review Checklist

Mutability & defaults

  • ☐ No mutable default arg ([]/{}) — sentinel None or default_factory !
  • ☐ Function that mutates a passed list/dict is intended & documented (caller sees it).
  • ☐ Shallow copy where a deep copy is needed (nested mutables shared).

Names & scope

  • ☐ No closure/loop late-binding bug (bind via default arg or factory).
  • ☐ is only for None/singletons, never for value equality of ints/strings.

Data model

  • ☐ Custom __eq__ ⇒ matching __hash__ (or intentionally unhashable).
  • ☐ No dict resize while iterating; hashable keys only.

Concurrency

  • ☐ CPU-bound work uses processes, not threads; shared mutable state is locked (don't trust GIL atomicity) !
  • ☐ No blocking/CPU call inside a coroutine (to_thread/executor).

Errors & resources

  • ☐ No bare/over-broad except; exceptions chained with from; re-raise via bare raise.
  • ☐ Files/locks/conns via with; encoding="utf-8" on I/O.
  • ☐ Type hints present on public APIs; Optional None-branch handled; mypy/ruff clean.
