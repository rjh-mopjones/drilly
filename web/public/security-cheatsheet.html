Fundamentals

  • CIA: Confidentiality · Integrity · Availability (+ authenticity, non-repudiation).
  • Defense in depth: layers, so one failure isn't fatal.
  • Least privilege: minimum access needed, nothing more.
  • Fail secure / deny by default; secure defaults.
  • Threat model with STRIDE: Spoofing, Tampering, Repudiation, Info disclosure, DoS, Elevation.

Password Storage

store = argon2id( salt + password )   FIX
# per-user random salt, high work factor
# NEVER: md5/sha1/sha256(password)   VULN
  • Use Argon2id / bcrypt / scrypt — slow & salted by design.
  • Salt stops rainbow tables; work factor stops brute force.
  • Add rate limiting + breached-password checks + MFA.

AuthN vs AuthZ

AuthNwho are you? (login, MFA, passkeys)
AuthZwhat may you do? (RBAC/ABAC)
  • MFA = know + have + are. Prefer WebAuthn/passkeys (phishing-resistant).
  • ! Always enforce authorization server-side; deny by default.

SQL Injection

// VULN — string concat
db.query("SELECT * FROM users WHERE id="+id)

// FIX — parameterized query
db.query("SELECT * FROM users WHERE id=?", [id])

Fix = parameterized queries / prepared statements / ORM. Input validation is defense-in-depth, not the fix. Least-privilege DB user.

CSRF · SSRF · Clickjacking

  • CSRF FIX: anti-CSRF token + SameSite cookies.
  • SSRF FIX: allowlist URLs; block link-local & 169.254.169.254 metadata. !
  • Clickjacking FIX: X-Frame-Options / frame-ancestors.
  • Open redirect FIX: validate redirect targets.

JWT & Session

  • Cookies: Secure + HttpOnly + SameSite.
  • ! JWT: reject alg:none/alg confusion; strong secret; short expiry + refresh rotation; no sensitive data in payload; can't easily revoke.
  • Rotate session ID on login (session fixation).
  • OAuth: validate redirect URI, use PKCE + state.

Supply Chain & Secrets

  • Secrets in a vault/secret manager — ! never in git or committed env files; rotate.
  • Pin & lock deps; watch typosquatting / dependency confusion.
  • SBOM + artifact signing (Sigstore) + SLSA provenance.
  • Scan images; use minimal/distroless; run non-root.

Cloud / Infra / Memory

  • Cloud: IAM least privilege; no public buckets; IMDSv2; shared-responsibility model.
  • Network: TLS/mTLS, HSTS, segmentation, zero trust.
  • Memory (see OS sheet): overflow/UAF → ASLR + DEP/NX + canaries; memory-safe langs (Rust) prevent the class.

☐ Threat-Model / Review Checklist

  • ☐ Map trust boundaries & data flows; run STRIDE per boundary.
  • ☐ AuthN strong (MFA); AuthZ enforced server-side, object-level (no IDOR).
  • ☐ All input parameterized; all output encoded.
  • ☐ Secrets in a vault; TLS everywhere; least privilege.
  • ☐ Deps scanned & pinned; images minimal + non-root.
  • ☐ Security headers (CSP/HSTS/X-Frame-Options); cookies hardened.
  • ☐ Logging w/o secrets/PII; alerting + an IR plan.
  • ☐ Fail closed; validate at the boundary; assume breach.
