Critical Rendering Path

flowchart LR H["HTML"] --> D["DOM"] C["CSS"] --> O["CSSOM"] D --> R["Render tree"] O --> R R --> L["Layout / reflow"] L --> P["Paint"] P --> X["Composite (GPU)"]
  • CSS is render-blocking; a sync <script> is parser-blocking → use defer/async.
  • Fewer bytes on the critical path = faster first paint. !

Event Loop

console.log(1);
setTimeout(()=>console.log(4));      // macrotask
Promise.resolve().then(()=>console.log(3)); // microtask
console.log(2);
// → 1 2 3 4
  • Microtasks (promises, queueMicrotask) drain fully between macrotasks.
  • Macrotasks: timers, events, I/O.
  • rAF runs right before paint. ! Long task = frozen UI.

JS Engine (V8)

  • parse → bytecode (Ignition) → JIT (TurboFan) → deopt if shapes change.
  • Hidden classes: keep object shapes consistent; init all props in one place. !
  • GC: generational mark-sweep; leaks keep objects reachable (see below).

Browser Security

  • SOP: origin = scheme + host + port; cross-origin reads blocked.
  • CORS: server opts in via Access-Control-Allow-*; non-simple → preflight OPTIONS.
  • CSP: allowlist sources → mitigates XSS.
  • SameSite cookies + tokens → mitigate CSRF; frame-ancestors → clickjacking. Cross-ref Security sheet.

Caching

Cache-Control: max-age=31536000, immutable  // hashed assets
Cache-Control: no-cache        // revalidate via ETag
→ If-None-Match: "abc" → 304 Not Modified
  • Layers: memory → disk → Service Worker → network; plus bfcache.
  • Bust cache with content-hash filenames.
  • SW strategies: cache-first / network-first / stale-while-revalidate.

Performance — Loading

  • Hints: preconnect, preload (critical), prefetch (next), dns-prefetch.
  • Code split + route chunks; dynamic import(); loading="lazy".
  • Minify + tree-shake + compress (br/gzip); optimize images (AVIF/WebP, srcset).
  • Kill render-blocking CSS/JS; inline critical CSS. !

Performance — Runtime

// layout thrash — read/write/read/write
els.forEach(e=>{ e.style.h = e.offsetHeight+1 }) // !
// fix: batch reads, then writes
const hs = els.map(e=>e.offsetHeight);
els.forEach((e,i)=>e.style.h = hs[i]+1);
  • reflow (geometry) > repaint (pixels) > composite (transform/opacity, cheap, GPU).
  • 16.6ms/frame; break long tasks; debounce (wait for idle) vs throttle (rate-limit); virtualize long lists.

Web APIs

  • Web Worker: CPU off main thread (no DOM, postMessage).
  • Service Worker: network proxy, offline, push.
  • IntersectionObserver: lazy-load / infinite scroll.
  • History API: SPA routing (pushState).
  • WebSocket/SSE; IndexedDB; AbortController to cancel fetch.

Memory Leaks (spot them)

  • Detached DOM kept by a JS ref.
  • Listeners/timers/intervals never removed. !
  • Closures capturing large scopes; growing global/module maps & caches.
  • Find: DevTools Memory → heap snapshots, "Detached" nodes, retainers.

☐ Playbook: slow page / "type a URL"

  • ☐ DNS → TLS → HTML → CRP → JS parse/exec → hydrate → interactive.
  • ☐ Measure first: LCP/INP/CLS, the request waterfall, main-thread flame chart.
  • ☐ Loading slow? cut critical bytes, preconnect, split, compress, lazy-load.
  • ☐ Janky? find reflow/thrash/long tasks; debounce; virtualize; move CPU to a worker.
  • ☐ Big bundle? analyze, tree-shake, drop deps, dynamic-import routes.
  • ☐ Leak? snapshot, find detached nodes + retainers, remove listeners.
  • ☐ Pick storage/rendering by the constraint (SEO, offline, size, sent-to-server).
