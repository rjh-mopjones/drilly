Floating Point

bool eq(double a,double b,double eps=1e-9){
  return std::abs(a-b) <= eps*std::max({1.0,std::abs(a),std::abs(b)});
}
  • double for prices; never == — use epsilon/ULP. !
  • Money is NOT a double — integer cents / decimal (0.1 is inexact).
  • Catastrophic cancellation bites finite-diff Greeks; -ffast-math breaks NaN. !

RAII & Ownership

  • RAII = lifetime-bound resources; deterministic dtor (no GC pauses).
  • Rule of 0 (prefer); rule of 3/5 if you write one, consider all.
  • unique_ptr (owning, zero-cost) > shared_ptr (atomic refcount — off hot path). !
  • Never raw new/delete.

Templates & CRTP

template<class D> struct Engine {
  double price(){ return static_cast<D*>(this)->calc(); }
};  // CRTP: static dispatch, inlinable, no vtable
  • CRTP / templates remove virtual dispatch on the hot path.
  • Expression templates (Eigen) fuse a=b+c+d, zero temporaries.
  • Constrain with concepts: template<std::floating_point T>.

Move & RVO

  • std::move is a cast; move ctor steals the buffer O(1) vs O(n) copy.
  • Return big objects by value — RVO/NRVO elides the copy.
  • ! return std::move(local) disables RVO; move on const copies.

Cache & Layout

  • SoA > AoS for bulk pricing (vectorizes, cache-friendly).
  • 64B cache lines; pad to avoid false sharing. !
  • No allocation on the hot path — reserve, reuse buffers, pools/arena.
  • Layout, not FLOP count, usually dominates numeric perf.

Eigen + Cholesky

// correlated normals: X = L * Z, Sigma = L L^T
Eigen::LLT<MatrixXd> llt(Sigma);
MatrixXd L = llt.matrixL();
VectorXd X = L * Z;   // Z ~ iid N(0,1)

Eigen = expression templates + SIMD; call BLAS/LAPACK/MKL for heavy ops. Cholesky is THE correlated-draw primitive.

RNG (<random>)

std::mt19937_64 g(seed);
std::normal_distribution<double> N(0,1);
double z = N(g);
  • Never rand(). Fixed seed for reproducibility.
  • ! Parallel MC: one engine per thread, distinct seeds — never share.
  • Sobol (quasi-random) → faster MC convergence.

Monte Carlo Pricer

double sum=0, sum2=0;
for(int i=0;i<N;i++){
  double z=Nd(g);
  double ST=S*exp((r-0.5*sig*sig)*T + sig*sqrt(T)*z);
  double pay=std::max(ST-K,0.0);
  sum+=pay; sum2+=pay*pay;
}
double price=exp(-r*T)*sum/N;         // stderr ~ 1/sqrt(N)

Template on payoff+generator to inline; antithetic +z/-z for variance reduction.

Numerical Methods

// Newton for implied vol: f(sig)=BS(sig)-mkt
sig -= (bs(sig)-mkt)/vega(sig);   // repeat
  • Newton (fast, needs derivative) vs bisection (robust) vs Brent (both).
  • Trees (backward induction, American), finite-diff PDE (Crank-Nicolson).
  • Watch stability & step size.

Low Latency

  • Kill virtual dispatch on hot path → CRTP / templates / variant.
  • [[likely]], inlining, SIMD (-O3 -march=native), SoA.
  • No exceptions/allocation on hot path; PGO + LTO. ! Measure, don't guess.

Concurrency

  • std::execution::par for easy MC; std::atomic + memory orders.
  • Parallel MC: split paths, per-thread RNG, reduce partials. !
  • Float non-associativity → results vary by thread count (reproducibility).
